# 曲面场景实时队列数值验证（2026-10-22）

本轮把独立观测帧率接入已有场景队列，并修复暂停恢复、负时间步的曲面对象更新。**内核与场景队列已通过原版数值对照；曲面的 Worker/App 实时播放、录制链路尚未完成，原版整窗验收仍为 0/11。**

## 修正内容

- 场景更新现在可以传入独立 `actualFrameRate`，由实际消费它的曲面参数动画读取；省略时继续使用固定回放 FPS。
- 暂停帧只显示、不更新对象。恢复时，点对象允许更新序号跳过暂停帧，网格以最近显示帧检查顺序，不再错误要求对象每帧都更新。
- 保留原场景的有符号时间。负时间步可以回退场景时钟；曲面对象遇到非正时间步提前返回，不更新参数、位置或对象时间。
- 合并原来额外的曲面帧类型，使用共享帧合同；保留重复更新、非有限时间、取消和失败对象保护。

## 实际执行了什么

运行原 MathArt 1.7.8 安装包内的 JSON 配置解析、CPU 曲面构造、场景队列、参数动作、相机更新和模式切换。10 组流程共 133 次更新，独立执行两次，结果相同，两个 JVM 子进程均正常退出并回收。

| 流程 | 核对内容 |
| --- | --- |
| 点／网格参数启停 | 变化的观测 FPS、参数渐启和停止 |
| 点 → 网格 → 点 | 当前对象替换、初始动作对象身份保留 |
| 带暂停的渐变过渡 | 中间遮罩透明度、切换时机、恢复更新 |
| 零时长动作、空网格队列 | 首帧启动、队列结束后对象不再更新 |
| 独立参数片段 | 片段开始与结束的参数生命周期 |
| 负场景时间、初始暂停 | 有符号时钟、点／网格暂停后首次更新 |

本地通过正式 JSON 导入和现有场景队列执行相同输入。逐帧比较场景时间、队列位置／完成状态、相机及旋转速度、对象时间、首个坐标、模式及替换身份。Float32 比较完全相等。原版记录的遮罩为 0–1 浮点数，本地展示合同为绘制阶段的 0–255 字节，按原版绘制转换比较。

探针没有调用原版绘制，也没有打开窗口。基础 PGraphics 输出了不支持加载 shader 的提示，原始 stderr 已保留。此轮不能证明原版 GPU、完整网格像素、鼠标操作、录制或整窗视觉一致；未操作用户桌面。
