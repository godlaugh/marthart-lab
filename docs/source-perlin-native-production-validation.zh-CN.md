# Perlin 原生数学图层与工作流验收

2026-10-26，已进入 Apple Silicon 本地应用 **2.0.0-preview.10**，改动前基线 `1e6a0d5`。完整源 Perlin 的 GPU 绘制已接到本机原生 OpenGL；两个原版预设共 10 帧、3,000,000 个数学图层像素全部相同。数值模型、时间线和 CPU 绘制仍由原来的 Worker 拥有。**整体仍在 M3：场景一致性验证，Perlin 全家族及其余场景尚未完成。**

## 原版证据与差异定位

原版仍为固定的 MathArt 1.7.8 JAR，SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。使用未改写的 `Noise/noise1.json`、`Noise/noise2.json`，原版正常许可、策略与水印全部保留；当前 VIEW、RUN、EXPORT 检查均通过。原版 offscreen 宿主连续执行正常 `runFrame`，30 FPS，主画布逻辑 406 × 486、density 2，输出逻辑 250 × 300、实际 500 × 600。

新增观察在原版 Perlin draw 前读取实际顶点、索引、uniform、纹理和 GL 状态，draw 后立即读取数学图层，随后继续正常文字／水印绘制。没有修改 draw 参数、着色器或时钟。两组各五个采样点的正常完整画面均与 10 月 22 日保存的原版逐像素相同，支持观察没有改变画面。两个原版任务分别用时 12.719、7.526 秒，exit 0、stderr 空、无超时、进程组已回收；没有创建 AWT 窗口或激活桌面窗口。真实原版窗口的自然播放时序仍未由这项离屏观察证明。

这次比较完整 300,000 像素的数学图层；旧报告的 1／23 个差异是较小固定中心区域的数值，两者没有冲突。浏览器最大通道差均为 1。原生通道的 10 帧、3,000,000 像素以及实际场景时间 Float32 位模式全部相同。文字、水印和其它叠加不在这一数学图层结论内。

实际原版关闭 DITHER，本地旧 GPU 绘制启用。单变量实验在两组五个时刻分别开关 DITHER，20 帧输出完全不变，排除了它作为残差原因。生产 WebGL 状态仍修正为与原版相同，但消除差异依赖原生执行路径。现有证据将差异定位到浏览器／原生 shader 绘制后端，尚不能进一步宣称是哪一个超越函数或编译优化产生了低位差异。没有加入像素特判、公式恒等式猜测或误差容限。

## 实现与所有权

原生与 WebGL 共用一份原版 fragment body、参数规范和 ARGB 转换。原生 producer 使用已校准的覆盖整幅画布的四顶点；片元只使用 `gl_FragCoord`，没有插值输入。原生通用帧 v12 明确表示“使用接收端支持的最大 anisotropy”，能力由当前 CGL context 查询；既有数值采样请求仍用 v3，没有硬编码本机的 16，也不借用浏览器能力充当原生能力。

Worker 保留 Perlin 数值、主画布、导出画布和录制实例。主页面只代理绘制，复用已有原生连接和请求槽，并按 Worker、会话、请求、绘制序号绑定返回值。取消先撤销交付，再等待已经提交的原生帧结束，最后释放对应 Worker；失败不自动改回其它绘制后端。

收到原生 ACK 后，目标以无混合的 RGBA8 覆盖更新像素及多重采样历史，再发布原生身份。CPU 绘制、释放或失败会清除旧原生身份，不能把旧回执套在新 CPU 图像上。截图依次更新离屏画布和主画布；录制重建数值模型时保留原有画布历史。已有像素、源纹理、IPC 副本、传输与目标缓冲合并准入 256 MiB 表示预算；它不是进程 RSS 或 VRAM 上限。

真实录制测试发现，异步运行的取消闭包进入了录制返回 context，导致 Worker 消息不能克隆。修复放在状态拥有者：交接 context 使用共同的 `GenerationInput` 快照，取消能力单独留在运行状态中；没有在发送消息时盲目删除函数。

## 当前已完成的验证

- 正式 `legacy import → Generator → Worker → 主页面代理 → CGL → 保留目标 → RGBA` 链路，两个原版预设各五帧，完整数学图层零差异。
- 真实 CGL 到保留 WebGL 目标的 20 组对照，包含 0 和 4 倍采样，全部整层一致。独立 GL 参考验证两轮 GPU → CPU 淡化 → GPU → CPU 历史；取消等待 ACK、请求期间拒绝读取／释放、超预算不派发、context 丢失不保留旧身份均通过，剩余 GL 对象和服务进程为 0。
- v12 编码／真实 CGL／HTTP 的 52 项检查通过。一次旧测试仍期待笼统 runtime 错误；使用改动前已封存的原生程序复现同样的 `gpu-compile`，确认是前一阶段精确错误分类后的旧断言，已更新并保留失败证据。

- 最终相关回归：71 个文件、1,274 项全部通过，24.57 秒；包含其它原生通道的共享协议、会话和取消回归。TypeScript 检查通过。这是选定相关测试，不是仓库全量检查。
- 真实 Generator／Worker 的播放、暂停、色板热更新、截图、录制与停止检查 43 项通过；真实公共界面的 CPU／GPU 播放、自动录制、手动停止保存、取消均通过。
- 保留画布录制的五组实际界面验收通过：CPU 曲线累积历史、切换后应用 GPU、取消重试、Escape 保护及取消后替换场景、空队列。四个真实 MP4 的尺寸、帧数及帧率经 ffprobe 核对；上传的完整 PNG 像素与实际 Worker 输出逐字节相同。
- 当前帧截图五组通过，覆盖粒子／曲线、累积开关、CPU／GPU 热切换；另有 density 2 检查。共 14 次成功下载逐字节核对 RGBA，包含 1×／3×／5× 放大；取消下载未产生文件，也未替换保留的 Worker。

Apple Silicon `2.0.0-preview.10` 构建、TypeScript、Vite 与 `codesign --verify --deep --strict` 均通过。真实打包应用用独立测试资料目录隐藏启动两次，visibleWindows 与 showEvents 始终为 0。当前／重播 PNG 共下载三次；原生回执均核对到包内执行文件的真实路径和 SHA。保存、完全退出、重开后，使用公开“返回起点”对齐，再导出当前帧，完整像素相同。两次退出码 0、拥有的进程组消失、监听端口关闭，ASAR、原生程序、manifest 和原始输入未变。整个打包流程验证 14.51 秒。

重开验收证明项目数据与对齐后的图像一致，不代表播放位置会跨启动保存。构建仍有既存 Vite 大块体积提示，本轮没有据此扩大到拆包优化。

## 性能测量与取舍

对同一 Noise2 终点图像，每次仍实际执行新绘制并取得递增的原生回执，测试脚本保留 Playwright bootstrap route 时，无插桩热帧中位数为 104.80 ms。只移除已经结束用途的 route 后降为 **37.20 ms**，范围 32.8–46.5 ms；四组实验共 36 帧完整图像 hash 均相同。约 55–68 ms 是验证工具的网络拦截开销，不能当作产品修复或据此加入产品缓存。

单独的原生 helper 同一请求热往返中位数约 8.01 ms，内部 7.27 ms，其中编译链接 3.29、读回等待 2.47、纹理上传及 mip 0.89 ms；没有增加 GL fence 或改变 shader。原生 helper 每帧 CPU 中位数 5.13 ms，进程累计高水位 RSS 27.52 MiB。它不等于浏览器、Worker、HTTP 服务组成的整体成本，纯 GPU 时间未测。

最终同一源码树、相同两组五时刻任务的实际结果如下。帧耗时在 Generator 返回时立即取值，不含随后用于证据保存的字符串／base64 转换。

| --- | ---: | ---: | ---: | ---: | ---: |
| 原生 filament | 1155.1 | 39.90 | 37.1–44.5 | 8.44 | 1.75 |
| 原生 swirl | 1050.8 | 33.85 | 32.8–80.8 | 5.52 | 1.84 |

| WebGL swirl | 1022.8 | 4.90 | 4.7–5.1 | 4.57 | 1.74 |

两组完整任务原生约 5.05 秒，WebGL 约 4.48 秒。首帧包括新 Worker、场景与数值初始化，仅第一个原生预设还创建服务子进程／上下文；没有清空系统或驱动 shader cache，不能称为严格冷启动实验。后续帧推进不同时间，模型工作量也不同。250 ms 采样的进程族 CPU／RSS包含验证器、证据序列化和服务；短命子进程可能未被采到，不是每帧内存测量。

原生路径在本次样本中消除了浏览器后端低位差异，同时增加了端到端绘制成本。没有证据宣称它比 WebGL 快，也没有承诺所有尺寸均达到 30／60 FPS。传输剩余成本、最大复杂度、长时间运行、纯 GPU 时间及整个任务 token 成本尚未测全。

## 保留的失败与修正

- 原版 shader 校准首轮重复携带 `#version`；只移除宿主会添加的版本行后通过，没有改公式或输入。
- 实际录制暴露的取消闭包克隆错误已在状态拥有者修复；begin 和 finish 均增加真实 Worker structuredClone／transfer 验证。
- 旧录制验收期待 Escape 关闭正在工作的导出窗口，但该保护早已存在于基线。现验证 Escape 保持窗口、取消和服务清理完成后再公开切换场景；内部延后队列另由独立检查覆盖。
- 移除所有网络 route 后，Chromium 不再向 Playwright 暴露 Blob PNG 上传正文，导致字节审计失败。录制字节审计保留必要拦截，并明确不作性能测量；性能验证仅移除用完的 bootstrap 拦截。
- 截图检查完成后曾被开发服务器 HMR WebSocket 和缺失默认 favicon 的控制台消息判失败。现保留原位置与文本并单独记录这些精确辅助资源提示，其它应用错误仍导致失败；没有忽略任意 404 或网络错误。
- 分段性能首轮错误要求队列结束后 Scene 时钟也停在 8 秒。原版对象时间与图像冻结，但 Scene 时钟继续；修正验证器后重新执行，原失败证据保留。
