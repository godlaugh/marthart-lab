# 弹跳场景：随机配色与主色编辑验收

2026-10-24。2.0 弹跳场景现在可以使用单色、类似色、互补色和分裂互补色四种随机配色。当前仍处于 **M3：场景补全与一致性验证**；本批完成随机配色，不代表 2.0 或整个弹跳家族验收结束。

## 使用方式

在弹跳作品的“外观 → 速度色板 → 随机配色”中选择策略和数量，点击“生成并替换色板”。生成结果会替换整套色板，包括超过 25 色的导入尾部；只改设置不会修改作品。

| 设置或操作 | 行为 |
| --- | --- |
| 默认 | 16 色，类似色；生成数量可设为 2–25 |
| 分裂互补色 | 主色数量 3–6，默认 5；可以编辑主色文字或 RGB |
| 主色文字 | 保留输入原文；alpha、非法内容和空白交给原版规则解析，不提前改写 |
| 普通生成 | 使用当前草稿生成，选中第一个结果颜色 |
| 随机主色并替换色板 | 同时更新主色草稿并立即应用新色板；保留当前颜色选择 |
| 草稿与保存 | 策略、数量和主色草稿不随项目保存；生成后的完整颜色数组会保存 |
| 模拟与导出 | 改色不重新播种、不推进模拟；PNG 使用当前色板和所选模拟检查点 |

原版有一个容易混淆的默认：主色数量是 5，但初始草稿只有四项 `#FF7A59`、`#F9C74F`、`#43AA8B`、`#577590`。第五项只在显示层从当前色板补齐。未经主色编辑就生成时，原函数仍收到四项，因此走其默认锚点分支。本地实现保留这个区别。

改变主色数量只改变显示范围，不截断草稿；编辑一项时才用当前显示列表替换主色草稿。无效主色不会触发隐式修正，生成器按实际原版分支处理。

## 原版一致性证据

参考 MathArt 1.7.8，JAR SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。直接调用原包 `ManualPaletteGenerationKt` 中的数值辅助方法和生成器，使用现有 Temurin 21.0.7，以无头模式执行，窗口数为 0。

**85 组转换样本全部一致**：原始主色解析、Java AWT HSB/RGB、sRGB 传递函数、OKLab 和极小负色相边界。浮点输出按 Float32 位模式核对，RGB 按字节核对。极小负色相可能因 Float32 舍入得到 AWT 的分支 6；原版返回黑色，本地也保持这个行为。

**18 组生成结果全部一致**：12 组完整色板、6 组随机主色，覆盖四种策略、数量限制、类似色 5/6 色分支、3–6 主色、默认四项草稿、空/非法/有效主色以及截取顺序。

原程序保持自身随机源。只读 JDI 观察记录了 **226 次实际 Math.random 返回值**，包括 Double 位模式；产品测试按同一顺序重放这些值，逐项比较最终 `#RRGGBB` 数组及随机调用次数。没有替换、重新播种或修改原程序的随机源，也没有修改原 JAR。

这些结果证明所列输入和随机流的算法一致，不能把两个独立随机运行的作品称作同一幅画。所用 JVM 是本地 Temurin，不是原应用捆绑的 JVM；本批未新增原版 GUI 或整图对照。

原版默认、按钮回调和草稿不进入 ProjectState 的结论另有完整字节码依据，属于静态证据；不把它描述为原版窗口事件实测。

## 实际产品验证

无头 Chrome 操作真实 App，原生 CGL 与 WebGL 两条路径各 **84 项通过**。其中包含此前的手动编辑回归，以及随机策略、主色草稿与显示分离、无隐式应用、数量限制、保存重载和导出。使用 64 粒子作品检查交互，不扩展成新的高负载性能声明。

两条路径均确认：

- 随机配色后完整模拟检查点保持一致。
- 保存刷新与项目下载保留完整生成色板；刷新后局部生成草稿恢复默认。
- 下载 PNG 的 RGBA 与生成器实际交付并按产品规则增强的像素逐字节一致。
- 关闭导出以及重新定位同一检查点后，真实画布像素保持一致。
- 无未处理页面异常；运行期间源文件稳定，结束后无所属辅助进程残留。

相关七个测试文件共 **149 项通过**，包括 103 组实际原版向量。`build:v2`（含 TypeScript）及中英文审计通过；构建仍有已有的大文件体积提示。

| 本机流程 | 耗时 | 进程组 CPU | 采样峰值 RSS |

| 原生 CGL 实际页面 | 8.78 秒 | 16.70 秒 | 2,047,328 KiB |
| WebGL 实际页面 | 9.79 秒 | 18.93 秒 | 2,086,192 KiB |

包含手动编辑、随机生成、保存、导出及验证开销，未区分冷/热缓存。没有同等旧流程基线；token、GPU/显存成本未测，不能据此宣称性能提升。原版采集的完整运行时间与退出记录保存在证据索引；其 CPU/RSS 未测。
