# 曲面录制客户端与队列验收

2026-10-22，开发分支 `codex/v2-scenes-parity`。

本轮接通生产 Generator 客户端、连续绘图实例与 GenerationQueue。**录制界面和 FFmpeg 输出仍待连接；没有完成视频文件验收。2.0 Goal 继续进行，原版整窗效果一致性仍为 0/11。**

## 已实现

客户端从已完成的曲面主预览取得录制权限，检查后台返回的场景身份、尺寸、连续帧序号、模拟帧率、实际帧率、预热与完成状态。几何帧在主线程绘成像素，每次录制只创建一个独立绘图上下文。返回像素为从上到下的原始绘制结果，保留公式标注元数据；不会套用暂停 PNG 的增强或放大处理。

如果后台已经推进一帧，而浏览器绘制失败，客户端保留该帧几何数据。用相同帧序号与观测帧率重试时，只重新绘制，不再让后台推进。实际帧率在入口统一转换为 Float32，保留负值和有符号零，由源动画规则处理；不会用导出帧率代替。

停止先释放录制绘图资源，再要求后台恢复主预览。释放失败时仍持有绘图实例和录制句柄，可以重试；客户端意外失效时，未释放实例由模块级清理登记表继续持有，下次创建前必须完成清理。资源释放各阶段分别记录结果，避免重复执行已成功的阶段。

队列为每个编码帧传入新的实际帧率观测，等待当前帧消费完成后才请求下一帧。取消会等待正在进行的消费结束，再停止会话。停止恢复保持当前作者文档，包括录制期间未应用的草稿；延后的视口或显式新版本请求继续由队列处理。

相机响应校验提取到 `sourceSurfaceResponse.ts`，预览与录制共同使用；录制帧序号校验由 `sourceRecordingClock.ts` 的共享契约负责，移除了 Domain 中同一规则的局部实现。停止预览的公共类型现在明确允许几何与像素，旧像素消费者仍需先校验类型。

## 验证结果

| 范围 | 结果 |
| --- | --- |
| 相关自动化测试 | 最新逐文件结果：16 个文件、350/350 通过 |
| 新增客户端与资源测试 | 客户端 21 项、绘图资源 5 项，均通过 |
| 真实客户端和 GL 绘图 | 16 种组合重复两遍，32/32 通过；CPU 点/网格/切换、GPU 点/网格、密度 1/2 |
| 本地像素交叉对照 | 32 组、136 个录制帧，客户端与直接会话渲染的 RGBA 摘要逐帧完全相同 |
| 真实 GL 上下文丢失 | 保留第 1 个已推进帧，停止后成功开始新录制；两个上下文最终都释放 |
| 构建 | TypeScript 与 Vite 通过，保留既有大资源包提示 |

浏览器验证通过生产 Generator、真实 Worker、生产 SurfaceRecordingRenderer 和 ArtRenderer。它检查每次录制只创建一个上下文、停止后上下文丢失、帧尺寸及像素内容，并实际触发 WEBGL_lose_context。损坏上下文之后的绘制报错保留数值会话，停止没有重复推进；随后使用同一 Generator 能重新录制。图像交叉对照只比较录制帧，不把不同墙钟下恢复播放的图像当作同一时刻。

自动化测试覆盖过期图像、缺失实际帧率、错误句柄、未交付预热、发布前后失败、客户端绘制失败重试、停止重试、清理失败、模块加载期间销毁、畸形相机/序号/帧率/尺寸/对象身份、未确认帧的非法时间跃迁、队列消费等待、延后草稿以及取消。绘图资源单测替换底层 ArtRenderer 来注入释放失败；真实浏览器测试另行证明 GL 绘制与上下文丢失处理，不能把模拟释放异常当成真实驱动故障复现。

测试中的非法停止帧最初直接修改 readonly 字段，导致构建失败；改成创建新的畸形帧后，相关 21 项重新通过，最终构建通过，没有放宽类型约束。其余文件采用最后一次通过结果，共计仍为 350 项。

## 成本与限制

最终客户端脚本墙钟约 12.06 秒，包含附加的上下文丢失恢复检查。32 组主任务的 38 次进程族采样记录累计 CPU 约 35.01 秒、采样峰值 RSS 约 1,743 MiB。测试驱动、Vite、Chromium 和辅助进程都在统计范围；采样可能遗漏短命进程及采样间峰值，不能视为产品单帧成本或精确峰值。

第一遍为模块载入后的首次任务，第二遍复用浏览器与模块、重新创建客户端和场景，不是完整 App 冷暖启动基准。前一版本没有等价的生产曲面录制客户端，本轮不作性能改善声明。完整 token 成本与 VRAM 未测量。256 MiB 检查限制当前几何与像素回读缓冲估算，不代表全进程或显存上限。

本轮没有操作原版窗口、移动桌面窗口或重新打包已安装的 Apple Silicon 1.0 应用。与直接会话像素一致仅证明本地传输和绘制路径一致，不能证明原版 GPU 或整窗效果一致。App 按钮、公式实际叠加、FFmpeg 编码、生成文件及导出恢复仍需随后验收。
