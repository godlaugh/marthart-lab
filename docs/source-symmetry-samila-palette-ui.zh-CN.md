# Symmetry／Samila 调色与重置验收（2026-10-24）

本批在 `306c02fdb714c489305e8a39b79c80772627588a` 基线上，接通新导入原版 Symmetry 和 Samila 的手动色板、Cosine、Curve，以及编辑、运行和完整应用三种状态。整体仍在 M3；已有 1.0 应用未重新打包。

## 可以怎样使用

| 操作 | 结果 |
| --- | --- |
| 选择 Cosine／Curve，修改数量、系数或曲线节点 | 即时生成颜色并更新画面；Cosine 使用连续余弦运行模式，Curve 使用生成后的线性色板 |
| 返回 Manual | 恢复切换前的原始颜色，保留刚编辑的生成参数 |
| 应用为手动颜色 | 保留生成颜色，结束生成模式，丢弃旧 Manual 快照 |
| 返回起点 | 恢复最后完整应用的配置并重新播放；编辑器仍保留随后修改的作者内容 |
| 完整应用 | 将当前作者配置设为新的重置基准；按原版冷加载规则使用离散颜色，即使生成器仍显示 Cosine |
| 撤销／重做 | 恢复该历史节点的编辑内容、有效配置和重置基准；新建运行会话，从起点暂停显示 |
| 保存 | 文件保存原始颜色；当前打开的编辑器和运行状态保留 |
| 重新打开保存文件 | 使用保存的离散颜色，回到 Manual 和默认生成参数 |

原版项目导入先读取生成器参数，再清除这两个场景的生成模式开关；参数留待明确选择模式时使用。项目缺省七色，直接运行配置缺省六色，不能混用。已有不带新原始色板字段的本地文档继续保留既有模式与扩展。

ARGB、非法颜色文本和长列表尾项按原文保留；实际热解析使用不透明 RGB，非法文本按原版回退。首次打开外观面板为空列表补蓝／青，为单色补橙色，数量控件默认八色；这次初始化不修改画面、不进入撤销记录，切换面板也不会重复执行。颜色选择器只规范化被修改项。列表保真、编辑器参数寿命和历史重建属于明确的本地编辑策略，不声称复制原版所有控件副作用。

## 本轮修复

重置基准现在包含完整已应用配置，避免热调色以后把尚未应用的参数误当成重置初始值。Symmetry 的参数编辑树与运行构造信息分开，热参数修改不会隐式完整应用；记录恢复路径沿用同一个冷配置所有者。Samila 单独保存作者配置和当前有效配置，因此返回起点后，修改一个参数不会连带恢复其它未应用内容。

同值参数也可以是一次明确操作：动画已改变运行参数后，再输入相同作者值会写回运行状态。Samila 使用每个参数的写入版本，后台只消费一次；撤销／重做建立新会话，避免旧会话拒绝倒退的版本号。完整 Apply 同时使用当前公式草稿。

保存边界移除临时编辑器和会话；Worker 输入由统一运行投影处理。快照复制与历史累计使用已有表示容量准入，拒绝循环和超限数据；这些预算不是进程 RSS 上限。已删除被新导入所有者替代且无调用者的旧 Symmetry 色板导入入口。
