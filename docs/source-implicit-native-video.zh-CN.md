# 隐式曲面原生视频导出验收（2026-10-24）

CPU 隐式曲面的离线视频已接入共享绘图后端。在显式开启 `VITE_SOURCE_RENDERER=native` 时，导出帧来自原生绘图服务；无公式、原版公式、本地公式三种作品均已通过实际 App → PNG 帧上传 → FFmpeg → MP4 下载与解码验证。

当前仍使用产品既有的固定时间离线回放：按用户选择的时长和 FPS 逐帧求值。本轮证明导出通路和取消恢复正常，尚未证明它与原版录制的预热、更新时钟、队列结束规则一致。

## 修复及边界

静态 PNG 与视频帧现在共用 `sourceImplicitImage.ts`，显式区分两种用途。两者都消费已经生成的网格、相机及公式帧，绘图后端由共享入口选择。静态 PNG 保留图像增强；视频帧合成公式后将 alpha 置为 255，不执行静态增强。无公式和原版公式路径保留原始 RGB；本地公式沿用既有 Canvas 合成规则。

旧作品的本地公式布局还暴露了一个生成边界错误：隐式曲面以前仅在原版公式布局下生成公式帧数据，因此本地布局在原生预览时报告“缺少实际帧的公式”。已修复生成入口，并同步收紧 Worker 消费端：两种布局都必须携带有效、匹配的公式帧。预览与导出不再各自从当前文档补猜公式。旧布局、作者文字和位置继续保留，不自动迁移。

普通本地曲面、GPU 隐式场景及 JPEG 不新增原生导出资格。原生后端仍需显式启用；本轮实际视频验收使用原生模式，没有重新运行默认 WebGL 视频工作流。

## 已执行验证

真实 App 验收使用 headless Chrome，不操作用户主屏窗口。三个场景复用包内 CPU 隐式曲面，并缩短等待段，使测试期间相机确实变化。

| 场景 | 下载结果 | 帧与公式检查 |
| --- | --- | --- |
| 无公式 | 160×120，4 FPS，1 秒，4 帧 MP4 | 每帧与对应原生响应转换后的完整像素相同 |
| 原版公式布局 | 同上 | 公式帧送达，完整上传像素与原生底图加公式合成相同 |
| 已保存的本地公式布局 | 同上 | 保留作者文字和位置，逐帧检测洋红色公式确实可见，完整上传像素匹配 |

三个视频均由 FFprobe 核对尺寸、帧率、帧数和时长，再用 FFmpeg 实际解码；首末帧不同。生成请求时间为 `0、0.25、0.5、0.75` 秒，12 个上传 PNG 的 alpha 全部为 255，期间没有调用静态图像增强 Worker。公式参考比较复用产品合成器，用于核对帧传递和合成接线，不是独立的原版字形或原版完整视频一致性证明。

无公式场景额外延迟一帧原生响应后取消：该帧没有上传，编码会话被删除且再次查询为 404。随后实际重试并下载 MP4；4 个重试 PNG 与首次成功的对应帧逐字节相同，重试视频也为 4 帧、1 秒。合计核对 16 个成功上传帧，另有 1 个取消帧未上传。

静态 PNG 使用既有原版参考回归：500×600，包含公式的完整艺术画面，差异像素 **0**、最大通道差 **0**。比较边界仍为品牌前、增强前，不声称产品文件等于原版带品牌最终 PNG。下载文件 SHA-256 与上一轮相同：`c6f2e99d140681ce9939a563f722bfbc9615a3c557442b88eda6d2d69da0c1bf`。

相关测试 **5 文件、31 项通过**：静态 PNG 5 项、视频 PNG 3 项、隐式图像通路 5 项、隐式公式帧 8 项、实时录制合成 10 项。`npm run build:v2` 的类型检查和构建通过，仍有既有大 chunk 提示。

## 证据与成本

本地证据目录为 `.cache/source-implicit-native-video-20261024/`：

- `ui-verified/report.json`、三个 MP4、逐帧 PNG、输入与作品文件：三组最终验收及取消重试；源文件摘要稳定，清理无错误、遗留服务进程为 0。
- `png-regression/`：实际静态 PNG 下载及原版艺术画面对照，遗留服务进程为 0。
- `tests-cleanup.log`、`build-cleanup.log`：清除冗余布局判断后的最终测试和构建日志；UI 验收时的日志也保留。
- 较早目录保留测试入口选择器错误、本地公式缺失及过小测试文字导致颜色阈值未通过的记录；不将这些运行计为成功。最终本地公式使用正常字号重新验证。

三组视频及取消重试完整任务墙钟 **33.408 秒**；采样观察到进程族 CPU **58.970 秒**、峰值 RSS **2752 MiB**，101 次采样无错误。CPU 和内存采样覆盖三组 UI 工作流，始于服务与浏览器启动后、止于最终清理前；短命进程可能未被完整观测。墙钟包含启动、检查和清理成本。没有等价旧实现基线，也没有受控冷暖缓存分组，因此不能据此声称性能提升。GPU 与本轮 agent token 成本未测量。

## 尚未完成

原版隐式录制的 `setRenderMode`、预热和三倍更新时钟、队列完成语义仍需独立对照；原版主窗口的 DPI、平滑、动态帧及更多隐式参数也未由本轮证明。其它场景族一致性、既有界面翻译缺口及 Apple Silicon 原生组件打包发行继续保留在 2.0 Goal 中。
