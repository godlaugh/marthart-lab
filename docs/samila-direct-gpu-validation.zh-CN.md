# Samila 源 GPU 直接绘制验证

本轮针对新采样版本的生产绘制结构。之前的路径先将随机坐标经过公式计算后写入粒子缓冲，再读取缓冲绘制散点；原版在同一个 vertex shader 中完成采样、公式、映射、投影、旋转和绘制，并在 fragment shader 中取色。

## 修正依据

上一轮严格对照中，20 组完整生产 GPU 坐标有 10 组与原 shader 的采样坐标不同。首次报告比较的是原公式前坐标与本地公式后坐标，阶段标签不够严谨。本轮在相同输入下补查原 shader 的公式前、映射投影后、旋转后的现有 `vTexCoord`，还分别连接空 fragment、原 fragment 和同时捕获 `gl_Position`：这 20 组恒等公式／零旋转案例中各原阶段逐位相同，仍与本地有 10 组差异。阶段错位不能解释已观察到的结果。

同阶段诊断保存在 `.cache/samila-stage-diagnostic/report.json`，耗时约 2.83 秒、源文件稳定。它只证明这批输入，不能说明任意公式前后的坐标相同。正式后续协议将原始随机坐标只用于 PCG 算法检查，将原 `vTexCoord` 与实际绘制的公式／旋转后坐标比较。

另外，原版映射和投影选择使用 uniform，本地旧管线将其编成常量；原版 fragment 执行取色，本地旧管线提前在 vertex 取色。这些都是可观察的结构差异，不能仅凭代数等价认定不会影响浮点编译。

## 实现与结果

新采样版本已采用一次 GPU 绘制：采样、两条公式、26 种映射、6 种投影、旋转和点／四边形覆盖都在原有阶段执行，色板与余弦取色留在 fragment 阶段。数学解析由共享模块提供，不为新管线再维护一套公式解释。旧采样版本继续走原路径。

新路径只保留累积画布和有界的统计缓冲，不保存全部中间粒子坐标。统计读取来自同一次实际绘制；可选的同步观察接口也读取该次绘制，正常使用不分配观察缓冲。四边形按完整六个顶点分块，不在块间重置样本编号、种子或衰减。逻辑采样统计与实际顶点执行次数分别解释，工作预算在能力探测前按每样本最多六次公式对求值计费。

修复了初始化时遗留 ARRAY_BUFFER 绑定引发的 GL 错误，并补齐分配失败时的资源归属：删除失败保留句柄，清理未完成时拒绝读取及继续绘制，允许之后重试。旧路径的部分分配同样保留待清理记录；其内存诊断明确是分配计划的保守上界。没有引入用于规避编译缓存的随机 shader 注释。

图像比较沿用每通道 `abs(actual-expected)/max(1,abs(expected)) ≤ 2e-5`，本次最大约 `1.55e-6`。它与坐标逐位检查是不同指标，不能用图像阈值通过替代坐标失败。正式严格报告保持 **failed**，没有候选 shader 替换或私有采样步骤 hook。

PNG 下载像素与对应 Worker RGBA 完全相同；视频上传保持目标 RGB、使用不透明传输。两段视频均为 192 × 128、3 fps、3 帧；有损解码 RGB 平均字节误差约 1.506–1.658，不作为原版视频一致性证明。36 次已完成的新采样渲染均记录实际 WebGL2 后端，未以 CPU 轨迹加 GPU 调色代替通过。

正式矩阵耗时 26.60 秒，与全量检查并行；源文件前后稳定。公开操作报告也稳定，398 个源文件均已与最终工作区逐项核对哈希。记录位于 `.cache/source-samila-direct-complete/report.json` 与 `.cache/samila-direct-public-complete/report.json`；可读版本为同目录 `report.md`。这些耗时不是隔离的性能基准。

## 原 shader 自身的重复编译差异

独立诊断使用完全原版 vertex＋fragment shader，依次创建三个 WebGL 上下文。第一份的 20 个跨范围坐标与固定参照全部相同，第二、第三份均只有 10/20 相同；不需要任何本项目生产代码即可复现。证据保留在 `.cache/samila-stage-repeat-diagnostic/report.json`。

仅在忽略的诊断程序里为每次编译加入不同注释后，实际路径的 64 组完整绘制、20 组稀疏坐标和密集样本检查都通过。它支持“编译／缓存状态影响浮点结果”的推断，但没有定位到具体驱动缺陷，也不证明跨设备表现。生产代码没有采用这一规避手段，正式结果仍使用不打补丁的路径。

## 复跑

需要项目锁定依赖、Chrome、FFmpeg／ffprobe、固定 MathArt JAR，以及已核对原包身份的字节码提取证据。原包 SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。在 `studio/` 执行：

```sh
python3 scripts/source-samila-noise-oracle.py
node scripts/source-samila-palette-oracle.mjs
node scripts/build-samila-sampler-oracle.mjs .cache/samila-sampler-oracle
node scripts/build-samila-direct-oracle.mjs .cache/samila-direct-oracle
node scripts/verify-source-samila-sampler.mjs .cache/source-samila-direct .cache/samila-sampler-oracle/fixture.json .cache/samila-direct-oracle/fixture.json
node scripts/verify-samila-source-math-public.mjs .cache/samila-direct-public --splat --timeline
```

严格验证在当前已观察环境中会返回非零退出码；不能当作通过或忽略。原包提取、坐标数组与图片保留在忽略的 `.cache/`，不提交二进制。

## 保留范围

原版 JVM／JOGL 整窗一致性仍未证明。本轮原版窗口访问返回 Mac 锁定，未取得原版画面。Chrome 中执行原 shader 是独立、受限的参照，不能代替原应用运行。

本地固定帧重放与原版每次 display 的采样、热参数修改、调整尺寸和暂停截图生命周期仍有差异；这些不会因合并 GPU 程序自动解决。1.0 Apple Silicon 安装包不重新打包或替换。
