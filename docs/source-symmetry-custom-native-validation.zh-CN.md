# 自定义 Symmetry 原生计算核验证

2026-10-26。**四组构造输入、32 帧的完整状态纹理逐位一致，包含有效粒子和补齐区域，共 72,003,456 字节，差异为 0。计算核尚未接入应用；M3 和 11 类场景最终验收仍未完成。**

## 实现与原版规则

原版 MathArt 1.7.8 的自定义函数运行在 GLSL 410 片元程序中。状态纹理边长为 `ceil(sqrt(batchSize))`，每次更新覆盖整个正方形。超出有效粒子数的单元初始为零，此后同样参与计算。自定义函数可以读取 `gl_FragCoord`、`texCoord`、`stateTex` 和 `iterations`，包括邻居与补齐区域。

现有内建原生路径使用顶点计算，只保留有效粒子，不能直接承载这些语义。现有自定义 WebGL 路径另有 4,096 次循环体预算和无效结果重生规则，也不能据此认定与原版一致。

本次将占位符展开、原版窄范围 uniform 匹配及参数绑定提取成共享事实边界。新的原生程序生成器保留原始函数、宏、片元上下文及结果；原来的 WebGL 方言保留已有行为。两者都有本地文本容量限制，该限制不是原版格式限制。应用尚未选择新路径，桌面包仍为 `2.0.0-preview.3`。

## 实际对照

使用未修改的原版 JAR，通过正常 `VIEW/RUN` 授权、`ProjectState → initScene → runFrame` 离屏执行。原版没有打包的 custom GLSL 预设，下列输入均为构造配置。

| 输入 | 有效粒子 / 状态纹理 | 结果 |
|---|---|---|
| Emperor’s Cloak 1 标准函数转 custom | 562,144 / 750×750，含 356 个补齐单元 | 8 帧零差异；首帧包含原版 16 次迭代的预热 pass |
| 坐标、邻居和补齐读取探针 | 7 / 3×3 | 8 帧零差异；补齐单元后续更新可被读取 |
| 同一探针，每 pass 迭代 3 次 | 7 / 3×3 | 8 帧零差异；pass 内读取冻结的输入纹理 |
| 4,100 次有限循环及非有限结果 | 7 / 3×3，每 pass 迭代 3 次 | 8 帧零差异；保留 Infinity、NaN、负零及负度量值，Z 被清零 |

本地使用生产 TypeScript 程序生成器和专用 CGL 诊断纹理执行器，逐个比较 RGBA32F 的 32 位表示，无误差阈值。原版捕获的初始状态和实际 pass 参数作为明确输入；这不验证本地种子生成或应用时间线调度，也未证明完整画面一致。

原版授权记录为 FREE、VIEW/RUN 允许、EXPORT 不允许。没有调用原版导出或录制，没有改写原版着色器或注入种子。原版各阶段检查均为零 AWT 窗口；本地诊断仅使用 CGL 上下文，WebGL 回归使用无界面 Chrome。四个原版进程组及四个最终本地验证进程组均正常退出，结束后为空。原版正常刷新了策略缓存，已备份并记录哈希；license 和 settings 文件未改变。每次本地验证期间源码及参照哈希稳定。
