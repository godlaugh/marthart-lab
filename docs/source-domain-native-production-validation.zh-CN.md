# 域着色原生绘制接入与本机验收

2026-10-26：修复已进入 Apple Silicon 本地应用 **2.0.0-preview.9**。原版参考用例的 **500 × 600 数学图层，300,000 像素、1,200,000 分量全部相同**。导入、播放、暂停、调参、导航、PNG 与短录制的产品流程通过本机验证。

整体仍在 **M3：场景一致性验证**。这不代表 Domain 全家族或其余 10 个家族已经完成；跨设备验证仍未进行，用户目前只有这一台 Mac。

## 实际改变

完整选择原版 GPU 公式、颜色、视口且使用单次采样时，Apple Silicon 预览应用通过已有的原生 OpenGL 通道执行完整域着色程序。四角顶点、UV、Processing Float32 矩阵、动态表达式和 16 槽色板由各自已有的数据所有者产生，不做逐像素补丁或预存图片替换。显式 CPU、混合规则和本地扩展保留相应路径；WebGL 构建继续可用。

同步与异步绘制共用同一个配置、恢复策略和输出事实处理流程；实时会话共用同一组操作，等待绘制确认后才发布结果。原生编译、链接、上下文、分配、绘制、读回错误携带明确阶段，才能进入所选 CPU 回退策略。连接、协议、容量、清理及未知运行错误不会被误标成 GPU 失败。

同时修复了录制停止后丢失色板编辑器草稿的问题，补上了 CPU 回退时对旧画面、输出和临时缓冲的联合内存计量。源场景的冷重播现在随结果交付实际公式标注。八个内置 Domain 示例已由当前导入与持久化所有者重新生成，避免继续使用过时的缺省色板和导入说明。

数学参考来自此前保存的原版 `domain_coloring_zero_linear_demo.json` 实际离屏运行。原图为底部起始行，比较时只转换行顺序；没有裁去不匹配像素。该参考的独立完整数学图层，与原版实际 Scene 的中心数学区域此前已经校准为零差异。它不含原版正常 FREE 水印；完整原图、水印与来源记录继续保留。

历史 ANGLE 重放在中心区域存在 744 个不同像素，这份历史结果仍有效；本次消除的是该参考用例在新产品原生路径上的数学图层差异。不是所有公式、参数、窗口状态都已验收。

## 重开后的时间行为

初次导入呈现 0 秒；本次重开呈现首个重建帧约 0.033 秒。验收分别执行公开“返回起点”操作，将两次启动对齐到同一重建帧后再比较，PNG 像素相同。没有据此声称播放位置会跨启动保存。

## 保留的失败及修正

- 最初协议校准使用了驱动查询名称 `u_palette[0]`；改为实际统一变量名 `u_palette` 后通过。完整 16 槽数据保留。
- 公共录制首轮暴露色板编辑器草稿丢失，已在调用方作者快照边界修复。随后的一次失败仅为 JSON 键顺序，验证器改为保留缺省与有符号零的结构比较。
- 首轮开发界面导出遇到 Vite 动态依赖失效；限定验证入口及公式依赖后通过。冷重播缺少标注事实则在共享呈现所有者处补齐，未在验证器中伪造标注。
- 打包检查首次卡在 Electron 的 `response.finished()` 观测等待；实际两次下载已完成。保存诊断并退出所拥有的隐藏应用，后续改用响应身份与实际下载结果验证。
- 广泛回归发现生成示例落后于当前导入规则；重新生成，并让生成器/测试使用正式持久化所有者区分保存数据与临时编辑器状态。

## 成本与限制

生产数学图层一次完成帧约 **91.7 ms**，包含本次绘制边界的耗时。整个原版数学对照加应用界面验证约 **10.65 秒**；进程族采样的数学阶段 CPU 约 8.56 秒、峰值 RSS 约 1.76 GiB，界面阶段 CPU 约 14.20 秒、峰值 RSS 约 2.16 GiB。公共 native 录制验证约 3.03 秒，进程族采样 CPU 约 6.42 秒、峰值 RSS 约 1.51 GiB；最终打包流程验收约 3.81 秒。

这些是同机完成任务的观测，不是冷/热分离基准或 native 对 WebGL 的性能提升结论。短寿命进程可能落在采样间隔外，未测任务总 token 成本及最大复杂度延迟。

Domain 生产公式、AST、迭代数、像素数与联合内存均有限制，但原生整图提交没有细粒度取消边界；超时与进程退役不能保证 GPU 即时停止。统计中的 `invalid: 0` 表示完整不透明输出覆盖，不能解释为没有无效数值轨道；轨道异常由原程序处理，未单独测量。

仍需验证更多公式/色板/视口组合、原版完整标注与整窗动态行为。CPU 跨运行时逐位一致性、其他 GPU 与第二台 Mac 的结果仍未知。
