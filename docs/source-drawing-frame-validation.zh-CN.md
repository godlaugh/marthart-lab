# 原生渲染准备：二进制帧传输

后续进展：[常驻渲染会话验证](source-renderer-session-validation.zh-CN.md) 已实现连续帧、进程管理和错误恢复；本文保留单帧协议阶段的历史记录。

2026-10-23，基线 `c6f481e`。本轮把原生诊断程序改为直接读取产品生成的二进制帧，移除了逐个导出 JSON 参数、shader 和缓冲文件的路径。**数值按原始位传输，完整艺术画面对照仍保持零差异。应用尚未切换到原生渲染。**

## 现在能做什么

- 调用者明确给出物理像素尺寸、背景、代次和帧序号，原生返回对应身份与尺寸。身份是响应关联字段，不是权限凭据。
- 同一帧内保留完整绘制顺序、正反面选择、深度状态和原版混合方式。
- 支持 uint16／uint32 索引、非零索引起点、非索引绘制及明确的空绘制。
- 浮点数组、整数、整数向量、矩阵和共享纹理由参数类型声明决定。负零不经过 JSON 数字转换；属性中的 NaN payload 和无穷大槽位保持原样。
- 不再限制为一张 64×64 纹理、500×600 画布或一至两个 draw。实际设备能力和资源预算不足时明确失败。

`sourceDrawingFrame.ts` 负责从已有绘制快照编码整帧；原生 `SurfaceCglReplay.m` 独立解析并检查收到的字节，不能相信调用者声称的长度或容量。所有字段、索引、参数和纹理范围检查完成后才创建 CGL 上下文。原生 shader 链接后还检查实际使用的参数类型，不能把缺失参数当成默认零值。

## 容量与生命周期范围

编码器先计算完整包长度，再分配最终二进制缓冲。读取端先检查头部长度，再读取有上限的包；截断、尾随字节、无效集合数量、越界索引、参数声明不符都会失败。

当前容量规则为：包长的四倍加画布每像素 12 字节不超过 256 MiB。四倍用于包、解析副本及上传／纹理 mipmap 的保守额度；每像素额度用于颜色、深度和读回缓冲。编码器还检查保留快照与输出包的共同额度。这是显式缓冲的资源准入，不是 JavaScript 对象、编译器、驱动和进程峰值内存的完整上限。尺寸还必须满足 16,384 单边、1,600 万像素和运行时设备限制。诊断程序会保存逐 draw 图像，因此它另有全部读回文件合计 256 MiB 的上限。

仍是一次命令处理一帧，成功退出后才作为有效结果。每个 draw 的 shader、buffer、texture、VAO 在 `finally` 释放；整个命令释放 FBO 和 CGL 上下文。测试与正式验证都用带截止时间的自有子进程运行，无窗口。编码时取消已有测试；**常驻进程的取消、超时恢复和应用接入尚未完成**，不能将本轮错误处理视为其验收。

## 验证

正式入口仍为 `node scripts/verify-source-surface-cgl.mjs`，其输入来自真实产品 Worker、材质和绘制快照，公式继续使用已有独立字形服务。Möbius、Cornucopia、Sphere 都检查逐 draw 几何以及公式合成后的完整艺术画面。原版水印／品牌图层不在艺术层一致性声明范围内。

新增边界测试直接编译、执行系统 CGL 程序，覆盖不同尺寸／背景、数组和整数向量、负零、两种索引宽度及起点、非索引范围、空绘制、多纹理和绘制顺序；也覆盖损坏头部、版本、身份、尺寸、非有限背景、截断、尾随内容、集合数量、索引、参数类型、shader 编译失败与超预算。

详细最终结果和成本对照见本文末尾的实测记录。普通应用仍使用 WebGL，Möbius 既知的 1 像素差异没有因此在应用里消失。

## 私有协议布局

当前版本 1，所有整数和浮点字按 little-endian 编码；文本为严格 UTF-8，禁止 NUL。长度字段是字节数；数值块保持位模式。此协议面向本地受管渲染器，不开放网络服务。

| 顺序 | 字段 |
| --- | --- |
| 固定头部，52 B | magic `0x31464c4d`、版本、总字节数、代次、序号、宽、高（均 uint32）；背景四个 float32；纹理数、draw 数 |
| 每个纹理 | 宽、高、float32 anisotropy、长度＋RGBA8 字节；固定 linear / linear-mipmap-linear / clamp，生成 mipmap |
| 每个 draw | 两段长度＋shader 文本；first、count、instances、状态位；面选择数量及顺序；属性集合；索引宽度与块；参数集合 |
| 属性 | 名称、分量数、实例步进 0／1、长度＋float32 原始字 |
| 索引 | 宽度 0／16／32；宽度非零时附长度＋原始字 |
| 数值参数 | 名称、类型标签、元素数、长度＋原始字 |
| 纹理参数 | 名称、类型标签 9、纹理编号 |

类型标签：float=1，int=2，vec2=3，ivec2=4，vec3=5，vec4=6，mat4=7，float-array=8，sampler2d=9。状态位 1 为深度测试、2 为深度写入、4 为顺时针正面；面选择 0=双面、1=正面、2=背面。深度比较固定 LEQUAL，颜色混合固定源 alpha 覆盖、alpha 通道相加。字段不能隐含新的光栅语义；扩展须同时更新编码、解析和真实验证。

输出 `frame.rgba` 为 bottom-up RGBA8，`renderer.json` 记录代次、序号、尺寸、驱动及行顺序。当前输出文件属于诊断工具；未来常驻会话仍需有边界的响应传输与进程身份绑定。
