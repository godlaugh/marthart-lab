# 原生 Symmetry 应用链路验收

2026-10-25。本轮完成 **内置二维源 Symmetry 的原生后端接入**。通过应用实际使用的 `Generator` 调用链，8 帧原版图像对照全部一致，暂停截图、导航和录制状态恢复通过。**M3 仍在进行，完整 2.0 尚未验收完成。**

## 已完成什么

- 实时预览使用生产 `SourceIteratedNativeBackend`，验证脚本不再自带一份诊断后端。
- 计算状态与累积图像分别持有；截图改尺寸只替换图像目标。程序切换保留已有墨迹、粒子检查点和显示次数。
- 新着色器先编译并验证接口，再替换旧程序。不兼容程序会被拒绝；清理失败会保留资源所有权，阻止继续使用不确定状态。
- 接入暂停/继续、热参数、暂停导航、截图、录制预热、逐帧录制及停止后的主预览恢复。页面时钟如实标为 `page-wall-clock`。
- 取消操作在已确认的效果之间停止，不中断其它场景共享的原生连接。

验证脚本曾记录 Vite 热更新 WebSocket 错误。最终验证在转换阶段按生产构建语义关闭 `import.meta.hot`，保留页面关闭时的连接清理；没有修改系统或浏览器的安全设置。最终运行没有浏览器错误。

## 成本记录

最终后台流程耗时 **8.66 秒**；子进程 CPU 累计 **23.80 秒**；每 0.5 秒采样的进程组 RSS 峰值 **1,109,072 KiB**。CPU 包含采样子进程开销；RSS 是同时驻留内存之和，不是 GPU 内存，可能漏过短暂峰值。

8 帧对照部分在释放资源前发出 44 个请求，共 9,135,883 字节；完整截图、导航、录制和清理流程共 88 个请求，18,295,939 字节。冷启动首帧 2.065 秒，后续帧 0.288–0.313 秒，包含传输与比较，并非交互帧率测量。前一诊断入口首帧 2.166 秒、后续 0.304–0.320 秒；只有单次样本，完整流程也不同，**不据此宣称提速**。

代理开销另记在证据索引：从本轮首次读数到开始写验收记录，Goal 工具计数增加 478,033 token、1,207 秒。这是工具计数器增量，不是每次渲染的 token 成本，也不是最终整轮总量。
