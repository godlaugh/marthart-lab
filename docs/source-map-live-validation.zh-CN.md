后续进展：公开界面、播放控制、暂停截图及迭代次数热更新已接通，见[实时界面验收](source-map-live-ui-validation.zh-CN.md)。下文保留核心阶段当时的验证范围。

2026-10-21。Map 的实时状态所有者已接入实际生成 Worker，复用原有 Symmetry 会话并保留 Map 的差异。**当前完成的是核心与 Worker 生成链路；Map 的公开编辑器、播放控制和暂停截图按钮尚未切换到实时链路。** 2.0 仍处于 M3，原版完整窗口验收为 0/11。

## 已实现行为

SourceIteratedSession 持有同一生命周期的时钟、队列、参数、原始粒子种子、GPU 状态、累积纹理和相机快照。已移除旧的 Symmetry 专属会话文件和身份辅助文件，现有 Symmetry 消费端直接使用共享模块，没有保留一层兼容转发。

Map 在队列未结束的帧执行两次有序更新，队列结束后执行一次，暂停执行零次。暂停后的普通显示仍增加一次墨迹；相机角度变化会清空 Map 累积，但不会修改粒子。重播期间继续执行原版规定的普通更新，显示重播时跳过相机捕获和参数确认；目标尺寸变化取消重播并保留粒子状态。

Map 动画写入颜色速度和相位时不请求重播，也不会覆盖同名公式参数。显式运行设置事件在队列所有者内比较当前动画值，使用原 Float32 差值和阈值，写入两个颜色字段后决定是否重播。事件有独立递增序号，重复值调用也可表达。原运行设置是整组调用：亮度、对比度、gamma、动态范围、饱和度、衰减、步长度量范围及模式、两个颜色字段都要求该事件序号，防止单属性修改绕过颜色回写；背景和点尺寸独立。过期事件或缺少必要事件的修改会被拒绝。

点尺寸另有显式事件序号。构造值保留原值；热 setter 才执行 max(1, Float32(value))。例如构造尺寸 0.5 在四倍导出比例下为 2，热 setter 后为 4，后续显示保留 setter 的运行值。它不重建场景，也不请求重播。

暂停截图复用共享状态顺序：先显示导出画布，再执行暂停更新，最后显示主画布。原版并非被动读回旧图片。同尺寸活动重播可以推进两次；改变尺寸会取消重播。Map 保留自身背景 RGBA 和主画布物理参考尺寸。

## 验证与证据范围

- 实际 Chrome WebGL 核验 Map 2／2／2／1 更新序列，并与独立 Float32 平移计算逐项比较粒子状态。零宽初始区间隔离此项调度检查；随机种子的原 JVM 证据仍由此前初始化验证负责。
- 核验暂停时零粒子更新且墨迹增加、角度清墨、变换重播、尺寸变化取消、恢复时钟与相机、过期事件拒绝。
- 核验动画颜色与显式热设置的区别、同名公式参数保留、构造／热更新点尺寸比例。
- 四组暂停截图组合覆盖普通／重播 × 同尺寸／改尺寸，同时检查容量拒绝和取消后的资源释放。
- 固定重建与原有固定回放逐项比较完整 RGBA 与累积纹理；这项属于本地两条路径的一致性，不冒充独立原版整图期望。
- 通过实际 Generator 和 Worker 连续生成 Map 帧，确认传输保留实时上下文和会话。Symmetry 的实时、Worker 队列及暂停截图回归也已通过。

源行为来自固定原 JAR 的 GenericMapAttractorScene、MapAttractorMobject 和公共宿主方法。证据与 PC 见本地 .cache/source-map-lifecycle/native-audit.md、live-session-review.md。没有运行原版窗口，也没有新增 Yomado 输入。

独立审查发现原运行设置事件的检查起初只覆盖颜色字段，已在共享字段契约中补齐整组设置，并增加实际 GPU 的无事件拒绝检查。

本次测试初次运行发现两处验证脚本输入问题：原相机初始角度不能假定为零，应使用已记录初态；单位测试导入 fixture 缺少必需的 name，已补齐。未因此改变产品行为。

最终完整检查：352 个测试文件、6,599 项测试通过；TypeScript 和 Web 构建通过。最后补齐 Map 运行设置事件检查后，再次运行完整测试和两个 Symmetry GPU 回归，均通过。

## 尚未完成

Map 的公开界面仍使用固定回放。下一步需要把界面事件、生成队列的播放暂停控制、Worker 输出绑定的截图能力接入共享核心，并验证真实编辑、保存重开及 PNG／MP4 流程。

迭代次数的原版热 setter 与明确 Apply 重建是两种操作。当前保存文档仍保留原构造校验，修改迭代次数按明确重建处理；尚未实现独立的热迭代次数事实。不会通过放宽构造校验来假装支持热更新。

仍需原生完整窗口、JOGL 驱动差异、MSAA／DITHER 和所有场景完整效果对照。已有 Apple Silicon 1.0 应用未重新打包或替换。
