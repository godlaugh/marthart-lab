## 原版挂起与清理

旧初始化实例的原版自带监测器记录 `EDT-HANG`，未发现 Java monitor 死锁环。线程记录显示 AppKit 的辅助功能焦点读取在等待 AWT，而 AWT 在等待 JOGL 创建原生窗口。它支持“跨线程等待”的判断，不能确定由哪个辅助功能客户端触发。

恢复后第一次在暂停状态跨屏，画布变黑；返回实体屏并重新绘制后恢复。第二次在持续绘制时跨屏成功，之后暂停截图也成功。因此，不能将第一次黑屏归结为虚拟屏普遍不支持该应用。

保存原版 PNG 后，应用再次记录 `EDT-HANG`：AWT 栈涉及 Skiko Metal 设备创建，AppKit 栈仍涉及辅助功能焦点等待。PNG 已经写入，但随后窗口不可读。Yomado 的“返回原显示器”明确报告应用不响应窗口查询，并保留位置记录。

保存第二次日志后，核对启动时间及可执行文件，结束本任务启动的挂起实例；受监督会话以 143 退出。Yomado 随后确认工作屏上不再有 MathArt 窗口。**窗口原位置恢复未验证；挂起进程已清理，专用虚拟屏保留为空屏。** 未关闭其它虚拟屏、修改系统防护或更改原应用二进制。
