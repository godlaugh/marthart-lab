# 隐式曲面 GPU 材质验收

在这台 Apple Silicon Mac 上，MathArt Lab 已接入原版隐式曲面的 GPU 材质。默认材质、四种程序纹理和一组光照参数共 **六种状态**，各自的 500×600 完整数学画面与原版逐字节相同，差异像素为 **0**。结果包括填充和原版切片线框，不把原版品牌水印纳入产品画面对照。

这里的 GPU 指材质绘制。网格仍由源 CPU Marching Cubes 生成，实际计算回执明确为 CPU；本机原版也因缺少 OpenGL Compute 能力而回退到 CPU。这项验收没有证明原生 Compute 计算成功。

## 已对齐的画面

参考为 MathArt 1.7.8 自带 `implicit_sphere.json`，实际方程是 `x²+y²−z²−1`。保留 60×60×60 采样、90,120 个顶点、相机、配色和 0.9 填充透明度，仅选择 GPU 模式；材质变体通过原版正常公开入口更新。

| 状态 | 完整数学画面差异像素 | 填充单独对照 |
|---|---:|---|
| 默认材质 | 0 | 一致 |
| 棋盘格 | 0 | 一致 |
| 拉丝金属 | 0 | 一致 |
| 陶瓷 | 0 | 一致 |
| 碳纤维 | 0 | 一致 |
| 光泽 64、环境色 `#204060`、高光色 `#E0A080` | 0 | 一致 |

每个状态比较全部 1,200,000 个 RGBA 字节，没有遮罩或容差。顶点、法线、24 项有效 shader 参数和调色板纹理也分别核对。产品从同一原始配置和事先确定的材质命令独立生成，不使用原版截获的顶点或像素作为绘制输入。

离屏 GPU 材质使用原版逻辑尺寸：500×600 输出、2 倍像素密度对应 250×300 的相机和线条视口。CPU 已有的物理尺寸处理保持不变。原版切片线框共用已有实现，既不改成三角形边线，也不重复乘像素密度。

## 使用和保存

导入源隐式网格后，绘制选项区分原版 CPU 绘制和 GPU 材质；一般本地场景仍保留原来的采样方式。编辑场景会先暂存，点击“应用场景”后重置动画。热调色板与已应用的运行状态保持独立。

源 JSON 中未被原版读取的通用材质字段不会被伪装成有效的原版配置。原版冷启动材质默认值和本地显式材质编辑分别保存。空调色板也保留其真实空数组身份：CPU 使用白色填充回退，GPU 使用 `paletteSize=0` 分支。

## 本机应用流程

实际界面使用真实 Worker、原生绘图服务及 FFmpeg，完成以下流程：

| 功能 | 实际结果 |
|---|---|
| 保留状态录制 | 1 张预热帧后保存 4 张不同画面，128×96、4 fps 的 MP4 正常生成 |
| 视频交付 | 原生 RGBA 与上传 PNG 对应；所有解码 RGB 与独立原始帧输入的 FFmpeg 编码一致，交换帧或重复首帧会被检查拒绝 |
| 录制后继续播放 | 沿原实例继续；暂停、改变窗口大小及恢复播放不丢失进度 |
| 暂停 PNG | 65×49 请求按原规则得到 66×50；重复截图相同；3 倍放大正常 |
| 取消截图 | 不生成新下载；再次保存恢复相同画面 |
| JPEG | 从初始状态重放，实际消费原生数学帧，64×48 JPEG 可正常解码 |
| 取消录制 | 删除编码会话、不留下半成品；再次录制成功 |
| 暂存与应用 | 修改时长保持运行配置；点击“应用场景”后递增应用和重置版本，回到时间 0 |

这部分验证的是产品实际操作和交付链；有损 JPEG/MP4 没有被宣称与原版文件逐字节相同。测试用的录制场景为 12×12×12 网格，与上方 60×60×60 原版整图对照分别记账。

最终 Apple Silicon 应用包 `2.0.0-preview.16` 也单独通过隐藏运行检查：实际导入原 60×60×60 GPU 配置，完成 90,120 个顶点、原生预览、一个源公式及 500×600 PNG 下载。下载内容与包内编码 Worker 的实际结果一致。启动和保存状态后的重开另行通过；退出后无残留自有进程，监听端口全部关闭，可见窗口和显示事件均为零。应用仍位于 `dist-desktop-v2/MathArt Lab 2 Preview-darwin-arm64/MathArt Lab 2 Preview.app`。

## 尚未闭合的范围

原版每次网格变脏后都会重新尝试 GPU 计算。失败退出时，`PApplet.endPGL()` 会恢复 primary 的视口，导致当次离屏绘制从 500×600 变成 810×972；下一个没有网格重建的暂停帧恢复正常。这一行为已在默认及五个热材质状态中实际观察到。本页的零差异结论只覆盖后者的稳定帧，**首次或参数更新触发的网格重建尚未对齐**。

因此，GPU 稳定材质验证不能直接推成所有参数动画的原版逐帧一致性，`MAS-IMP-023`、M3 和总 Goal 仍不应整体标记完成。原版 PREVIEW 粒子算法及其它设备上的 Compute 路径也不在本页结论内。用户目前只有这一台 Mac，跨设备保留为未验证。

## 证据说明

原版 JAR 摘要为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。所有原版采集使用正常授权和访问策略，未修改 JAR、许可、设置或品牌。原版的 Compute 异常如实保留。原版和产品绘图均无可见窗口，采集后自有进程为零。

原版参考位于 `.cache/source-implicit-gpu-reference-20261027/` 和 `.cache/source-implicit-hot-material-20261027/`；产品独立比较位于 `.cache/source-implicit-gpu-material-20261027/`。首次产品比较在相机参数检查中发现物理尺寸与逻辑尺寸混用，未进入 GPU 绘图；该失败记录保留。修正后的默认及五项材质比较全部通过。

可复查的精简索引见 [验收 fixture](../tests/fixtures/source-implicit-gpu-material/20261027.json)。最终改动涉及的 17 个测试文件共 **195 项通过**，全仓类型检查和 Apple Silicon `2.0.0-preview.16` 构建通过。较早的界面验证器仍按“编辑立即生效”及“暂停一定产生新生成帧”判断，已按实际暂存/Apply 和暂停回执修正；失败报告保留，最终完整界面流程通过。

五项原版热材质采集共 11.477 秒，观察到的进程族峰值 RSS 约 597 MiB；产品各次直接比较约数秒，包含编译与观察。它们是验收成本，不是普通使用性能；未做等价冷暖性能或 GPU 时间基准。

最终两组界面流程墙钟 19.05 秒，抽样进程族 CPU 45.53 秒、峰值 RSS 约 2.57 GiB，包含浏览器、开发服务、观察器和编码器。没有采样错误，退出后服务自有进程为零；这些数字不能代表日常运行占用。本轮 agent token 未独立计量。
