# Symmetry 实时会话、Worker 与播放队列验收

2026-10-21。Symmetry 的动画队列、粒子、累积图像、宿主时钟和相机锚点已由同一个实时会话管理，并接通真实 Worker 及 GenerationQueue。暂停与恢复通过独立消息处理，不额外演算或显示一帧。

**当前完成的是后台与播放队列接入。App 的按钮、编辑事件和暂停期间的连续重播调度尚未启用这条路径；原版整窗口验收仍为 0/11。** 已安装的 1.0 Apple Silicon 应用没有重新打包或替换。本轮使用后台 Chrome/WebGL，没有进行原版窗口操作。

## 行为变化

- 实时播放保留队列、粒子、累计图像和相机锚点；队列未结束时保留两次有序数学调用，结束后保留一次调用。每次调用使用自己的参数快照。
- 调色板和六轴变换编辑使用显式重播序号。即使值相同，新编辑事件也触发重播；遗漏事件或倒退序号会拒绝，保留已接受状态。时间线参数更新不伪装成用户编辑。
- 用户修改数学参数会重新构造场景；色调、迭代数等已知热设置保留实例。场景构造身份与完整呈现身份分开，重命名可以复用完成图像，但色彩或相机改变不能被误当作元数据。
- 暂停等待正在生成的帧完成；随后控制准确的完成结果。恢复重置宿主时间基准并恢复暂停前角度，不补算暂停时长。旧结果和错误场景类型不能控制新会话。
- 重播时跳过参数确认和相机捕获；画布变尺寸时保留粒子、取消重播，再正常确认参数和相机。
- 宿主 renderFps 只影响下一次重播预算，与固定时间线 fps 分开。
- 显式 startAt 从新实例逐帧重建数学与图像，再进入实时模式。它是本地重建功能，不表示原版有任意时间跳转操作；重建受工作预算与取消约束。

Samila 与 Symmetry 共用 SourceSceneHostClock，移除了旧的 Samila 专属时钟表示。相机呈现现在接受有限的负时间，修复系统时钟回拨时误用固定跳转范围的问题；固定跳转仍在时间线请求入口限制为 0–86400 秒。

## 实际验证

| 验证 | 结果 |
|---|---|
| 有序数学更新 | 注入 4 个宿主时间，调用数量为 2、2、2、1；独立 Float32 粒子递推逐项完全相等 |
| 暂停与恢复 | 控制操作不增加显示/数学次数；暂停时间未进入恢复后的 dt，角度恢复正确 |
| 编辑重播 | 重置种子、普通更新先于重播、相同值的重复事件、宿主帧率变化均通过 |
| 尺寸变化 | 重播中修改相机后调整尺寸，取消重播并恢复参数/相机确认 |
| 负时间 | 实时宿主 1000→500 毫秒，rawDt 和相机呈现时间保留 -0.5 秒 |
| 无效请求 | 缺少显式事件、旧序号、未经过控制消息的暂停变化均拒绝，已接受状态不变 |
| 取消与恢复 | 中途取消逐帧重建，资源计数归零，下一次从新实例恢复 |
| 固定重建 | startAt=0.2 与独立固定步进所有者的完整像素和原始累积缓冲完全相等 |
| 真实 Generator/Worker | 暂停、恢复、过期输出拒绝、错误场景类型拒绝及编辑重播通过 |
| 真实 GenerationQueue/Worker | 等待进行中的帧再暂停；重命名复用同一完成结果；暂停编辑重播不推进普通数学 |
| 针对性测试 | 46 项通过，含两种场景的播放控制排序及取消/替换/卸载边界 |
| Samila 时钟回归 | 16 个既有真实后台验证案例通过 |
| 全量测试 | 339 个文件，6,234 项通过 |
| 网页构建 | TypeScript 与 Vite 通过；保留既有大 chunk 提示 |

新验证脚本为 `scripts/verify-source-symmetry-live.mjs`，要求全新输出目录：

```sh
node scripts/verify-source-symmetry-live.mjs .cache/source-symmetry-replay/live-new-run
```

最终报告在 `.cache/source-symmetry-replay/live-queue-final-gpu/report.json`。Samila 回归在 `live-samila-clock-regression/`；全量测试与构建日志为 `live-full-tests.log`、`live-build.log`。脚本验证源文件前后摘要未变，浏览器与 Vite 正常关闭。本地输出不提交 Git。

新增队列联测的第一次运行失败，是验证脚本在“图像已回调、当前请求 finally 尚未结束”之间立即请求暂停，却错误地假定第二帧已进入 Worker。修正脚本的事件循环顺序后通过；此前失败记录保留在 `live-final-gpu/report.json`。

## 证据范围与剩余工作

原版调度、编辑与尺寸变化语义沿用已保存的原始字节码和前轮 JVM 证据，见[调度验收](source-symmetry-dispatch-validation.zh-CN.md)、[尺寸变化验收](source-symmetry-resize-validation.zh-CN.md)与[宿主时钟验收](samila-realtime-clock-validation.zh-CN.md)。本轮没有新增原版 JOGL 或原版窗口运行证据。

本地真实 WebGL 和 Worker 通过，证明上述接线实际运行；不证明跨 GPU/JOGL 的完整图像一致，也不证明 App 的交互流程已经完成。下一步接入 App 的实时会话身份、显式编辑事件、播放按钮、暂停重播调度及本地跳转，并在后台浏览器验证真实界面。原版整窗口对照与 2.0 完整验收继续保留为未完成。
