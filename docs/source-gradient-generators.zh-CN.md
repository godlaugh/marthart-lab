# 曲面与吸引子：Cosine / Curve 色板生成器验收

2026-10-24。曲面和吸引子的原版场景已接入共用的 Cosine、RGB 曲线生成器，以及此前已验证的手动随机配色。当前仍处于 **M3：场景补全与一致性验证**；这是两个场景家族的色板增量，不代表整个 2.0 已完成。

## 怎么使用

打开源曲面或源吸引子作品，在「外观 → 渐变与色彩 → 调色板模式」选择 Cosine 或 RGB 曲线。

| 操作 | 实际行为 |
| --- | --- |
| 选择生成模式 | 立即更新作品，保存切换前的手动色板快照 |
| 颜色数量 | 2–25，Cosine 与 Curve 共用；导入长色板只限制新生成数量，不截断原快照 |
| Cosine | 独立编辑 RGB 的 A/B/C/D；A/B/D 的界面范围 0–1，C 为 0.5–3 |
| Curve | 三条 RGB 分段直线；可添加、拖动、键盘微调或删除节点 |
| 随机生成参数 | 立即生成并应用，保留颜色数量 |
| 切回手动 | 恢复之前的完整色板，包括 alpha、原文和超过 25 色的尾部 |
| 应用为手动色板 | 将当前结果保留为手动颜色；之后切换恢复的是这份新色板 |
| 保存、重新打开 | 保存最终颜色；重新进入手动模式，生成参数恢复默认 |

手动模式还提供单色、类似色、互补色、分裂互补色四种随机配色。手动随机设置仅为草稿，点击「生成并替换色板」才替换颜色。

原版 Curve 使用 Float32 **分段线性插值**，不能复用旧本地曲线的 PCHIP。节点可有相同 x；移动或删除边界点后，缺失的端点以最近颜色补齐。界面使用数值输入和键盘扩展，本批没有宣称与原窗口布局或手势完全相同。

## 原版依据

MathArt 1.7.8，JAR SHA-256：`a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。直接执行公开 `GradientPaletteSupportKt` 纯方法，使用现有 Temurin 21.0.7、无头 JVM；未启动原版 GUI，也未初始化 ProjectState、许可或渲染器。

**61 个原版案例全部对上**：21 Cosine、22 Curve、10 安全振幅上界、5 随机 Cosine、3 随机 Curve。其中包含 5 个预期 null-list 构造错误、3 个预期 maxStops<2 错误。状态按 Float32 位模式比较，生成颜色逐字符串比较；保留的节点 ID 逐字比较，新 UUID 验证新建关系。

8 个随机案例通过公开 API 传入独立 Random，共观察 206 次 nextBits。候选重放实际的上层随机返回值，并核对范围、调用顺序及消费数量；没有修改全局随机源或原 JAR。产品默认随机数来自浏览器，不能把两个独立运行结果称为同一个随机作品。

浮点边界包含有符号零、重复节点、缺失端点、短向量、空曲线、半整数舍入及随机上界。Curve 端点处理后必须再次稳定排序；普通 B 参数不受随机生成时的安全振幅上界限制。

模式切换、立即应用、手动快照和项目字段依据来自完整字节码。原版只有 Fractal 写出这组生成器参数；Surface、Attractor 保存最终色板。因此本批采用局部界面状态，复用既有颜色解析和保存所有者，没有新增项目字段。此项为静态依据加本地运行验证，不是原版窗口保存重开实测。

## 实际产品验证

无头 Chrome 操作真实 App，曲面 CPU 网格、GPU 网格及吸引子 CPU/GPU 四个配置均覆盖。WebGL 配置和原生配置各 **96 项通过**，均核对实际呈现方式。**原生配置中曲面走 CGL，吸引子仍走既有 WebGL 路径**，不把后者写成原生验证。

验证包含即时颜色变化、共享数量、随机参数、Curve 添加/实际指针拖动/键盘/删除、32 项原文色板恢复、烘焙、保存重开、项目 JSON 下载和 PNG 下载。生成器默认线性九色色板在页面逐项核对；实际画布像素随颜色变化。

曲面 PNG 通过当前暂停画面捕获、增强再编码，与实际返回并增强的 RGBA 逐字节一致；GPU 吸引子 PNG 与其交付光栅 RGBA 一致。CPU 吸引子验证导出尺寸、可见像素及正确色板输入，本批不新增其 PNG 逐像素一致性结论。所有四个配置均保留其余源配置。

边界补验 **29 项通过**，覆盖单色色板、吸引子「未指定」与「空色板」的区别，以及手动随机组件回调；报告为 `.cache/common-gradient-edges-20261024-reviewed/report.json`。曲面源网格要求已有非空色板，不为此放宽文档格式。完整流程后仅补齐手动随机组件的选择回调，29 项增量复验确认：整套生成选中第一色，随机主色保留当前选择；其余生成算法未改。

相关七个测试文件 **276 项通过**；`build:v2`（含 TypeScript）及中英文审计通过，无必须翻译项缺失。构建仍有既有的大文件体积提示。完整页面运行结束后没有所属辅助进程残留，源文件在各次运行期间保持不变。
