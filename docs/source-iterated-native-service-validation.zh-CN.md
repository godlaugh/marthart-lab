# 原生迭代绘制：正式服务链路验收

2026-10-25。**浏览器客户端 → HTTP 连接 → 原生服务 → GPU 成图已跑通；同一原版场景的连续 8 帧全部像素一致。M3 仍在进行中。** 这次使用应用已有的客户端、连接租约、进程服务和会话调度；场景后端由验证脚本注入，应用默认后端选择尚未接入。

## 本轮实现

- 增加原生绘制协议，支持累积图像的创建、绘制、呈现与独立释放。计算状态和累积图像有各自的身份与计数。
- 图像呈现绑定最后一次绘制的检查点。之后即使粒子继续推进，旧累积图像仍能正确呈现。
- 同一粒子状态可以拥有两份独立累积图像；仍有图像依赖时拒绝释放粒子状态。清理失败会保留所有权，涉及原生运行错误时等待实际子进程退役后再清理服务登记。
- 新版推进支持单独清零错误计数，保留旧版计算协议的行为。真实测试覆盖非有限状态、零步重置、停止记录、交错通用绘图和故障恢复。
- 非法绘制参数现在在懒分配粒子纹理视图前被拒绝。客户端把 `null`、数组和标量形式的错误响应归为协议错误，并释放请求占用。

严格 clang 编译、TypeScript 检查及 `build:v2` 通过；构建仍有既有的大包体积提示。首次完整浏览器验证暴露了验证脚本的代理来源配置和结果接收路由错误，修正后通过，失败记录保留。一次生命周期测试也修正了跨进程身份断言：新子进程的内部 context 序号可重新从 1 开始，须以服务 session 身份区分。

## 测量范围

完整验证耗时 7.675 秒，子进程 CPU 合计 22.273 秒，采样峰值进程组 RSS 1,119,392 KiB。首次建立资源的帧耗时 2.166 秒，随后 7 帧为 0.304–0.320 秒；这些时间包含 HTTP 图像传输和参考比较，不代表界面帧率。

已计费保留资源为 88,012,257 字节，约 83.94 MiB，并非实际显存。该验证没有每帧读回全部粒子或浮点累积。总耗时包含编译、Vite、Chrome、原生子进程及关闭；CPU 包含采样开销，0.5 秒采样可能漏过短峰值。新进程和新资源已区分，但驱动缓存冷暖、实际显存、功耗、agent token 成本未测；未完成与混合 WebGL 路径的同负载性能比较。
