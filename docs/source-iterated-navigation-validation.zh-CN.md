# Map／Symmetry 暂停视口操作验收

2026-10-21。Map 2D 已支持暂停拖动平移；Map 3D 和 Symmetry 已支持暂停拖动旋转。三者均可滚轮缩放。恢复播放时还原进入暂停前的旋转角度，保留平移与缩放。操作保留当前粒子、动画相位和最后应用的录制配置，不通过重新应用文档来模拟导航。

这是 2.0 M3 的一项完成进展。原版完整窗口效果验收仍为 **0/11**，Goal 未完成。已安装的 Apple Silicon 1.0 应用未重新打包。

## 原版证据

原 MathArt 1.7.8 JAR SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。重新核对 7 个类的字节身份，方法与指令位置记录于 `.cache/source-map-lifecycle/viewport-navigation-audit.md`。

通过 JNI 构造最小对象，直接调用原包的 `mousePressed`、`mouseDragged`、`mouseWheel`、`togglePause` 和 Map 拖动方法，执行了 12 组案例。其中 10 组数值案例的 7 个 Float32 通道与本地实现逐位相同；另 2 组原方法样本确认运行中和拾取模式不导航、不要求 redraw。没有用本地公式生成期望值，也没有启动原版窗口、构造器、主程序或绘制线程。

原始样本与未修改的执行器源码保存在 `tests/fixtures/source-viewport/`；完整运行清单、标准输出、类哈希和实现复核保留在 `.cache/source-map-lifecycle/viewport/` 及 `viewport-navigation-implementation-review.md`。这些数值结果不能替代原版窗口像素验收。

## 状态归属与操作规则

- 视口写入实时相机，不修改作品文档。暂停前的角度仍由原有宿主时钟保存和恢复。
- 缩放同时写入持有缩放动画的时钟，避免恢复播放时被旧值覆盖；正在执行的动画保留原起点，尚未开始的下一段动画才捕获新值。后续动画可以覆盖手动导航结果。
- 暂停操作会重新绘制已有粒子，但不推进粒子运动。Map 角度／平移变化超过原阈值时先清空累积再绘制；Symmetry 仅旋转时保留累积。两者缩放遵循既有相机变化检测。
- Worker 控制必须引用当前完成的主预览；每次返回新的完成帧身份。错误身份、尺寸、像素数据、时间或会话响应会使不可靠的 Worker 失效。
- 同一手势按事件顺序提交；播放、尺寸变化、作品编辑与取消通过同一队列串行处理或终止旧手势。新产生的画面经实际 Viewport 呈现。

浏览器输入是明确的本地适配：逻辑 CSS 像素决定拖动距离，DPR 不放大拖动量；滚轮一行映射一个 count，像素模式每 16px 映射一个 count，保留分数。原版 Processing 收到整数 count，不能据此宣称各操作系统触控板手感完全相同。

另设置最多 8 个待执行重绘任务的本地背压预算，外加 1 个执行中任务。超量输入被拒绝，拖动手势结束，已接受事件保持顺序，不合并 delta。原版没有由本轮证据证明的“8 个事件”限制。审查最初发现队列无上限；修复后提交 10,001 次输入只接受 9 次，其余 9,992 次被拒绝，处理后 owner 与 busy 均正常释放。

## 实际验证

- `navigation-gpu-final3/report.json`：实际 WebGL／Worker 的 Map 2D、Map 3D、Symmetry 共 3 案例。比较完整粒子缓冲区，验证拖动／滚轮不重新初始化或推进数学时间，检查暂停重绘与累积清空规则、原地恢复、PNG 捕获保留视角、非法事件无副作用，以及录制仍恢复最后应用的相机。
- `navigation-ui-final/report.json`：实际 App 界面共 3 案例，覆盖 DPR 1／2、右键分步拖动、像素／行滚轮、事件顺序、画面交付、恢复播放、运行中拒绝导航。截图位于同目录。此处使用小粒子数控制流程样本，不作为作品视觉质量样本。
- 新增 12 项数值／动画语义测试、6 项队列容量与并发测试、20 项客户端完成帧／损坏响应测试。完整回归为 **355 个文件、6695 项测试通过**，Web 构建通过。

一次补充 GPU 断言错误地将“清空累积”理解成“最终缓冲区全零”，未计入随后的已有粒子重绘，测试因此失败。核对原显示路径后，改为验证清空事件、累积轮数与零数学步进，最终通过；没有修改产品来迎合错误断言。失败记录保留在 `navigation-gpu-final2/`。

上述运行报告统一位于 `.cache/source-map-lifecycle/`。原版完整窗口仍未验证，本轮没有操作用户主屏或重新检查 Mac 锁定状态。结构与相机字段的 Apply 暂存、完整控件事件细节和 11 个场景的整图对照仍待推进；高分辨率、大粒子数与长期交互性能未建立结论。

参数热更新实际 GPU／Worker 回归 4 案例、录制 Worker 34 个时钟案例和 8 个队列案例均通过，分别记录于 `navigation-parameter-regression/` 和 `navigation-recording-regression/`。
