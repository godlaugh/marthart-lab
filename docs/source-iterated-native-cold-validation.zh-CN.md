# Map / Symmetry 原生冷重放与桌面导出验收

2026-10-26。**Map 和内建 Symmetry 的“从初始状态重放”已接入原生 CGL，独立桌面预览版更新为 `2.0.0-preview.3`。M3 仍在进行，全部 11 类场景的最终验收尚未完成。**

## 改变的行为

原来实时预览使用原生渲染，但从头重建仍交给 Worker/WebGL。现在完整源模型的冷重放使用独立原生资源；固定帧率、初始粒子、预热、两次有序参数更新、清空历史、相机锚点和最终调色仍由原来的重放逻辑统一管理。

异步接口区分 Samila 与 Map/Symmetry 所需的输入，不再要求后两者伪装成 Samila 相机或采样。输入在第一个异步等待前复制，调用方后续修改不会影响正在执行的重放。累计工作预算使用原生前缀计算的实际求值量；超预算帧在提交前拒绝。

取消会等待当前操作确认，再释放本次重放资源。清理失败保留所有权并拒绝替换；不取消共享渲染进程，不自动重试结果未知的绘制，也不把冷帧当作实时预览使用。

## 实际桌面操作

验收使用打包后的应用、隐藏窗口及独立测试用户目录。没有占用主屏幕或移动用户窗口。

Business Cycle 和 Emperor’s Cloak 均通过：

- 导入、热改参数、播放和暂停；原生计算资源保持连续。
- 当前暂停画面导出 160 × 120 PNG，与原生像素经源图像增强后的结果相同。
- 切换到“从初始状态重放”，连续导出两张 PNG。两次使用独立计算资源，PNG 与原生输出逐字节相同，两次导出的像素也相同。
- 关闭导出后继续播放，主预览仍使用原来的计算资源。
- 重启应用，工作区、场景和已编辑参数恢复。

两个应用进程组退出码均为 0，进程组为空，服务端口关闭。运行前后应用归档和原生 helper 哈希不变。深度严格代码签名验证通过；这是本地 ad hoc 签名预览包。

## 检查与测量

最终通过 **161 项不同的 Vitest 检查、39 项桌面检查、TypeScript 检查及 2.0 桌面构建**。冷重放测试包括动画中两次不同参数更新、固定种子、倒退、尺寸变化、延迟起点、停止记录、输入隔离、累计预算、取消与清理失败。CPU recorder 只证明调度和所有权；画面结论来自上述实际原生运行。构建仍有既有 Vite 大 chunk 提示。

桌面流程耗时 16.302 秒，监督器记录 CPU 25.687 秒；实际 Electron 进程组采样 RSS 峰值为 1140.5 MiB，重启组为 544.6 MiB，驱动组单独为 366.4 MiB，分别采样的峰值不能相加。采样间隔 0.5 秒可能漏掉瞬时峰值；GPU 显存、能耗和温度未测。工具计量窗口内 Goal token 增量为 120,370，时间增量 663 秒，未包含随后报告与提交收尾；没有等价旧流程 token 基线。
