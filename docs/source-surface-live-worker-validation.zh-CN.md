# 曲面实时 Worker 与渲染验证（2026-10-22）

曲面的 **Generator → Worker → 保留场景 → ArtRenderer** 链路已接通。CPU/GPU 点、网格以及 CPU 点→网格→点切换，都通过了真实浏览器验证。**App 尚未自动启用这条链路；参数热编辑、当前帧 PNG、录制和原版整窗对照仍待完成。整窗验收仍为 0/11。**

## 本轮实现

同一会话保留曲面对象、参数动画、相机绑定和队列；后续帧消费独立时间及观测 FPS，不从头重建全部历史。暂停／恢复使用独立操作，暂停重绘不推进队列，恢复不累计暂停期间的墙钟时间。

当前帧操作重新交付独立缓冲区，解决 Worker 传输会分离旧缓冲区的问题。它只重绘当前状态，不执行新的场景更新。旧输出、错误会话或错误响应不能继续控制当前场景；中途失败的对象必须重建。

固定回放与实时展示共用同一个几何输出函数。工作预算由实际操作拥有：固定回放的一次完整重建共用 2000 万工作单位，实时请求各自共用同样上限；模式替换和子对象不会绕过它。拖尾原有内存上限继续保留。连续 401 次更新可以正常完成，超大单次重建仍明确拒绝。

显式新 revision 会替换本地会话配置；相同 revision 的草稿修改不会进入正在显示的曲面。此处验证的是本地配置版本边界，**不代表原版工具栏的热编辑／Apply 行为已全部复刻**。显式 seek 仍是本地固定重建，不声明为原版操作。

## 实际验证

真实无头 Chrome 使用未替换的 Generator、Worker 和 ArtRenderer，覆盖以下五组：

| 场景 | 已验证 |
| --- | --- |
| CPU 点 | 参数改变像素、暂停、恢复、重复获取当前帧 |
| CPU 网格 | 相同流程，含传输后重新交付网格缓冲区 |
| CPU 点→网格→点 | 同一会话内替换对象，遮罩与绘制拓扑按顺序变化 |
| GPU 点 | 实际着色器绘制、暂停像素稳定、恢复可见变化 |
| GPU 网格 | 实际着色器绘制和重复显示，未回退到 CPU |

五组均验证了旧画面控制被拒绝、无效 FPS 被拒绝、配置版本捕获、Worker 失败后重新创建并恢复初始像素。浏览器无页面错误，运行前后源文件摘要一致。此轮没有操作用户桌面，也没有运行原版 JVM/JOGL 窗口；本地像素稳定不等于原版整窗像素一致。

检查结果：

- 针对性 76 项测试通过，新增 24 项会话和传输测试。
- 首次全量：406 个文件、7,637 项中 7,620 项通过，17 项出现超时栈；当时构建与测试并行且本机负载较高。
- 在不改生产代码、不增加超时阈值的情况下，将失败文件及最终传输测试以 2 个 worker 重跑：13 个文件、265 项全部通过。
- 以每个文件最新结果合并，7,637 项全部通过。**这不是一次全量运行全部通过**；原始失败记录保留。
- 最终 TypeScript 与生产构建通过，保留已有大包体提示。

## 等价任务与开销

与提交 `c5cba41` 比较，使用 32×24 采样、32 个请求：原流程每次固定重建，新流程保留对象，并以相同 0.25 秒步长及 FPS 4 更新。四类任务均运行三个独立对象，全部几何、GPU 数据及相机／队列事实一致。摘要排除了耗时、提示文本、新会话元数据，以及“请求时间”与“实际场景时间”的标签差别；GPU 着色器的时间参数仍参与比较。

| 任务 | 原流程首／热运行耗时 ms | 保留会话首／热运行耗时 ms |
| --- | --- | --- |
| CPU 点 | 104.14／83.80／76.27 | 26.48／17.97／9.31 |
| CPU 网格 | 370.03／311.13／308.74 | 52.67／37.23／29.42 |
| GPU 点数据 | 38.89／25.68／12.38 | 22.39／7.53／6.04 |
| GPU 网格数据 | 82.60／43.70／38.35 | 27.17／11.25／12.37 |

这项比较包含导入、32 次完整数据交付和摘要，首任务计时开始于模块加载之后，不是 App 冷启动。逐任务 CPU 时间和累计峰值 RSS 保存在原记录中。完整比较任务墙钟 5.51 秒、采样进程族 CPU 6.90 秒、峰值聚合 RSS 342.0 MiB，未观测到所属遗留进程。

真实浏览器五组验证共 5.32 秒，采样进程族 CPU 16.24 秒、峰值聚合 RSS 1.75 GiB，未观测到所属遗留进程。单个 Worker 首次请求约 273–333ms，后续保留会话请求约 0.9–1.3ms；这些单次观测不构成完整 App 性能承诺。50ms 采样会漏掉短进程和峰值，共享内存可能重复计数；token、显存和原版应用开销未测量。
