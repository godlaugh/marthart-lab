# 弹跳方向控件：使用度，保留原始精度

2026-10-24。初始方向与方向散布现在以“度”显示和编辑，项目文件及模拟继续存储弧度。方向散布按原版限制在 0–360 度；输入无效时保留草稿并显示错误，不改动有效配置。

原版 `BouncingParticlesSectionKt` 的字节码表明，这两个控件在显示与提交时转换单位；方向散布在提交时限制范围。本次另用原版随包 JVM 运行两个纯转换方法，取得 36 个 Float32 位级结果，覆盖正负零、常用角度、负数和极值。产品转换全部匹配这些结果。探针没有创建场景、窗口或请求读取应用数据；这项数值证据不代替原版窗口交互验收。

转换不能保证往返无损。例如原始值 `2.345599889755249` 弧度显示为 `134.39297485351562` 度，再转回会变成 `2.345600128173828` 弧度。因此，只聚焦再离开输入框，或输入相同的有效角度，不再重新写入配置或重置模拟。该处理位于控件的单位转换边界，未改动保存格式。

实际 App 在无窗口 Chrome 中连接原生 CGL 与 FFmpeg，177 项检查通过，其中包含单位标签、45 度提交、450 度散布限制、无改动精度保留、无效草稿、PNG/MP4 导出及资源清理。控件、时钟、导出与语言回归共 44 项通过，另有 39 项导出服务检查通过。构建及语言目录审计通过。
