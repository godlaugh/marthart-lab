# 弹跳验证耗时排查（2026-10-24）

**同一组 62 帧严格对照，从约 123.5 秒缩短到 11.2～12.4 秒，完整画面仍全部零差异。** 本轮修改的是验证工具，尚未接通产品弹跳预览，也没有提高产品帧率的结论。

## 改了什么

新增仅启用 Runtime、Page 的无窗口 Chrome CDP 驱动，不启用 Network，不接收或解码每帧约 32 MB 的请求体事件。验证默认进入专用空白页，仍加载真实产品种子生成、GPU 模拟、原生客户端与 HTTP/CGL 服务。没有替换渲染、缩小粒子数量或跳过像素／状态比较。

原来的 Playwright 驱动和应用首页入口保留为显式对照选项。端口必须精确匹配服务允许的来源；端口被占用时直接报告错误。

驱动只管理自己启动的 Chrome，使用独立临时配置目录；启动、导航、评估和关闭均有期限。退出时先请求关闭，必要时通过持有的 ChildProcess 终止，等待退出后才移除配置目录。真实浏览器测试覆盖导航、HTTP 读取、运行时异常后继续使用、关闭时拒绝未完成评估，以及重复清理。

## 实测结果

同机、同版 Chrome 155.0.8059.85、同一 CGL 可执行文件和原版参考，串行执行。每轮启动新的浏览器与原生服务。所有原生轮次均为 200 万粒子、60 次更新、62 张完整 500×600 画面和 11 个完整状态纹理。

| 驱动与页面 | 整套墙钟 | 观测进程族 CPU | 采样峰值 RSS | 严格原生对照 |
| --- | ---: | ---: | ---: | --- |
| Playwright，空白页 | 123.50 秒 | 185.16 秒 | 3.82 GiB | 62/62 通过 |
| CDP，空白页，首轮 | 12.35 秒 | 19.53 秒 | 3.08 GiB | 62/62 通过 |
| CDP，空白页，复跑 | 11.16 秒 | 19.45 秒 | 2.56 GiB | 62/62 通过 |
| CDP，应用首页 | 12.43 秒 | 22.26 秒 | 2.97 GiB | 62/62 通过 |

原生轮次的 RGB、完成帧 alpha、相机和 88,097,900 个状态浮点分量全部相同。每轮源码摘要稳定，浏览器／服务关闭成功，受管原生进程剩余数为零。

作为反例，默认 WebGL 在新驱动下耗时 6.23 秒，仍以退出码 1 报告原有四处绿色通道差异：更新 6、21、36、51，各一个像素；58/62 帧完全一致。这验证了新工具没有把已知失败变成通过。

## 能确认什么

在这组实际工作流中，替换自动化驱动显著减少了验证开销；加载应用首页并不能解释原来的百秒级耗时。Playwright 的当前实现确实启用 Network，并解码请求事件的 Base64 正文。这支持请求观察增加成本的判断，但两种驱动的启动参数和上下文设置也不同，**不能把全部差额归因于某一条 Network 命令**。

CPU 和 RSS 每 250 ms 采样，可能漏掉短进程或短暂峰值；RSS 包含浏览器、Node、原生服务和采样器。这里只测了串行新进程运行，系统／驱动缓存未受控，不宣称严格冷、暖基准。GPU 独立时间及 token 成本未测量。

## 产品通路仍有多少开销

CDP 空白页复跑增加了浏览器侧分段墙钟计时：

| 62 帧累计阶段 | 时间 |
| --- | ---: |
| 提交模拟更新 | 0.010 秒 |
| 构造原生快照（含状态读回） | 0.761 秒 |
| 11 次完整状态比对与参考读取 | 1.606 秒 |
| 原生客户端调用（编码、HTTP、CGL、读回、翻转） | 5.016 秒 |
| 艺术画面／最终 PNG／相机比较 | 1.007 秒 |

这些阶段不含全部初始化与服务清理，因此不能相加代替整套墙钟。模拟更新计时可能只是异步 GPU 提交，等待会落在后续读回中；原生请求计时也不能当作纯 CGL 时间。原生调用中位数约 78 ms，仍不足以据此承诺流畅实时播放。

62 帧仍读回约 1.99 GB 状态，500 万粒子的完整快照仍被当前表示预算拒绝。下一步继续解决状态的持续持有与传输，再接入实际预览、截图、录像及取消／恢复验证。本轮没有修改产品运行时或已安装应用。

## 复跑

```sh
MATHART_SOURCE_RENDERER_BACKEND="$PWD/.cache/bouncing-cgl-20261024/backend.json" \
node scripts/verify-source-bouncing-native-animation.mjs \
  .cache/bouncing-native-animation-20261024/residual-states/native-bouncing \

```

默认使用 CDP 空白页。设置 `MATHART_VERIFY_DRIVER=playwright` 可复跑旧驱动，设置 `MATHART_VERIFY_PAGE=app` 可加载应用首页。省略原生后端变量则运行仍应失败的默认 WebGL 对照。
