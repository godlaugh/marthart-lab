# Map 实时界面与暂停截图验收

2026-10-21。Map 的公开编辑器已接入共享实时会话；播放、暂停、继续、变换重播、迭代次数热更新和暂停 PNG 截图通过实际浏览器界面验证。Map 与 Symmetry 的保存重开、PNG／MP4 导出均通过。**2.0 仍处于 M3；原版完整窗口对照为 0/11，不能据此认定原版效果完全一致。**

## 本轮改变

Map 的界面、生成队列和 Worker 使用同一个已完成主预览作为播放控制与截图依据。暂停等待正在生成的画面结束；恢复时排除暂停时长。过期输出、错误场景类型、复制出来的输出对象以及取消后的旧响应不能取得实时控制权。预检拒绝只有在 Worker 明确确认时才保留原预览；不确定状态退出当前后台会话。

Map 与 Symmetry 共用公开截图入口、事件调度和界面验证脚本，删除旧的两份 Symmetry 专属 UI 脚本。不同场景的颜色、背景、采样和截图事实仍各自保留。

迭代次数只修改源配置中的该字段，保留原始公式、参数顺序与随机种子，不经过整份配置的 Apply 规范化。配置所有者只判断一次构造输入是否改变，避免热编辑与重建路径各自维护一套判断。实际 GPU 验证确认：暂停编辑不改变现有粒子或时间；恢复后的下一次更新按新的三次迭代运行，没有重复预热。

原版通用点尺寸检查器没有调用 Map 的热 setter。本地界面对此采用重新生成，保存值 0.5 仍按构造值 0.5 显示；核心独立保留原 Map 热 setter 的钳制语义，但界面不假称绑定了该原版入口。背景修改也重新应用配置。

## 原版证据与剩余差异

原始包为 MathArt Studio 1.7.8，JAR SHA-256 为 a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018。原检查器事件映射来自固定包的回调与工作流反编译，属于静态证据；本地记录为 .cache/source-map-lifecycle/inspector-events.md。

原版迭代次数检查器走实时运行设置；背景直接应用；结构配置和相机角度有暂存至 Apply 的分支；参数值更新有热更新入口。目前本地参数编辑仍重新生成，结构编辑仍立即应用，相机角度沿用本地实时角度编辑与恢复。原版暂停视口滚轮／拖动的 zoom／center 行为也尚未完整接通。因此本报告不声称检查器事件时机完全一致。

MP4 仍按固定时间从初态逐帧生成；本轮未实现原版保留实时画布的录制生命周期。原版 JOGL、MSAA／DITHER 与整窗截图对照仍待完成。已有 Apple Silicon 1.0 应用未重新打包或替换。
