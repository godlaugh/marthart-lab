固定原版 JAR 和已验证的宿主运行应用自带 JVM 21.0.7。使用原版 JSON 配置构造器、BouncingParticlesMobject 构造器和 `uploadInitialState` 方法；原来的采样、拒绝循环、速度计算、随机调用次序及 Float32 数组写入均由原版执行。

诊断只在最后的 GL 上传边界截取完整 FloatBuffer，不执行 GPU 命令。只接受原方法的两次纹理绑定和一次上传，检查目标、尺寸、格式、数组长度及调用次数。这证明数值生产端一致，**不是 GPU 渲染、场景生命周期或原版窗口一致性证据**。
