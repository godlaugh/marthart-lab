# Samila 原生冷导出验收

2026-10-24：Samila 的独立 PNG／视频导出已接通原生渲染。实际界面验收 **7/7 通过**，导出及取消保持已有预览；五个原版预设的 **15 张完整 500×600 RGBA 对照仍全部一致**。整体 Goal 处于 **M3**，下一项是保留热会话的录制和动画对照。

这里的“冷导出”是按选定时间从初始状态独立重放，与继续录制已有预览是两个流程。此能力使用开发分支的 `VITE_SOURCE_RENDERER=native` 及已配置的本机原生服务；默认 WebGL 入口、已安装的 1.0 应用和发行包未更新。[机器证据索引](../tests/fixtures/source-samila-native-cold-export/20261024.json)保留源码、原生程序、报告和测试摘要。

## 用户流程实测

测试在一个隐藏 Electron 44.7.2 窗口中操作真实 App，未操作实体桌面。使用原版 samila1 的公式、参数及色板，明确降低到每批 256 点以验证交互；这不是完整原预设的性能或画面验收。

| 流程 | 结果 |
| --- | --- |
| 热改参数后导出同尺寸 PNG | 674×452，下载完成；解码完整 RGBA 与该次原生输出逐字节相等，预览像素及采样数保留 |
| 导出不同尺寸 PNG | 193×129，同样完整 RGBA 精确；点尺寸仍参考主画布物理高度 452 |
| 导出短视频 | MP4 为 192×128、3 fps、3 帧；三张上传帧的完整 RGB 与原生输出相等，上传 alpha 全为 255；ffprobe 确认尺寸、帧率及帧数 |
| 导出框打开时调整窗口 | 不产生预览请求；关闭后只执行一次必要的 634×432 尺寸重绘，保持同一预览资源 |
| 当前预览尚未完成时打开导出 | 开始按钮等待当前画面和暂停确认完成；单纯打开／关闭不增加采样 |
| 导出采样中取消并按 Escape | 等当前请求完成，只释放导出资源；不撤销共享 HTTP 请求，预览完整像素保留 |
| 取消后手动播放／暂停 | 原预览会话正常继续，全部原生请求按顺序执行 |

视频的本地模拟频率是 30 Hz，三帧对应 replayFrame 0／10／20，实际执行 21 次累积、3 次呈现。视频是有损编码；本次没有声称 MP4 解码像素与原图无损相等。

## 修复与资源边界

冷导出复用既有固定帧重放循环，保留时间、随机种子记录、参数变化补采、后退和尺寸变更语义。新增异步绘制接口，没有另建一套时间或历史解释。

原生协议新增 `step(5)` 与 `present(4)`：前者只累积并返回实际逐样本分类，后者只对已有墨迹调色、输出完整图片及实际像素统计，不推进采样检查点。预览保留原有 `display(2)`。重复请求同一帧、分数时刻呈现、改变亮度都不会多采样。未测量的 step 像素统计字段必须为零，不作为实际空画面的证据。

用户取消独立导出时先撤销该次任务的交付资格，等待已经提交的原生请求确认，再释放其确切资源。共享进程因此仍可保留预览。真正的进程故障仍明确报错；当前失败调用不会自动重发或改用 CPU。下一次明确的冷重放可重用保留的种子记录。失败的释放保留所有权，由既有导出清理注册表重试。

真实界面测试发现并修复了两个关联问题：

- 状态栏仅有最小高度，长提示在“就绪／正在计算”之间换行，实际高度为 26／27 像素，导致画布 432↔431 反复清屏、重新采样。现在固定状态栏几何，长文本省略显示并保留原有详情提示；最终实测全程 26 像素。
- 源录制模式下 Escape 绕过工作中的关闭保护。现在与普通导出共用关闭入口，避免旧窗口清理回调覆盖新窗口的工作状态。

## 原生与原版证据

真实 CGL 生命周期 **5 项通过**，覆盖两个资源交替使用、与通用原生绘制共存、非法输入及容量拒绝、尺寸清屏、精确释放、真正进程取消后的资源失效。新增检查确认 step→present 与相同种子 display 的完整像素和统计一致，重复 present 不改变检查点。

真实 HTTP／生成器检查另确认：固定种子的冷重放与等价的逐步 display 基线完整 RGBA 一致；后退使用已保存种子，改尺寸开启新种子记录；超容量在取种子前拒绝；真实 CGL 已执行且响应已完整收到后取消 B，A 的完整像素、检查点及随机字数不变。

原版对照继续使用已保存的 MathArt 1.7.8 run5，未重新运行或修改参考。五个未修改预设各三次暂停显示，完整采样量、500×600 场景缓冲，**15/15 RGBA 逐字节一致**；实际占用像素和最大墨迹质量也一致。唯一变换是 GL 行序翻转，没有裁剪、容差或 alpha 修正。比较不包括窗口界面和 PNG 增强。

原版捕获时 45 次绘制在读取 uniform 前有待处理 GL1282，后续检查为 0；来源及观察完全无扰动仍未知，继承[前轮报告](source-samila-native-integration-validation.zh-CN.md)的限制。

## 验证与成本

本轮相关 **75 个不同测试文件、1,105 项测试通过**：CPU／模拟边界 1,059 项，共享原生服务及呈现回归 41 项，Samila 真实 CGL 生命周期 5 项。`build:v2` 和 `git diff --check` 通过，构建保留已有的大 chunk 提示。最终 UI、冷重放和原版对照报告均核对了运行前后完整 src/server 摘要；服务和隐藏宿主全部关闭，原生子进程数为 0。

在相同尺寸、种子和请求序列下，逐步 display 基线返回 1,332,616 字节，step/present 返回 628,612 字节，减少约 52.8%；请求字节都为 890,734。字节数不能代替代理 token 或性能测量。

该次基线／新路径序列分别用时 0.249／0.136 秒，新资源首帧分别为 0.033／0.023 秒，后续重放、重新呈现及后退时间逐项保留在报告。全项冷验证墙钟 3.83 秒，user 6.69 秒、system 2.94 秒；工具最大 RSS 为 646,529,024 字节。这是一次验证运行，期间另有构建工作，且 OS／模块／驱动缓存未受控，**不据此宣称加速**。最大进程 RSS 也不是同时相加的进程族峰值。进程族／GPU 内存峰值和代理 token 成本未测。
