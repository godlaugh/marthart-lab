# 弹跳场景验收清单复核

2026-10-24。当前仍在 M3：场景补全与一致性验证。弹跳已经取得原版 JVM 的完整状态、艺术画面和四个内置预设的完整录像证据；早期记录中的“JVM 未成功加载”“仅有局部图像一致”已不代表当前进度。

完整家族验收尚未结束。下表将已有证据与剩余范围分开；历史失败报告保留，不用后续结果改写当时的观测。

2.0 新建菜单、作品文件夹和七个弹跳示例已接入原版模型，保留完整粒子数量。原生 CGL 与普通 WebGL 的实际页面入口均已验收；详见[新建与示例入口记录](source-bouncing-creation.zh-CN.md)。这不替代原版控件交互和完整家族验收。

| 验收项 | 已确认的进展 | 尚需核对 |
| --- | --- | --- |
| MAS-BOU-002：粒子数量与默认值 | 配置构造默认 20 万粒子、2 子步；内置示例分别为 200 万、500 万和两个 100 万公式预设。真实产品保留这些完整数量 | 原版默认界面的控件行为；文档“200 万默认、无上限”不能当作所有输入的运行保证 |
| MAS-BOU-003：步长、子步与时钟 | 生产时钟、暂停、两种录制起点及预热完成边界已接通；四个内置预设完整录像共 5,401 次原版更新与时钟一致 | 原版可变帧率窗口、1–16 子步及更广步长组合 |
| MAS-BOU-010：公式初始化 | 两个原版公式预设各 100 万粒子，11 份完整状态与 62 帧艺术画面一致；真实导出流程通过。两段完整 10 秒录像各 600 活动帧及 599 编码帧通过；实际 JVM 数值对照覆盖所列函数组合，并确认原版拒绝指南的 `Math.sin(...)` 写法 | 完整函数库、错误及边界语义；保留指南与实际程序冲突 |
| MAS-BOU-012：采样与拒绝 | 全部 14 模式的所列填充／轮廓及 512 次尝试 fallback 现已通过实际 JVM 数值对照；四个内置预设另有完整状态证据 | 所有参数与拒绝边界仍未穷尽。指南“全部点从容器内开始”与原版失败后保留中心的行为应分别记录 |
| MAS-BOU-014：初始速度 | 六种速度模式、噪声、零速度及退化方向的所列案例已通过实际 JVM 数值对照；四个原版预设的连续状态与画面通过。方向控件使用度，36 项原版转换数值匹配；无改动保留弧度精度 | 全部数值边界与原版窗口交互 |
| MAS-BOU-023：GPU 更新与绘制 | 原生状态保留、完整纹理、点与边界绘制已接通产品；四个预设完整 5,401 帧 RGB、最终 alpha、相机和时钟一致 | 所有参数、渲染尺寸与原版窗口交互；整类验收不由单个预设替代 |
| MAS-BOU-024：示例构图 | 原包螺旋、星形及两个公式预设已有完整录像对照；指南玫瑰、六边形、椭圆各完成 600 次原版更新、62 个整图样本和 11 个完整状态检查点，保留指定粒子数量 | 指南列出的五组设置均已有运行证据；未指定值的选择已记录，不扩展为任意参数、原版窗口或完整视频声明 |
| MAS-BOU-025：高负载与视频 | 500 万原版预设完整 60 秒、3,601 个活动帧和 3,600 个编码帧通过；累计输入容量修复后，同输入 MP4 解码及文件字节与原版一致 | 高质量 2–4 子步、4K 视频及其它设备仍未覆盖 |

这里的“艺术画面一致”指正常品牌绘制之前的完整 RGB，并单独检查最终 alpha，不裁剪区域来取得通过。编码一致性使用同一批原版品牌完成帧作为两条编码路径的输入；这不表示产品生成了原版品牌叠加，也不代替原版 GUI 验收。
