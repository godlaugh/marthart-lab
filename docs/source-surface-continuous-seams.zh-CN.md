# 连续接缝偏移与动态相机验收（2026-10-24）

16 组 CPU/GPU 输入、52 帧完整艺术画面与原版逐像素一致。全部帧的相机角度、缩放、焦距也一致。本轮没有发现需要修改产品渲染实现的差异，补充了可复用输入和相机数值校验。

## 验收范围

每种输入分别运行 CPU 与 GPU 网格，使用 9×7 采样、填充及线框、384×288 像素画面。录制模拟帧率为 4 FPS，独立传入的实际帧率包括 37、24、12、1、0、-2。包括预热帧和队列完成帧，并验证停止录制不额外推进状态。

| 输入 | 每种模式帧数 | 原版观察与结果 |
| --- | ---: | --- |
| 强制 U 闭合 | 2 | 连续偏移 0.984375，整图一致 |
| 同时强制 V 闭合 | 2 | 连续偏移 -6.09375，整图一致 |
| V 参数范围反向 | 2 | 连续偏移 -0.984375，整图一致 |
| 曲面带空间偏移 | 2 | 连续偏移仍为 0.984375，整图一致 |
| 参数随时间变化 | 5 | 首帧计算偏移 3.515625，后续保留；五张参考画面互不相同 |
| 参数变化且强制 V 闭合 | 5 | 首帧计算偏移 -6.046875，后续保留；五张参考画面互不相同 |
| 相机表达式 | 2 | `phi=a*PI`、`theta=PI/3`、`gamma=-a`，数值与整图一致 |
| 相机时间线 | 6 | 先滚转到 `PI/4`，再同时缩放至 1.4、焦距变为 45；四个不同画面状态一致 |

曲面方程为 `x=u, y=v+a*u, z=.17*u*v`，初始参数 `a=0.17`。参数动画使用原版 `paramStart`，不是测试代码逐帧替换曲面。原版接缝字段通过只读访问采集，没有调用可能重新计算偏移的诊断方法。

相机时间线中的 `rotateTo` 保留既有 phi/theta，改变 gamma，因此这批动态输入主要覆盖滚转、缩放、焦距，不据此声称全部三轴运动或鼠标交互已验证。数值校验要求双方字段存在且有限，再按 Float32 比较，避免缺失值被误认为匹配。

## 证据与复现

原版为 MathArt 1.7.8，JAR SHA-256：`a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。原版正常权限检查、品牌绘制和最终 PNG 均保留，对照取品牌绘制开始前的完整艺术画面。没有裁剪、遮罩、容差，也没有宣称带品牌的最终文件相同。

产品侧走实际导入、Generator、Worker、原生渲染服务及录制流程，使用显式启用的 `VITE_SOURCE_RENDERER=native`。默认 WebGL 路径不属于本轮零差异结论。

可复用输入：`scripts/source-surface-scene/continuous-seams-camera-cases.json`。运行：

```sh
python3 scripts/source-surface-scene/prepare-seams-camera.py \
  --cases scripts/source-surface-scene/continuous-seams-camera-cases.json \
  --output <新输入目录>
```

此命令只生成输入，不执行原版。重新生成的 16 个输入已与实际采集输入逐项核对相等。原版采集仍需要本地原版 JAR、JVM、离屏启动器和探针，不声称全新机器可直接复现。

本地证据目录：`.cache/source-surface-continuous-seams-20261024/`。

- `reference/`：原版输入、探针、52 帧像素、相机与接缝状态、来源摘要、进程及文件检查。
- `final/report.json`、`final/<案例>/frame-*.png`：最终产品对照结果及可查看画面；`compared/` 保留加强相机有限值检查前的首次通过结果。
- `tests.log`：5 个测试文件、109 项通过，覆盖接缝几何、网格运行时、GPU 集成、相机导入与时间线。
- `reproduced-inputs/`：重新展开并核对的输入。

原版 16 次执行均成功退出并回收进程组；164 次窗口边界检查均为零窗口。settings/license 状态与摘要未变，正常策略缓存写入前留有备份。产品服务遗留进程为 0，源文件和参考数据在验证期间摘要稳定。

最终产品验证墙钟 10.110 秒；进程族观察 CPU 25.860 秒、采样峰值 RSS 1886 MiB，32 次采样无错误。原版采集累计 104.838 秒。未控制冷暖缓存或并行测试负载，原版 CPU/RSS、GPU 与 token 成本未测量；这些数据不支持性能改善结论。本轮只修改验证脚本、输入和文档，未重复产品构建。
