## 后续定位：差异发生在 8 位颜色混合（2026-10-24）

对四个残差时刻进一步逐粒子重放，已将范围收窄到 **原生 GL 与 ANGLE Metal 的 RGBA8 混合／输出转换边界**。粒子更新和混合前的颜色都没有出现差异。

每个时刻选出影响该位置附近的 176 个候选粒子，在独立浮点画布逐个绘制；四次共 704 个候选的混合前 RGBA 全部一致。再保持原顺序重放全部 200 万粒子，首次且唯一的累计差异均发生在 **编号 1,973,629（从 0 开始）的粒子**。

独立混合对照还把背景绿色改为 138、139、140、141、142：两个后端仅在 140 这一组的最终绿色字节不同。四个时刻都重现同样结果。这里的“改背景”仅发生在诊断用的临时画布，原版参考帧没有被替换。

数学上的混合结果接近 8 位量化的半级边界。上述实验确认差异位于混合与输出转换，但**尚未确认驱动内部的计算精度、融合运算或舍入规则**。浮点画布的 alpha 也存在一个 Float32 单位的差异，所以不能笼统声称两个后端所有浮点混合结果都一致。

两个实际后端分别是 `Apple M2 Max` 原生 GL4，以及 `ANGLE Metal Renderer: Apple M2 Max`。尝试指定 Chrome 的 GL 后端时实际回退到了 SwiftShader，已在正式比较前终止，不能将它当作原生 GL 验收。
