# 曲面粒子、网格、相机与拖尾验证

本记录对应 2.0 开发分支的曲面 CPU 点模式，以及已接入渲染器、尚未开放完整界面流程的 CPU 网格。1.0 Apple Silicon 应用包未更新。其余 11 类场景补全与原版效果一致性仍是未完成目标。

## 本轮进展：CPU 网格线框绘制

网格运行时产生的线框已接入实际渲染器，支持耦合网格边和独立参数曲线，并在填充之后绘制。每对端点展开为四个顶点、六个索引，保留原版边顺序和重复边；不增加连接拐角或圆头。宽度包含原版 modelview 行列式缩放，使用逻辑画布尺寸；方向先计算原坐标的 Float32 差再变换，避免平移后的舍入丢失。默认源路径保留透视／正交对应的深度偏移、深度写入和透明叠加。

填充与线框共用 CPU 坐标变换和 Processing 整数颜色解析。填充先替换 alpha，线框保留原始 stroke alpha；零 alpha 的小整数仍按不透明灰度解释。线框展开前核算位置、方向、颜色和索引的完整 CPU 缓冲，超过 256 MiB 明确拒绝。这是本地资源边界，不是原版格式上限或包含显存的总内存保证。交付线框数组纳入统一的 Worker 转移与缓存计量；GPU 资源由渲染器创建和释放。

本轮 **38 个测试文件、740 项相关测试通过**，类型检查与 Web 构建通过。线框验证器从原版 Processing 包读取 LineVert/LineFrag，使用独立 Python Float32 计算位置、方向、线宽和颜色，再与实际 ArtRenderer 的 **26 组完整 RGBA8 画面**比较：所有字节一致，所有展开缓冲一致，浏览器错误为空。覆盖运行时生成的两种线框、填充遮挡、淡出、透视／正交、DPR 2、缩小和非整数比例导出、近裁剪面穿越、零长度、视线方向、反向端点、非有限端点、透明重复线和 65,540 个展开顶点。

此前填充的 13 组画面对照继续通过；现有 CPU 点模式的实际界面导入、编辑、保存重开和 PNG 导出再次通过，服务、下载和独立冷渲染器输出一致。以上对照共享生成的几何和相机输入，未启用 MSAA，**不等于原版 JVM/JOGL 整图验收**。本轮复查原版窗口仍被系统锁屏阻止，没有增加原版一致性通过项，仍为 0/11。

## 已完成：CPU 网格基础与填充渲染

已实现原版网格配置解析、几何与接缝、循环色板平滑、线框几何、单对象逐帧运行时，以及独立的 CPU 填充渲染路径。**公共导入和界面仍未开放这条完整网格路径**；线框的 Processing 绘制路径已在上述后续工作接入；点／网格切换宿主及 GPU 模式尚待接入。本轮基础代码不能视作整个曲面场景完成。

网格包含参数域两端，粒子索引与渲染顶点索引分别保存；每个四边形按较短对角线分割，任何角点无效就不绘制该四边形。U 接缝偏移由对象首次需要显示时求出，参数变化不会擅自清空原版的偏移缓存。几何与线框共用这些事实；线框保留源边顺序、对角线和独立曲线的断线规则。源 CPU 法线中被丢弃的叉积结果也按原版保留，没有套用本地网格算法修正它。

网格与点模式共用公式、参数和分轴变换的所有者。坐标输入先转 Float32，再进入 double 公式求值，输出再按 Float32 顺序缩放、偏移。模式更换时，新函数复制当时的基础常量；旧动作仍持有旧函数变量槽。每个函数独立标记参数变化，避免把旧对象的后续修改传播到新对象。

网格运行时明确分开 `update` 与 `display`：所有跟踪动作绑定同一个可变跟踪点；固定网格与移动跟踪点使用各自的参数坐标。网格更新推进参数动画，但不会自行推进渐变计时器。首次接缝计算发生在对应的显示帧，`snapshot()` 只读取已完成帧；漏掉显示步骤会报错。

CPU 填充按 Processing 的即时几何路径，在 CPU 上逐步 Float32 计算 modelview，再由默认颜色着色器乘 projection。它使用无光照顶点颜色，不应用 GPU 网格材质。填充透明度先转换成字节并替换色板 alpha；仍保留 `fill(int)` 的特殊解释：零 alpha 且 RGB 整数不大于 255 时按不透明灰度处理。生产者保留 packed 颜色，渲染边界统一转换成 RGBA；不会从显示 RGB 反推原值。

本轮 36 个相关测试文件、708 项测试通过，类型检查与 Web 构建通过。网格运行时到实际渲染器的 13 组完整 RGBA8 画面，与保留的 Processing 着色器及独立 Python Float32 变换结果逐字节一致，覆盖透明度、零透明度灰度分支、旋转、正交投影、反向参数域、无效但未使用的顶点和参数变化。对照共享生成的几何、packed 颜色和相机输入，不执行原版 JVM/JOGL，也不包含原生抗锯齿及驱动差异。原版完整画面验收仍为 **0/11**。

共享公式所有者的重构也经过现有点模式回归：实际界面导入、参数编辑、保存重开、8 次时间跳转和 PNG 下载通过；服务文件、实际下载和独立冷 Worker／渲染器的 PNG 完全相同。静态点、拖尾、参数动画及四种渐变模式的前后输出摘要一致。点模式性能没有稳定改善，不能把结构复用称为加速。

网格缓存由每个函数自身的参数版本失效；几何、线框和映射颜色缓存不向外暴露。每帧交付独立缓冲，并在复制前计入工作预算；测试覆盖外部修改和转移缓冲。没有可观察消费者的半开粒子数组停止重复计算，移动跟踪点仍逐帧更新。首次显示的接缝偏移和原版渐变更新时机保持不变。

## 已接入：曲面参数动画

CPU 点曲面支持具名／全部参数的开始与停止，以及独立 `param` 片段。界面可编辑参数名、范围、每帧步进和动作的端点减速；独立片段可单独启用各参数。导入后保存重开、正向与反向跳转、相机跟踪、拖尾和导出使用同一条参数回放。

参数初始值留在作品文档中，运行值由每次回放单独持有。未声明参数读取为 0、写入没有效果，参数原名仍保留。上下界不自动交换；范围不大于 0.000001 时写下界。具名开始可替换已有设置；独立片段替换所有参数动画，采用自身的默认端点减速，并在结束帧的曲面更新之前停止。动作组则在结束帧仍推进参数。片段缓动、参数端点减速和时间步长分别处理，没有套用旧本地振荡器。

**帧率边界：**离线回放使用作品的名义帧率；原版读取实时 `PApplet.frameRate`。计算保留帧率不大于 1 时回退 60 的规则，但没有测得原版实时帧率序列，因此不宣称可变帧率下的原版动态一致性。

本轮还修正了上轮导入遗漏：原版在分派动作之前会跳过缺少数组／对象 `args` 的动作。`gradientStop` 与 `paramStop` 等需要显式数组或对象才会执行；原始输入和数字文本保留。有效空数组／对象仍按各自帮助函数的默认语义处理。

独立 Python 转写覆盖 11 个数值案例、30 帧；运行时 27 项测试通过，公共导入、文档保存和几何链路新增 13 项回归，包括停止顺序、未知参数、同组动作顺序、名义帧率、反向跳转、取消和容量限制。广泛回归首轮 64 套件、1448 项中通过 1446 项；另两项旧预期已修正，最终 73 项定向回归全部通过，类型检查与构建通过。参数动作展开后计入既有 4096 项时间线预算；逐帧参数运算计入粒子回放工作预算。

## 上轮进展：曲面渐变时间线与动态拖尾已接入

CPU 点曲面现在可以导入、编辑并执行四种渐变：色相轮转、偏移循环、交叉淡化和色板变形。开始、停止、再次开始与相机动作共享原版顺序队列；界面支持速度及 RGB、Linear、OKLab、OKLCH 插值。保存重开保留配置，倒退会从头重放，已有 1.0 应用包未替换。

渐变期间，粒子头部使用平滑后的颜色，拖尾按记录年龄重建历史颜色。停止渐变后保留头部最后颜色，并恢复静态拖尾透明度规则。色板由统一入口解析，拖尾颜色由历史记录的生产者交付，渲染器不再从当前粒子颜色推算历史颜色。

本轮保留的原版细节：

- 同组动作先全部启动，再按列表顺序更新。启动、调速、结束可在一次显示帧内多次应用颜色，不能合并；重新启动从当时主偏移开始。Surface 只在有效步长更新渐变，没有套用 Roots 的双阶段时钟。
- 目标帧由 double 转 Float32，再映射为主偏移、第二偏移和混合量。环形偏移按 0.2 平滑、混合量按 0.18 平滑；仅当某项变化严格超过 Float32 的 0.0001 时才整体写回。刷新会重置基础颜色及点透明度，随后粒子运动再应用边界渐隐。
- 拖尾年龄以 120 Hz 量化，使用当前速度向历史外推，不使用头部平滑状态。渐变运行时只取采样 RGB，透明度从 255 开始按记录顺序渐隐；停止后恢复基础颜色的 alpha。逐段跳过无效端点并复用相邻端点颜色，保留原版 512 项年龄缓存、4096 项颜色缓存及完整哈希碰撞行为。
- Surface 读取 args 对象或 args[0] 对象；不扫描后续数组项。默认 HUE_ROTATE / OKLAB / 60，两个区域标志固定为 true。FRACTAL 排除保留原字符串空格语义，未知模式跳过，数字原文单独保留。GPU、网格仍明确报未接入；参数动画已在本轮接入。这里的默认配置只适用于通过外层 args 判断的动作，上轮遗漏已按本轮说明修正。

**验证结果：**累计 850 项不同的相关测试通过，构建通过（仍有既有的大文件体积提示）。新增独立 Python 生命周期转写覆盖四种模式及三种同组顺序，共 69 帧的完整头部／拖尾颜色与透明度；公开导入、保存重开、几何生成、相机查询、反向跳转和导出入口与其匹配。前置计算的 122 组映射、平滑、采样和年龄量化金标继续保留。字段所有者清理后复跑 25 项相关测试，并新增 3 项数值来源边界／取消保护测试；最后复跑相关两套共 18 项，均通过。

真实应用页面中，修改渐变方式为 palette_morph、插值为 OKLCH、速度为 240 后保存重开，设置保持；启动、等待、停止、重启与反向跳转检查通过。活动阶段的拖尾有多个历史颜色，停止阶段保留静态颜色。257×193 PNG 的实际下载、独立导出服务与冷 Worker／Renderer 结果相同，SHA-256 为 `afd00905782b1da70fec1d7092cc488f22af9cb525dee7d48b6d3c3eaf5fa21b`。浏览器没有页面异常，测试创建的服务和浏览器已清理。

## 已完成：圆形光照点与尺寸

曲面 CPU 点现在使用原版保留的圆形光照着色器方程与 64×64 点纹理。每个粒子用一个四边形实例绘制，直接借用生产者的位置、颜色和透明度缓冲；移除了此前专供此路径使用的方形 `Three.Points` 和重复 RGBA 拷贝。材质拥有纹理，清理材质时同步释放。原版 CPU 点没有设置网格材质的光照参数，因此保留着色器零值回退，不把网格高光控件错误地套到粒子上。

点半径保留符号，负值不取绝对值、不钳制为零。原版没有 settings 对象时默认 1.68，有 settings 而缺少有效 dot_size 时默认 2；非有限结果明确拒绝。点半径和预览像素密度在粒子回放分配前验证。界面可编辑负半径并保存重开。

主画布使用原版半径倍率 0.8；离屏导出还按渲染高度与预览像素密度计算源缩放。实际预览密度随 Worker 请求及输出交付，导出读取已呈现帧的密度，不从系统值猜测。无该字段的旧直接调用明确标记使用密度 1。这些是本地预览密度，不是原版 PApplet 像素密度的观测。

独立验证器从原版 JAR 读取顶点及片段着色器，在直接 WebGL2 程序中绘制展开的四边形，与生产实例化材质对照；纹理由独立 Python Float32 转写生成。12 组完整 RGBA 图像逐字节一致，覆盖主画布、DPR 2、不同导出比例与参考密度、负/零半径、小点纹理缩小、重叠及场景渐隐正交投影。着色器编译、链接和 WebGL 错误均检查通过。

此对照共享已交付的相机矩阵及尺寸 uniform，矩阵与尺寸推导由其它金标单独验证。对照未启用 MSAA；原版桌面 GLSL 150 适配为 WebGL2 GLSL 300 es，使用 highp。原版反向边界 smoothstep 表达式保留，但其跨驱动结果、原生纹理 mipmap 可用性、混合、抗锯齿及完整 JVM 画面仍未验收。12/12 着色器对照通过不等于 11 类场景的原版整图验收通过。

## 已完成：静态色板与点透明度

曲面 CPU 点模式现在直接使用原版静态色板采样规则：沿 U 正向排列、按粒子编号保持颜色。非周期色板也会把最后一行绕回首色；周期色板分段闭合。旧实现的反向色板和本地高度着色不再参与这条路径。

导入、编辑、保存和重开均保留颜色原文，支持单色、ARGB、十进制和 `0x` 表示。缺省使用源六色，显式空数组拒绝；无法解析的颜色文本保留，按源规则显示白色并给出警告。最多 65536 色、合计 1 MiB 文本是本地准备预算，不是原版上限。此前保存的源粒子作品在缺少新色板字段时，会从其已保存的手动色标迁移，保留后续编辑，不用原始导入记录覆盖。新导入则直接保存源色板或源六色默认。

点初始使用基础透明度；有正时间步长的更新中，流动且周期的 U/V 轴在各自参数范围两端 10% 内渐隐，两轴因子按源 Float32 顺序相乘，再量化为 8 位透明度。原版曲面配置缺省开启点渐隐，但该版本的 JSON 解析器不读取 `fade_points`，导入时保留其原文并提示未使用。MathArt Lab 外观面板可编辑并保存点渐隐状态。拖尾使用基础色板透明度，再按记录顺序渐隐；基础 alpha 为零时原版拖尾回退到不透明，这一特殊规则也保留。点的渐隐不会额外压暗拖尾。

实际界面完成了颜色文本修改、渐隐开关、保存重开和 PNG 导出；Worker 的逐点 alpha、渲染器逐实例颜色与透明度属性及最终可见像素均已检查。下载、隔离服务文件与冷 Worker/渲染器 PNG 哈希相同。以上证明本地实现及导出链路，不代表原版完整画面一致；圆形光照点的本地独立对照见上节。

## 已实现的行为

导入含有效 `track` 动作或启用的 `trails` 片段的原版 SURFACE JSON 时，CPU POINTS 作品使用显式粒子版本 `mathart-1.7.8-points-v1`。静态拖尾与时间线录制开关已接入，原版缺省设置为显示拖尾、开启渐隐、寿命 4 秒、线宽 1。

- 两个参数轴均使用半开采样范围，索引为 `U编号 × V数量 + V编号`。不再以另一套本地采样顺序解释跟踪索引。
- 位置、速度与边界处理按源 Float32 运算顺序更新。周期流动使用余数回绕；周期反弹仅在严格越界时反转速度，并丢弃越界余量、夹到边界。
- 绘图和相机跟踪使用同一生产者的位置。过渡更新先读旧位置，粒子更新后相机控制器再读取当前位置；等待片段继续更新粒子，队列完成后的帧不再推进粒子。
- 表达式复用编译结果和变量槽，自定义参数可遮蔽 `u`、`v`。不会凭空增加原版公式没有的时间变量。
- 导入先解析时间线结构，再选定几何字段的解析路径。同一字段不再先由本地解析器处理、再被源规则覆盖。关闭的片段不读取其类型、时长或动作。
- 编辑器支持粒子索引和即时拖尾录制片段；尚未接入的参数动画、GPU 和网格模式不会被替换为另一种已实现效果。取消或运算失败后的粒子实例无法继续发布部分位置。

拖尾由同一粒子状态生成，保留源程序的以下规则：

- 严格越界时记录出口、断点、入口和最终位置；断点两侧及不同粒子之间不会连线。恰好到达最大端点时会回绕但不插入断点，这是源规则本身的行为。
- 每条记录使用当前帧时间；先追加，再删除年龄严格大于寿命的记录。队列结束后不再推进或过期。每粒子还受源容量 `max(0, int32(float32(寿命×60))+120)` 限制，保留原有溢出规则。
- 渐隐按记录顺序计算，断点也计入分母；不是按年龄计算。输出透明度保留源 8 位量化规则。
- 线宽按 Float32 的 `max(0.1, 线宽×0.95)` 计算，拖尾在点之后覆盖绘制，关闭深度测试。原生线条栅格化尚未对照。
- 显示设置只决定是否绘制历史；录制设置决定初始状态，随后可由时间线切换。编辑后从头重建历史。原版 JSON 没有读取 `record_trails` 字段，导入时初始录制为开启。

时间线 `trails` 片段默认开启录制，`enable:false` 则停止追加。该动作不清空、不隐藏已有线条，旧记录仍按寿命过期；重新开启时不会自动插入断点，因此未过期的末点可能连到恢复后的首点。

原程序将此片段构造成零时长的 `InstantAction`，不读取其 `duration`、`easing` 字段；忽略的原字段及已登记数字原文仍保留。即时片段占用一次队列更新，不和下一片段合并。如果后面还有等待，当前帧仍按队列剩余时间推进粒子；如果位于队列末尾，开关会执行，但零有效步长不推进粒子或过期历史。界面显示其实际占用的一帧，不提供无效的时长编辑；普通相机补间的零时长输入仍明确拒绝。

既有本地作品、此前只接入源相机的作品，以及没有有效跟踪动作或拖尾片段的新导入作品，保持各自已有采样行为。本批没有宣称全部曲面都已迁移。
