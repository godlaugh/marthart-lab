# 曲面粒子、网格、相机与拖尾验证

本记录对应 2.0 开发分支的曲面 CPU 点、网格及两者切换，以及 GPU 点模式，包含导入、编辑、保存、回放和导出。1.0 Apple Silicon 应用包未更新。其余 11 类场景补全与原版效果一致性仍是未完成目标。

## 2026 年 10 月 19 日：GPU 点模式接通，透明度与错误恢复已复验

GPU 点曲面现在可以从原版作品导入，修改采样、半径、参数域、运动速度、公式与色板，保存重开、跳转时间，并导出图片或视频。公式直接编译为 GLSL，Worker 交付初始参数种子、固定 tint、参数 uniform 和相机事实；可见点的位置由 GPU 按时间计算，没有先在 CPU 生成整组位置再冒充 GPU 绘制。现有 1.0 应用包保持不变。

按保留的 MathArt 1.7.8 类与着色器证据实现以下行为：

- 点云使用半开参数网格；周期流动、反弹与边界渐隐遵守 GPU 着色器公式。相机跟踪点仍按 CPU 逐帧递推，最后一次 setup 绑定指定活动目标，较早的其它目标保持初始位置。两条路径在反弹时可能不重合。
- 原版 GPU 模式切换片段转换为同长度等待；不读取该分支不使用的目标和缓动。GPU 不显示拖尾；时间线渐变仍运行，但不会重建创建时已经绑定的点颜色。界面说明这些行为，保存保留原始配置与导入来源。
- CPU/GPU 点材质共用正确的 Processing BLEND：RGB 使用源透明度覆盖，alpha 使用 ONE/ONE 相加。旧默认 Three 混合会低估半透明重叠区域的 alpha，现已修复。
- 未使用的 GPU 默认跟踪点出现非有限坐标，不再使整个曲面失败；GPU 保留可见的有限区域。相机实际消费无效目标时，仍返回明确错误。没有替换公式、坐标或跟踪目标。
- shader 编译失败会保留真实诊断，停止无效绘制并释放 shader；程序继续由材质缓存负责销毁。同一渲染器可在新作品输出后恢复，验证没有残留 GL 错误。

## 前一批：点／网格切换的界面与导出已接通

含 CPU 曲面模式切换的原版作品现在可以导入，在界面选择初始模式、分别修改点云和网格采样、添加切换片段、选择目标模式并保存重开。切换先淡出到黑色，再创建目标曲面并淡入；相机与几何使用同一次回放，倒退会重新生成对应状态。既有参数、渐变和跟踪动作仍绑定初始曲面，遵守上一批核对的源行为。

点与网格由一份完整配置 `surfaceSource` 持有。旧版 `surfaceSourceMesh` 文件在读取边界迁移，保留用户编辑，不从导入原文覆盖配置；冲突或缺失版本的旧字段会明确报错。旧点模式项目维持原有行为，只有初始网格或带切换片段的导入进入新宿主。

原版 JSON 切换的淡出比例固定为 0.5；目标只识别 MESH，其它未知值按源规则回落为 POINTS，保留原文。非正时长使用原版默认 1 秒。同模式切换保留原始时长，但队列只执行一次更新。播放和导出使用本地固定帧率，尚未证明与原版实时调度一致。

## 前一批：CPU 模式切换的运行时与时钟

已实现单个曲面宿主在 CPU 点与网格之间切换，并接入共用场景时钟。**这一批还没有开放切换片段的公共导入、编辑和画面遮罩**；不能把下面的运行时验证当作界面功能已交付。现有 CPU 点和初始网格仍使用已验收的入口。

静态依据来自固定的 MathArt 1.7.8 安装包，本次重新核对 JAR 与 15 个相关类摘要。原版切换先淡出到黑色，在淡出比例处创建新对象，再淡入；不是同时显示点和网格。两个半段各自应用缓动，alpha 按原版 Float32 计算并取整到 0–255。同模式请求只占一次更新，但原始时长仍参与该帧的剩余时间计算；不能替换成零时长等待。时长和淡出比例保留构造器的最小值及夹取规则。

新宿主明确区分“时间线绑定的初始对象”和“正在更新、显示的当前对象”。切换当帧先创建新对象，再更新新对象；新函数复制当时的基础参数，自己的变量槽和动画注册表独立。已有跟踪位置、参数／渐变动作、拖尾录制开关仍指向初始对象，切换后不会自动改绑。原版只保存和恢复相机及角速度，已有跟踪引用不被清除，因此相机随后仍会读取旧对象的冻结位置。

旧对象移出时释放粒子、颜色、拖尾和显示缓存，捕获的位置只保留独立的三坐标向量。所有新建对象共用一次回放的 2000 万工作单位预算，反复切换不能重置预算；取消或容量错误不会交付部分切换结果。仅相机查询保持相同跟踪轨迹，不冒充完整画面输出。

本批 **53 个测试文件、1,064 项测试通过**，包含 19 项宿主／时钟边界用例，以及共用 Roots 时钟回归。类型检查、Web 构建通过；现有点模式和网格模式的实际界面、保存重开及 PNG 下载再次通过，点 PNG 摘要保持原值。测试覆盖点→网格→点、同模式短路、相机快照恢复、旧目标冻结、旧参数注册表、全量／相机查询、反向重放、帧顺序、取消、累计容量及外部修改交付缓冲。

## 2026 年 10 月 19 日：CPU 网格完整操作链路

初始为 CPU MESH 的原版作品现在可直接导入，编辑采样数、参数域、接缝、分轴变换、移动跟踪点、填充、两种线框及完整 ARGB 颜色，再保存重开和导出。网格配置由一个保存合同持有，界面、生成器和回放使用同一份值；不再从旧的本地网格字段反推。反向参数域、零值和未使用的源字段保留；超过本地容量会明确拒绝，不截断到上限。GPU 初始模式和点／网格切换仍明确报告尚未接入。

参数、渐变动作和相机共享源顺序队列。网格的静止采样与移动跟踪点分别更新；保留原版网格不自行推进渐变时钟、拖尾开关无绘制效果的行为。每帧仍执行必要的几何与接缝显示计算，只为所请求的最终帧复制交付缓冲。仅查询相机时不生成不可观察的网格画面；这种查询不能当作完整渲染成功的证据。时间线缓存覆盖完整网格配置并保留负零，倒退或编辑不会借用其它作品的运行状态。

本次修复了实际测试发现的半透明背景偏暗：Processing 将原始 RGBA 传给清屏，Three 默认会预乘 alpha。源网格现在通过渲染器的状态所有者执行原始通道清屏，并在无公式标注的 PNG 导出中直接编码 framebuffer，避免 Canvas 再次反预乘。独立解码确认两种线框 PNG 的四角均为 `[64,128,192,128]`，完整解码 RGBA 与冷启动 WebGL framebuffer 一致。**带公式标注的图片及非 PNG 导出仍使用既有合成路径，尚未验证这条透明颜色规则；不能据此宣称全部导出格式一致。**

## 已实现的行为

导入含有效 `track` 动作或启用的 `trails` 片段的原版 SURFACE JSON 时，CPU POINTS 作品使用显式粒子版本 `mathart-1.7.8-points-v1`。静态拖尾与时间线录制开关已接入，原版缺省设置为显示拖尾、开启渐隐、寿命 4 秒、线宽 1。

- 两个参数轴均使用半开采样范围，索引为 `U编号 × V数量 + V编号`。不再以另一套本地采样顺序解释跟踪索引。
- 位置、速度与边界处理按源 Float32 运算顺序更新。周期流动使用余数回绕；周期反弹仅在严格越界时反转速度，并丢弃越界余量、夹到边界。
- 绘图和相机跟踪使用同一生产者的位置。过渡更新先读旧位置，粒子更新后相机控制器再读取当前位置；等待片段继续更新粒子，队列完成后的帧不再推进粒子。
- 表达式复用编译结果和变量槽，自定义参数可遮蔽 `u`、`v`。不会凭空增加原版公式没有的时间变量。
- 导入先解析时间线结构，再选定几何字段的解析路径。同一字段不再先由本地解析器处理、再被源规则覆盖。关闭的片段不读取其类型、时长或动作。
- 编辑器支持粒子索引和即时拖尾录制片段；尚未接入的参数动画、GPU 和网格模式不会被替换为另一种已实现效果。取消或运算失败后的粒子实例无法继续发布部分位置。

拖尾由同一粒子状态生成，保留源程序的以下规则：

- 严格越界时记录出口、断点、入口和最终位置；断点两侧及不同粒子之间不会连线。恰好到达最大端点时会回绕但不插入断点，这是源规则本身的行为。
- 每条记录使用当前帧时间；先追加，再删除年龄严格大于寿命的记录。队列结束后不再推进或过期。每粒子还受源容量 `max(0, int32(float32(寿命×60))+120)` 限制，保留原有溢出规则。
- 渐隐按记录顺序计算，断点也计入分母；不是按年龄计算。输出透明度保留源 8 位量化规则。
- 线宽按 Float32 的 `max(0.1, 线宽×0.95)` 计算，拖尾在点之后覆盖绘制，关闭深度测试。原生线条栅格化尚未对照。
- 显示设置只决定是否绘制历史；录制设置决定初始状态，随后可由时间线切换。编辑后从头重建历史。原版 JSON 没有读取 `record_trails` 字段，导入时初始录制为开启。

时间线 `trails` 片段默认开启录制，`enable:false` 则停止追加。该动作不清空、不隐藏已有线条，旧记录仍按寿命过期；重新开启时不会自动插入断点，因此未过期的末点可能连到恢复后的首点。

原程序将此片段构造成零时长的 `InstantAction`，不读取其 `duration`、`easing` 字段；忽略的原字段及已登记数字原文仍保留。即时片段占用一次队列更新，不和下一片段合并。如果后面还有等待，当前帧仍按队列剩余时间推进粒子；如果位于队列末尾，开关会执行，但零有效步长不推进粒子或过期历史。界面显示其实际占用的一帧，不提供无效的时长编辑；普通相机补间的零时长输入仍明确拒绝。

既有本地作品、此前只接入源相机的作品，以及没有有效跟踪动作或拖尾片段的新导入作品，保持各自已有采样行为。本批没有宣称全部曲面都已迁移。
