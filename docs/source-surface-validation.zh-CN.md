# 曲面粒子与相机跟踪验证

本记录对应 2.0 开发分支的曲面 CPU 点模式。1.0 Apple Silicon 应用包未更新。其余 11 类场景补全与原版效果一致性仍是未完成目标。

## 已实现的行为

导入含有效 `track` 动作的原版 SURFACE JSON 时，CPU POINTS 且 `show_trails: false` 的作品使用显式粒子版本 `mathart-1.7.8-points-v1`。

- 两个参数轴均使用半开采样范围，索引为 `U编号 × V数量 + V编号`。不再以另一套本地采样顺序解释跟踪索引。
- 位置、速度与边界处理按源 Float32 运算顺序更新。周期流动使用余数回绕；周期反弹仅在严格越界时反转速度，并丢弃越界余量、夹到边界。
- 绘图和相机跟踪使用同一生产者的位置。过渡更新先读旧位置，粒子更新后相机控制器再读取当前位置；等待片段继续更新粒子，队列完成后的帧不再推进粒子。
- 表达式复用编译结果和变量槽，自定义参数可遮蔽 `u`、`v`。不会凭空增加原版公式没有的时间变量。
- 导入先解析时间线结构，再选定几何字段的解析路径。同一字段不再先由本地解析器处理、再被源规则覆盖。关闭的片段不读取其类型、时长或动作。
- 编辑器支持粒子索引；尚未接入的参数/渐变动画、拖尾、GPU 和网格模式不会被替换为另一种已实现效果。取消或运算失败后的粒子实例无法继续发布部分位置。

既有本地作品、此前只接入源相机的作品，以及没有有效跟踪动作的新导入作品，保持各自已有采样行为。本批没有宣称全部曲面都已迁移。

## 实际执行的验证

1. 25 个测试文件、468 项测试通过。覆盖源公式、标量、导入、数字原文保存、曲面运动、相机队列、时间线及旧作品兼容。
2. 独立的 3×5 网格金标检查半开范围、索引、边界反弹、回绕、分步 Float32 缩放，以及跟踪与几何的位置关系。这些金标根据保留产物的指令推导，未运行原版应用。
3. 实际 Chrome App 导入、初始相机编辑、重开、粒子索引 7→6→7 编辑及 PNG 导出通过。
4. 实际 Worker 在 0、0.25、0.75、2 秒及返回 0.25 秒的请求中返回相同编号规则；过渡完成后，相机中心与输出中被跟踪粒子的坐标完全一致。
5. 实际下载的 257×193 PNG、隔离导出服务保存的文件、独立冷 Worker/渲染器生成的文件，SHA-256 相同。人工查看输出确认包含点阵。本项证明本地预览/导出流程内部一致，不能替代原版画面对比。

`npm run build` 通过（仍有既有的大文件体积提示），另外 11 组实际普通相机 Worker/渲染器回归通过。

执行入口：

```sh
node scripts/verify-ordinary-source-camera-export.mjs --surface-particles
node scripts/benchmark-source-surface.mjs
```

上述浏览器验证需要本机 Chrome；过程使用隔离导出服务目录，不覆盖用户作品。

## 本机成本测量

公式任务为 30,000 个点、每点三条相同公式，共 90,000 次 Double 求值。两条路径输出字节哈希一致。编译和模块加载不计入任务计时，首次任务标记为冷，后两次保留运行时/JIT 状态。

| 路径 | 首次耗时 | 后两次耗时 | 首次 CPU 时间 | 后两次 CPU 时间 | 进程峰值 RSS |
|---|---:|---:|---:|---:|---:|
| 每次使用既有源标量解析器 | 146.5 ms | 127.8–128.0 ms | 197.3 ms | 131.9–136.7 ms | 242.6–243.0 MiB |
| 编译一次后更新变量槽 | 13.5 ms | 10.2–14.6 ms | 19.8 ms | 16.4–24.1 ms | 163.1–177.0 MiB |

另测完整本地任务：导入、保存重开、40×20 点曲面及相机、颜色，连续请求 20 个时刻。首次耗时 205.5 ms、CPU 241.0 ms；后两次耗时 178.6–181.4 ms、CPU 182.4–185.8 ms；进程峰值 RSS 为 219.0–242.4 MiB。该任务没有等价原版运行基线，不能声称比原版更快。

每种任务使用独立 Node 进程，计时区间没有子进程；RSS 为进程累计高水位，不是单次任务新增内存。浏览器进程族内存、GPU/显存、视频编码吞吐和代理 token 成本未测量。当前每次跳转从头回放，顺序视频帧尚未复用粒子状态；不能由小任务结果推断长动画性能。

## 仍需完成

曲面拖尾分段、GPU 与网格目标身份、模式切换、参数/渐变动画及更大任务的性能验证。颜色、点外观、原版实时帧率、平台数学函数差异、原版应用完整静态图和逐帧动画尚未验收。

源依据为 MathArt Studio 1.7.8 保留 JAR，SHA-256：`a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。本批使用其静态指令证据，没有把本地测试或独立渲染器当作原版应用运行证据。重新访问原版应用窗口时，系统工具仍报告 Mac 锁定、自动解锁失败；原版窗口对照需要解锁后继续。
