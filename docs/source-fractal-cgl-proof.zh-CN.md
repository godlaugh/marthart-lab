# 分形原生绘制：普通与深缩放的精确对照

2026-10-26。**已找到可验证的原生绘制路径：当前产品的 Mandelbrot 着色器与自己生成的输入，在独立 CGL 中绘制的三个固定样例，完整数学 RGBA 均与保留的原生参考逐字节一致。** 本轮交付可重复运行的验证命令；尚未接入桌面应用，当前桌面包仍是 `2.0.0-preview.5`，M3 继续进行。

## 此次解决了哪一个问题

[此前残差调查](source-fractal-native-residual-validation.zh-CN.md)确认：同机浏览器与原版 OpenGL 的算术执行有差异。浏览器里的舍入候选虽改善浅缩放，两个深缩放样例仍不一致，不能直接用于产品。

本轮保留当前产品的双 float 算术、扰动、公式与着色实现，只把着色器接口从 GLSL ES 300 适配到桌面 GLSL 330。程序运行在系统 CGL；不加载原版 JVM、库或应用，不打开窗口，也不调用原版受限操作。

先以原版已保存的输入校准 CGL 宿主，再换成**产品真实导入和运行后产生的输入**。两种方式均精确匹配。第二步由实际 `FractalSourceNewtonGpu` 上传参数、生成参考轨道与渐变纹理；读回所有活动 uniform 的全部数组元素。它没有用原版数据覆盖产品输入。

| 固定样例 | zoom 值 | 迭代上限 | 产品参考轨道 | 完整数学 RGBA 差异 |
|---|---:|---:|---:|---:|
| 原版默认 Mandelbrot | 0.5 | 300 | 不启用扰动 | 0 字节 |
| 较深视图 | 100000.125 | 800 | 800 项，与原版逐字节相同 | 0 字节 |
| 更深视图 | 1000000000.125 | 1200 | 1200 项，与原版逐字节相同 | 0 字节 |

每张图均为 500×600、1,200,000 个 RGBA 字节，包含 alpha；三张共 900,000 像素。没有裁剪、容差或像素特例。三组产品渐变纹理也均与原版的 1024 项 RGB32F 字节相同。

## 证据究竟覆盖什么

最终验证使用原版未删减 JSON；深缩放仅改变 center、zoom、iterations。浏览器中的实际显示所有者推进四次，每次只采样一个像素以产生当前程序和完整上传状态；随后独立 CGL 绘制完整画面。这验证生产输入与数学绘制边界，**不是实际桌面应用已使用 CGL 的证明**。

参考是历史原版独立 OpenGL 数学缓冲，它此前已与实际 Scene 的中心数学区域校准。此次全缓冲对照没有包含原版窗口、水印或公式叠加层。因此不能把结果称为原版整窗、整个分形家族或任意深缩放通过。Newton、Nova、其它公式、动画、预览/导出生命周期与另一台 Mac 仍须分别验收。

活动参数核对共有 53 个同名 uniform。原版使用 transform，独立产品顶点直接使用裁剪空间；产品另有两个轨道诊断 uniform。动态参数数组为本地 32 项、原版 24 项，共有部分字节一致，新增尾部为零；完整图像对照证明这些表示差异未改变本组三例输出，不外推到其它参数组合。

## 复验与运行成本

从 `studio/` 执行：

```sh
PATH="$PWD/../.cache/local-toolchain/node_modules/.bin:$PATH" \
node scripts/verify-source-fractal-cgl.mjs
```

命令使用项目锁定依赖、已有 Chrome 和系统编译器；不需要原版应用或私有大缓存。参考说明见[固定样例](../tests/fixtures/source-fractal-cgl/README.md)。校验固定三例、完整原图摘要、生产纹理摘要、源码稳定及进程清理；不会在空矩阵或缺少样例时报告通过。

最终命令通过，总耗时 **4.28 秒**，包括原生宿主编译、浏览器输入捕获、三次 CGL 绘制和关闭。各 CGL 子进程耗时约 1.20、0.15、0.16 秒；CPU 各约 0.06 秒，单进程 RSS 峰值约 27.3 MiB。每例均是新进程，系统/驱动缓存未清空；这不是冷机性能、暖会话复用或动画 FPS。Chrome、Vite、编译器的 CPU 和进程族峰值内存、GPU 内存尚未测量，也没有建立等价成功工作流的前后加速比例。

本轮 Goal 工具计数从 97,816,500 到报告快照 98,079,511，差值 263,011 tokens，包含调查、上下文和失败重试，不是每次绘制成本；快照之后的收尾未计入。验证脚本本身不调用模型。

最终运行所有原生子进程 exit 0、进程组为空；浏览器和 Vite 已关闭，593 个源码及输入文件摘要前后稳定。本轮没有修改生产代码，未运行全套测试或重建桌面包。

早期输入观察器最初只读取 uniform 数组的第一个元素；该组探索被单独保留，最终版本逐项读取全部元素并重新验证。另一次关闭依赖预构建导致浏览器模块导入失败，恢复正常依赖发现后重跑成功。这些失败及不完整记录不计入最终通过。
