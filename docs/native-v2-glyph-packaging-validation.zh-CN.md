# 独立公式服务随 2.0 预览应用打包

2026-10-26。**MathArt Lab 2 Preview 2.0.0-preview.2 已内置独立公式服务**，运行时不再依赖项目缓存里的 Java/JAR。21 组原版字形记录在签名后的包内运行时及实际桌面 HTTP 入口均逐字节一致；带公式的真实预览和 PNG 导出通过。**M3 仍在进行，11 类场景的全部效果一致性尚未验收完成。**

## 本机应用与构建

应用仍位于 `dist-desktop-v2/MathArt Lab 2 Preview-darwin-arm64/MathArt Lab 2 Preview.app`，现在约 **376 MiB**（磁盘占用 384,632 KiB）。双击即可使用包内服务，工作区与现有 1.0 分开。

构建命令为：

```sh
npm run desktop:build:v2 -- --glyph-backend /absolute/path/to/backend.json
```

配置需要 `javaHome` 和 `jarPath` 两个绝对路径，分别选择已存在的独立 JDK 和官方 JLaTeXMath 1.0.7。也可通过 `MATHART_GLYPH_BACKEND` 选择文件。构建会重新编译仓库内的 `FormulaGlyph.java`，不直接拿缓存 helper 作为产品源码。

本轮使用先前从官方取得并校验的 Temurin 21.0.7+6 和未改动的 JLaTeXMath。没有安装系统 Java、修改全局 PATH、下载额外软件或使用 MathArt Studio 的代码与运行时。

## 打包和身份检查

`jlink` 仅保留 `java.desktop` 及其依赖，裁剪后的运行时约 78 MiB；运行时、两个 JAR、自有 helper 源码及说明合计 80,890,664 字节。运行时 39 个许可文件和上游 JAR 内的许可/字体声明均保留。

打包工具复制额外资源时会解析符号链接，直接携带 jlink 的链接可能指向临时构建目录。因此构建在自己拥有的输出目录验证链接不越界，再复制为普通文件；最终公式资源中没有符号链接。运行时和 JAR 使用固定相对位置，manifest 读取时拒绝路径替换、架构不符、未知字段及无效摘要。

实际文件检查和进程管理仍由公式服务统一负责。新增 helper 摘要约束让已有 `helperJarSha256` 真正参与执行前验证，格式错误或内容不匹配会拒绝运行。显式外部后端选择仍优先，失败不会自动寻找其它 Java。

桌面宿主已把公式后端交给同一本地 API 服务，应用退出仍等待所属进程清理。Electron、JVM 原生代码和外层应用的本地 ad hoc 签名通过 `codesign --verify --deep --strict`；这不表示已完成 Developer ID 发行签名或 Apple 公证。

测试启动的是最终 `.app`，清除外部原生/公式后端覆盖变量，在隐藏窗口和隔离数据目录中操作，没有替换引擎或服务响应。最终页面和观测器错误为空。两次应用退出码均为 0，所观察的应用进程组为空，本地端口关闭。原生 helper 和 app.asar 在验证前后不变。

还把完整应用复制到另一个含空格的目录：14 个包内链接均指向新包内部，完整签名验证通过，从新资源位置启动后生成的 Cornucopia 字形仍与原版记录一致，退出码为 0、进程组为空，测试副本已清理。首次移动测试的清理记录访问了已关闭的 Playwright 对象而失败；保留原始失败，确认原进程组已退出并清理副本后，改用启动时保留的子进程句柄复验通过。这是本机路径迁移检查，不代表跨设备验证。

## 测量与未覆盖项

包内服务完整验证耗时 **33.07 秒**，子进程 CPU **29.98 秒**，同进程组采样 RSS 峰值 **275.1 MiB**。包含 21 组字形及错误/生命周期检查，不能当作单次渲染延迟。

Cornucopia 版本的完整桌面验证耗时 **34.13 秒**，子进程 CPU **43.62 秒**。应用组采样峰值为 **1114.3 MiB**，重启组 **545.8 MiB**，外层验证驱动组 **275.0 MiB**。这些是不同组的峰值，不相加当作同时峰值。CPU 包含采样开销，0.5 秒采样可能漏掉短峰值；GPU 显存、能耗及温度未测。进程新建，系统缓存未控制，没有等价旧版完整任务成本基线，也不宣称性能改善。Goal continuation 的 token 读数至本报告观测点增加 67,637；不含之后收尾，没有缓存拆分或等价旧工作流基线。

此次补齐的是本机预览包的公式依赖及已测交付链路，没有关闭全部场景一致性需求。所有 11 类范围保留；Map/Symmetry 冷重放及自定义 Symmetry 的 Worker 路径、更多公式与视频场景、各类剩余原版对照继续。只有这台 Mac，跨设备仍未验证，不再重复询问。

原始记录在 `.cache/native-v2-glyph-20261026/index.json`；最终 UI 为 `ui-cornucopia/`，真实服务为 `verify-packaged/`，原型和较早简单曲面结果也保留。二进制、JDK 和本地证据不进入 Git。
