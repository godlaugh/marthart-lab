# 曲面当前暂停画面 PNG 验收

2026-10-22。开发分支 `codex/v2-scenes-parity`。本轮完成曲面的当前暂停画面 PNG 导出；2.0 整体 Goal 仍在进行中，原版整窗效果一致性仍为 **0/11**。

## 现在可以做什么

导入原版曲面场景，播放后暂停，修改参数，然后选择“导出作品”。图像来源默认是“当前暂停场景”，支持自定义尺寸和 1×、3×、5× 放大。

截图使用已保留的曲面对象、参数和相机，不按时间重建。截图前后不推进动画，也不重新应用编辑器配置；导出完成后可以继续播放或点击 Apply。CPU 点模式仍保留原版的更新时机：暂停时直接修改函数参数，不会立即重算已有点位置。

## 实现和依据

Worker 中的曲面会话生成离屏几何和主预览几何，保持同一对象与队列。浏览器用现有 ArtRenderer 在独立画布绘制离屏结果，回读像素，再复用现有增强、放大和公式 PNG 编码流程。队列在截图完成前保留独占权，场景变更后丢弃旧任务的发布。

原版已保留的 MathArt 字节码显示，`savePausedFrameInternal` 在暂停状态调用当前场景的 render，之后增强并可选放大，没有调用 Scene.update。这是静态依据；本轮没有执行原版截图链路，也没有取得原版像素作为参考。

图像分配前检查尺寸和放大预算，客户端另检查收到的几何缓冲与图像预算合计，绘制前检查实际 GL 尺寸限制。256 MiB 是这些显式 CPU 缓冲的准入限制，不代表整个进程、Worker 中已存在的几何或 GPU 内存峰值。
