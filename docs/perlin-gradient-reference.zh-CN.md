# Perlin 渐变参考行为核对

2026-10-19。固定参考 MathArt 1.7.8 JAR 的 SHA256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。以下为包内类文件的静态观察与推导，没有运行原版应用。

原验收清单把“Cosine／Curve／HSV 缺函数参数渐变”当成 Perlin 的原版缺项，这个判断不准确。

原版 Perlin 编辑器可用 Manual、Cosine、Curve；Cosine 和 Curve 会先生成 2–25 个普通颜色，写入作品 palette 数组，再交给同一个运行时动画器。相关枚举没有 Sine／HSV。不能把本地函数色图的参数动画当成原版 Perlin 的运行合同。

| 原版动作 | Perlin 实际消费方式 |
|---|---|
| HUE_ROTATE | 色板主偏移，并非直接对 RGB 色标做 HSV 色相旋转 |
| OFFSET_CYCLE | 内外两个偏移的平均值 |
| CROSS_FADE | 同一色板在两个偏移处的采样混合，并非两组任意色标的单程过渡 |
| PALETTE_MORPH | 主偏移与外部偏移的采样混合 |

RGB、Linear RGB、OKLab、OKLCH 四种颜色插值确有执行路径。Perlin 动作构造器强制启用两个影响区域；CPU 粒子、曲线及 GPU 纹理均接入动画器。停止动画本身不触发颜色重新生成，只有实际状态变化才刷新；GPU 使用 256 项颜色纹理。曲线模式下，初始化时生成的空间色圆还保留自己的固定颜色，不能随每帧渐变重新生成。

当前本地实现的色相变换、双色板过渡、动画速度、停止刷新时机和 GPU 色板采样与这些源规则仍有差距。因此 MAS-NOI-033／034 **仍未完成**，独立的源 Perlin 色板状态、原始渐变动作解析与共享队列调度已实现；尚待接通作品导入、编辑及粒子、曲线、GPU 三个消费者，现有作品继续使用本地模型。

## 专属参数运行时与组合调度

2026-10-19 后续更新：`sourcePerlinParameterConfig.ts` 和 `sourcePerlinParameterRuntime.ts` 已接入共享队列的 Perlin 参数入口。参数与渐变使用同一次场景时钟；原始参数动作会按固定顺序读取 noise_offset、noise_scale、curve_noise_scale、curve_angle_scale，保留 double 配置与 float 字段的区别。

| 已实现边界 | 行为 |
|---|---|
| 参数数值导入 | 使用原版 getDouble 默认值与范围交换／限制，不求值表达式；异常格式用默认值，非有限数值因本地不可回放而明确拒绝 |
| 参数与渐变组合 | 所有参数动作先开始，再开始最后有效渐变；参数逐项更新及结束后，再更新渐变，最后推进对象 |
| 零／负时长 | 专属参数使用终点缓动；不套用普通动画的零除零结果 |
| 片段结束 | 开始持续振荡；同帧的对象更新可再次推进。旧振荡不会因新参数片段自动暂停 |
| 后端区别 | GPU 仍接受动作直接赋值，但对象更新不推进持续振荡；CPU 粒子只推进 noise_scale，CPU 曲线推进四项 |
| 曲线几何事件 | setter 按 CPU 样式发出角度场重建／几何失效请求，即使当前选中 GPU；样式与后端独立。实际几何消费者仍待接入 |
| 队列结束与回退 | 队列结束后冻结对象状态；倒退重建参数与颜色两个状态，避免使用未来值 |
| 资源与失败 | 保留原版逐次相位约简的舍入；超过本地单次 100000 步预算、取消或消费者失败时终止该状态，要求重建 |
