## 实测结果

艺术画面指原版完成几何与配置启用的公式、尚未绘制品牌叠加层的阶段。Cornucopia 的一组自动主方程没有增加几何阶段已有的像素差异；另外两份原配置关闭主方程。比较使用整张图像，未裁剪、重采样或用掩码跳过覆盖区域。

Möbius 唯一不同像素位于 `(71,257)`：本地为 `[139,154,33,255]`，原版为 `[255,255,255,255]`。它处于网格线与填充的覆盖差异，尚未定位到具体顶点／线段及深度计算；不能仅凭像素数很少而忽略其高对比差异。

最终含原版品牌叠加层的增强 PNG 仍整体参与比较，Cornucopia、Sphere、Möbius 分别有 12,172、13,526、7,151 个不同像素，最大通道差均为 222。这些计数混合了上述几何残差、后处理传播及原版品牌内容，**不能全部归因为水印**。

已查看本地 Cornucopia 与 Möbius 的实际增强图，能看到对应点构图、自动方程和网格。视觉可辨认不替代严格像素校验。

## 原版运行边界

固定 MathArt 1.7.8 JAR，SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。三个输入均为包内原始 `SurfaceConfigs` JSON，没有改变采样、公式、时间线或模式以制造一致结果。

复用已验证的后台 staged-loader 宿主和原版 bundled JVM，调用原 Scene 的 `runFrame(buffer,true)` 一次，保持初始暂停时刻。主画布逻辑尺寸 405×486、density 2；导出逻辑尺寸 250×300、物理尺寸 500×600，关闭导出 MSAA。通过被动 GL 转发读取公式绘制前的完整图像、每次纹理绘制后的图像及实际纹理／属性，原绘制参数和返回值不变。完整 raw PNG 和增强 PNG 由原版方法输出。

三个原始采集分别耗时 8.80、6.12、9.46 秒，退出码均为 0，进程均已回收，进程组不存在。窗口对象和可见窗口检查始终为 0。正常执行原版 VIEW / RUN / EXPORT 权限检查并保留水印，500×600 未超过许可的导出上限。策略缓存写入前有备份，变化来自原版正常策略刷新；settings 与 license 文件的存在状态和摘要保持不变。

Cornucopia 与 Sphere 另在独立原版进程中采集实际点输入，其完整几何图与首次采集字节相同，排除了这两张初始参考的随机运行漂移。

## 已排除和仍待定位的原因

| 检查 | 证据与结论 |
| --- | --- |
| 点精灵纹理 | 两个点场景的实际原版纹理与本地生成纹理，64×64 至 1×1 全部 7 级 RGBA 均相同 |
| 顶点变换发生位置 | 原版点程序收到已在 CPU 变换到视图空间的顶点，shader 的模型视图矩阵为单位阵；本地当前传世界坐标并在 GPU 变换 |
| CPU Float32 计算顺序 | 逐乘法、逐加法舍入得到全部 1,724 个中心点的 5,172 个原版坐标，差异为 0；每个原版四边形的四份中心坐标也相同。直接双精度求和后舍入有 725 个坐标不同 |
| CPU 视图变换候选 | 仅在诊断 Vite 转换中试用，Cornucopia 的不同像素从 3,905 降到 3,898，Sphere 不变；未消除主要残差，未集成 |
| 关闭本地 DITHER | 两张图的差异数、最大差和总差均不变 |
| 改为归一化 Uint8 RGBA 顶点颜色 | 两张图的差异指标不变；未集成该诊断改动 |

当前证据不能将剩余差异确认为片段着色器、插值、纹理采样或混合阶段中的某一项。下一步应使用实际原版顶点／uniform 的独立绘制来隔离这些阶段，并读取 Möbius 的线段／填充提交；不做逐像素补丁，也不把根因未明的 CPU 变换推广到其它消费者。

## 可复跑验证与证据

新增 `scripts/verify-surface-native-reference.mjs`，从真实导入器和 Generator/Worker 创建暂停曲面，再调用生产暂停截图、字形服务和公式合成器。使用独立 PNG 解码比较完整增强文件，绑定原版输入、探针、JAR、绘制阶段图像及当前源码摘要。当前运行耗时 27.57 秒，结果为 `differences`、退出码 **1**；源码和参考前后摘要相同，字形服务剩余进程为 0。此退出码是已确认的真实残差，不能作为绿灯处理。

```sh
node scripts/verify-surface-native-reference.mjs
```

证据位于 `.cache/surface-native-reference-20261023/`：

- `native-cornucopia/`、`native-sphere/`、`mesh/native-mobius/`：原版完整输出、分阶段捕获、探针及运行记录。
- `verified/report.json`：正式生产路径整图比较；同目录保存本地产出的底图与增强 PNG。
- `point-state/`、`point-boundary.json`：实际原版点输入、纹理各级及 Float32 坐标检查。
- `product-view-f32/`、`product-no-dither/`、`product-packed-color/`：三个隔离诊断，不是产品修复。

本轮耗时是采集和验证的墙钟记录，未测 CPU、RSS、显存及 token 成本，不作性能改善结论。GPU 曲面、连续动画、全部指南配置、完整原版窗口操作与 Apple Silicon 发行仍待验收；Goal 保持进行中。
