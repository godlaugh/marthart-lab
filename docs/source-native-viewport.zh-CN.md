# 曲面原生预览验收（2026-10-24）

原生曲面渲染现在可以直接显示在实际 App 的预览画布中。只有像素和公式都准备好后，画面才被标记为可用，播放才继续推进。快速调整尺寸时会取消旧请求，迟到的结果不会覆盖新画面。

这项功能目前通过 `VITE_SOURCE_RENDERER=native` 启用，覆盖符合源曲面规则的 Surface 场景。默认 WebGL 路径未切换；Apple Silicon 应用内原生组件的打包与发行验收仍未完成。

## 实现与修复

- 预览只保留一个活动操作和一个可替换的待处理请求。旧操作实际结束后才创建下一份渲染快照，避免占用同一个原生请求槽。
- 空公式列表直接复制像素，不给旧项目虚构新的公式布局。原版布局使用已有字形合成器，本地布局保留 MathJax 排版；均在完整合成后提交。
- 已完成的画面携带“公式已合成”状态，录像消费该画面时不会重复叠加公式。不同宽高比的录制预览保持比例。
- 原生合成器回收失败时保留其所有权，允许重试；组件卸载仍会释放其它渲染资源。
- PNG 验收按请求的采样配置分别识别预览和导出，替换了“页面只能出现两个原生请求”的过时假设。

## 证据与范围

本地证据目录为 `.cache/source-native-viewport-20261024/`：

- `ui-final/report.json` 与四张截图：最终预览、播放等待、取消和字形等待检查。
- `capture-classified/report.json` 与下载 PNG：导出回归。
- `recording-regression/report.json` 与视频：四组完整录制流程。
- `tests-final.log`、`build-final.log`：测试和构建输出。
- 早期失败记录保留在 `ui/`、`ui-diagnostic/`、`capture-regression/`，未覆盖。

每份浏览器报告保存运行前后代码哈希，运行期间代码保持一致。PNG/录制回归在最终卸载清理的 `finally` 调整前完成；最终预览与构建包含该调整。没有将不同运行伪称为同一次最终版本验收。

最终四组预览耗时 16.284 秒，进程族观察到 CPU 32.070 秒、采样峰值 RSS 2061 MiB。四组录制耗时 47.083 秒，CPU 71.590 秒、峰值 RSS 2553 MiB。采样分别为 53 次和 153 次，无采样错误；短命进程可能漏采。同期存在测试／构建负载，没有清空系统缓存或进行等价旧版比较，GPU 内存与 token 成本未测量，不能据此声称性能改善。

本轮使用无窗口 Chrome 与原生离屏服务，没有操作用户屏幕。它验证了产品预览交付和完整工作流；无公式像素对比的基准是对应原生服务响应，不是原版 MathArt 的整个窗口。原版艺术画面及最终遮罩的对照证据见[曲面切换与公式叠放验收](source-surface-transition-formulas.zh-CN.md)。其它场景族的效果一致性、更多尺寸／透明度和 Apple Silicon 打包发行仍在 2.0 Goal 中继续推进。
