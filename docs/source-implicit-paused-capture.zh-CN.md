# 隐式曲面暂停画面 PNG 验收（2026-10-24）

**录制后暂停的隐式曲面，现在可以直接保存为 PNG。** 导出使用后台实际保留的相机与动画队列状态，不再按文档 FPS 重算当前画面。修改导出尺寸、重复保存和取消后重试均不推进动画。

这是 2.0 预览源码的增量；已安装的 1.0 应用尚未替换，2.0 整体仍未发行。

## 使用方式

1. 对支持的原版 CPU 隐式曲面进行队列录制，停止后从录制状态继续播放。
2. 暂停，点击「导出作品 → 静态图像」。图像来源默认选中「当前暂停场景」。
3. 设置基础尺寸和 PNG 放大倍率，点击「开始导出」。保留「从初始状态重放」选项供主动选择。

此入口依赖录制后的真实延续会话。一般静态预览仍沿用原有重放方式；编辑文档或跳转时间会结束延续会话。

尺寸遵循原版像素密度取整。例如主预览密度为 2 时，输入 65×49 对应实际基础图像 66×50，界面会显示实际输出尺寸。1×、3×、5× 复用公式合成、基础图像增强和放大流程。

## 实际验证结果

| 验证 | 结果 |
| --- | --- |
| 真实 App 导出暂停 PNG | 两次 66×50 保存完全一致；128×96 基础图像放大 3 倍得到 384×288 |
| 取消原生绘图请求后重试 | 取消不下载；重试 PNG 与第一次完全一致 |
| 状态保持 | 保存前后相机、动画时间、队列位置不变，之后可以继续播放 |
| 原版已采集画面对照 | 35 个 384×288 状态逐像素零差异，其中 6 个暂停状态通过实际截图接口获取 |
| 失败与边界测试 | 拒绝过期或复制的预览、篡改响应、超限尺寸；几何生成失败以及缓冲转移前后交付失败可重试，均不多推进一帧 |
| Surface 共享流程回归 | Cornucopia、Sphere、Mobius 的真实 App PNG 下载、重复保存通过；Mobius 取消后重试通过 |
| 录制回归 | 自然结束、手动停止、取消重试、空队列、导出入口和保存恢复六组真实 App 流程通过 |

原版对照复用了有源码摘要和原始输入记录的离屏参考，使用原版完整 60³ 网格。原版 JAR SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。参考图是品牌叠加和图像增强前的作品区域；本轮没有重新运行原版 GUI，也不声称原版最终 PNG 文件字节相同。

实际 UI 使用 12³ 网格、真实 Worker、原生绘图服务和 FFmpeg。PNG 下载与实际暂停基础图像经过共享编码器后的结果逐通道相同；这项交付检查不是独立的原版 PNG 编码器对照。1×、3× 完成实际下载；5× 的尺寸与状态覆盖来自 Worker 及已有共享图像流程测试，没有额外声明此次完成 5× UI 下载。

## 实现与维护

数值会话通过准确的已完成主预览身份授权截图，只读取当前队列显示状态。导出几何与预览几何分别生成，传输缓冲失败不会破坏数值状态。客户端验证作者文档、会话、相机、队列及公式；取消只终止本次出图，保留可再次使用的暂停会话。

原有 Surface 专用截图模块已改为共享几何截图模块，移除了旧模块，保留原有 Surface 公共操作。Surface 继续使用逻辑尺寸和 DPR；Implicit 的线宽已经包含源像素密度，因此采用物理尺寸与 DPR 1，避免重复放大。两个场景共享资源释放、容量检查、原生读取和图像编码。

验证没有打开或移动用户窗口，全程后台运行。
