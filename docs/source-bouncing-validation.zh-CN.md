# 弹跳场景：2.0 实现与验收进度

更新时间：2026-10-19。当前处于 **M3：场景补全与一致性验证**。

原版运动模块与初始化模块已独立实现。**尚未接通界面的完整原版弹跳流程**；当前界面的旧本地模型仍使用自己的采样与碰撞算法。原版 JVM／JOGL 整图验收仍为 **0/11**，1.0 Apple Silicon 应用包没有替换。

## 已实现的行为

- 原版配置默认 20 万粒子、2 个子步；内置 `bouncing1` 示例请求 200 万粒子。这两个来源分别保留。
- 使用 Java 48 位随机数序列和完整有符号 64 位种子。每个粒子先采位置，再采速度；没有角度抖动时不额外消耗随机数。
- 支持全部 14 个初始化模式及填充／轮廓选项。原版 `ARCHIMEDEAN_SPIRAL` 实际落到 BOX，依照这个分派保留。
- 保留各形状的原版公式、Float32 运算顺序和丢弃随机值的行为；没有改成数学上更常见的曲线定义。
- 外层最多尝试 512 次，失败后仍保留粒子并放在容器中心或多边形顶点均值处。部分形状内部还有独立的 512 次尝试。
- 支持均匀、随机、径向向外／向内、顺时针／逆时针切向六种速度模式。
- 公式使用原版 FastExpression 语义，只绑定世界坐标 x/y。语法错误明确返回失败；轮廓模式是接受采样点后加抖动。
- 初始状态为连续的 `[x, y, vx, vy]` Float32 数组；GPU 负责纹理补齐和后续运动。圆、椭圆和多边形更新均保留原版每子步最多四次碰撞。

配置解析保留设置节是否出现、多边形来自根对象或设置节、被读取字段路径及数字字段路径。原作者内容仍由导入文档保存；这部分初始化投影不宣称完成颜色、相机或整个原版文档的验证。

## 验证范围

相关 **11 个测试文件、160 项测试通过**；TypeScript 检查与 Web 构建通过，构建保留已有大 chunk 提示。

运动模块已与独立提取的原版着色器在同一浏览器 GPU 上核对：13 组案例、72 份完整纹理状态零差异，包含 20 万与 200 万粒子。缺失浮点能力、编译失败、取消、上下文丢失、删除失败重试五类检查通过。

初始化另用独立 Python 解释器执行保存的原版字节码：**74 组配置、1,258 个粒子、5,032 个 Float32 通道及全部最终随机数状态一致**。其中 24 组公式案例执行原版比较包装和采样字节码，但内部表达式只用独立的有限算术适配器核对常量、x/y、四则运算和比较；完整 FastExpression 解析与函数库不属于这项独立对照。解释器使用 Python 数学库和显式 Java 基础类型适配，不能代替原版 JVM 的数学库或完整画面验证。原应用自带 Java 库的直接加载探针停在系统动态库加载阶段，尚未执行 Java 初始化方法；未修改原应用、运行时签名或隔离属性。

## 完整初始化成本

每组使用三个独立 Node 进程，各执行一次冷首任务和一次暖新任务。任务包括配置解析、全部粒子初始化、世界边界和完整结果哈希；重复结果一致。耗时与 CPU 取中位数，RSS 取三次最大值：

| 配置 | 冷／暖耗时 | 冷／暖 CPU | 冷／暖进程峰值 RSS |
| --- | --- | --- | --- |
| 默认 20 万粒子 | 120.46／106.17 ms | 134.20／115.63 ms | 64,096／67,456 KiB |
| 原包 bouncing1，200 万螺旋粒子 | 781.29／790.48 ms | 792.94／802.34 ms | 92,224／125,424 KiB |

任务期间没有子进程，因此进程族为该 Node 进程。模块加载与输入读取不计入耗时／CPU，但计入累计峰值 RSS；暖任务 RSS 也包含此前冷任务，冷启动没有清空操作系统缓存。原版 JVM 成本、浏览器／GPU、视频导出及 token 未测。此前没有等价的原版初始化实现，旧本地算法的随机序列和形状不同，未拿它充当性能基线。这些数字不代表实时播放帧率。

## 资源限制与剩余工作

初始化数组最多 128 MiB，总工作预算为 6,400 万单位（采样候选、公式节点、边界边与速度计算）。先检查完整请求的最低工作量，再按实际尝试扣费；超额或取消会返回失败，不减少粒子数，也不返回不完整数组。它不是 CPU 指令数或时间保证。

GPU 状态表示另有 256 MiB 预算，暂不支持原版 500 万粒子示例；不会自动降低粒子数量。初始化耗时与播放、绘制、视频导出耗时是不同指标。
