## 原版艺术画面对照

本轮复用已封存的 MathArt Studio 1.7.8 VIEW/RUN 记录，没有启动原版，也没有调用原版 EXPORT。输入原始场景、画布尺寸和外部时钟，经生产入口 `Generator → 本机 HTTP → CGL` 生成画面。初始化随机状态、Processing 上下文、自动参数和更新次数均由本地实现产生，没有把原版观测到的内部值或像素作为渲染输入。

13 组覆盖标准自定义公式、setter 类型、较小画布、参数动画、重新初始化、相机／世界配置、同名类型冲突、布尔参数、特殊输出布局、多输出、非有限值和 discard。每组 8 帧，**完整比较 303,918,112 个 RGBA 字节，差异为 0**。只将原版自下向上的行顺序转换为自上向下，没有裁切、颜色补偿或容差。

这里的“完整艺术画面”指原版 `presentAccumulation` 之后、覆盖层之前的 `core.rgba`。原版 `Scene.runFrame → flush` 之后的 `preview.rgba` 包含覆盖层，未计入本次通过范围；整个应用窗口也未计入。`world` 用例是普通帧的世界／相机配置，不等同于 world replay。

标准样例为 562,144 粒子、810×972 像素。下面两张图由对应的原始 RGBA 无损生成，艺术缓冲逐字节一致：

原版观测有边界：它使用原版 JOGL 绘图和 `noSmooth()`，读取像素会同步 GPU，并临时修改后恢复相关读取状态，还会清空 GL 错误队列。因此不能称为完全无干预的录制，也不能由本次像素一致推断原版没有 GL 错误。原始错误和状态记录保留。本次验证器检查完成标记、连续帧号及原始摘要；空帧列表、重复帧号和被改动的源码均被拒绝。

## 桌面实测发现并修复的问题

第一次新包验收中，暂停截图成功，但自定义 Symmetry 的“从初始状态导出”明确报错：缺少主画布尺寸及像素密度。导出界面已有迭代场景的密度参数，却错误地使用了几何场景的密度字段；此外，主界面只在存在实时会话时提供该参数，不能覆盖延迟开始或不保留轨迹的冷预览。

现在导出从**同一场景已完成的主画布图像**读取物理尺寸和逻辑尺寸，校验后取得密度；不使用更新更晚的显示器测量来补猜。显示策略在创建 viewport 前为 Processing 场景选择整数密度，普通显示路径继续保留非整数比例。

修复后重新构建，实际运行最终桌面包：

| 检查 | 实际结果 |
|---|---|
| Map、内置 Symmetry、自定义 Symmetry | 三个样例的原生预览、参数热改、播放与暂停通过，热改没有重建计算所有者。 |
| 自定义 GLSL 编辑 | 含宏源码由实际原生驱动生成候选首帧；候选资源释放确认后才发布主预览。 |
| 暂停 PNG | 三个样例实际下载 160×120 PNG，完整 RGBA 与原生捕获经过既有图像增强后的结果一致。 |
| 从初始状态导出 | 三个样例各导出两次；完整 PNG RGBA 等于原生输出，重复结果一致，恢复播放不替换主预览资源。 |
| 关闭与重新打开 | 场景名、参数和编辑后的完整 GLSL 恢复，界面重新就绪；此项未单独证明重启后的全部 native 通信或整图一致。 |
| 公式服务 | 21 个字形样本及 Cornucopia 公式开／关的两次图片导出通过。 |
| 1.25 倍显示缩放 | Chromium 显示参数模拟下，自定义场景的编辑、播放、两种 PNG 导出及重开通过。这是本机模拟，不是第二台设备。 |
| 资源清理 | 测试应用均正常关闭，拥有的进程组为空；服务监听地址关闭。 |

所有窗口以隐藏模式运行，测试使用独立工作区，没有切换用户工作屏幕。首次失败记录保留，没有算作通过。

53 项相关自动测试、39 项桌面测试、TypeScript 检查和最终桌面构建通过。相关测试包含真实 CGL 通路和模拟 ACK 的边界检查；没有把模拟项算作真实驱动验证，也没有声称执行全部测试套件。构建仍有既有 bundle 大小提示。

## 测量与证据

| 最终运行 | 耗时 | CPU | 同时进程组 RSS 采样峰值 |
|---|---:|---:|---:|
| 13 组完整艺术缓冲对照 | 67.58 秒 | 114.19 秒 | 674.0 MiB |
| 桌面三场景、公式及重开 | 52.57 秒 | 观测下界 59.06 秒 | 1298.2 MiB |
| 1.25 倍缩放补验及重开 | 11.70 秒 | 观测下界 18.05 秒 | 893.0 MiB |

整图验证为每组新建进程、重新编译渲染器，再在同一所有者内推进后续帧；不是清空系统缓存的严格冷启动。标准样例首帧 811.55 ms，后续七帧中位数 70.04 ms；这些帧计时包含完整 RGBA 比较及文件写入，不能当成纯渲染速度。CPU 包含监督器的采样开销。桌面 CPU 由每个进程身份的采样最大累计值求和，只是观测下界；不含验证驱动程序。RSS 每 0.5 秒采样，可能错过短峰，未测 GPU 内存。没有等价旧实现基线，不声称性能提升。

本轮 Goal 工具计数从 97,120,394 到报告快照 97,404,239，差值 283,845 tokens。这是整个工作区间的工具累计统计，包含调查、失败重试和上下文，并非每帧生成成本，也不含快照后的报告与提交操作。验证脚本本身没有模型调用。

本机证据保存在 `.cache/source-symmetry-full-image-20261026/` 和 `.cache/source-symmetry-desktop4-20261026/`：原版输入摘要、完整帧、最终源码快照、实际下载、测试与构建日志、签名结果及证据索引。这些文件不随 Git 分发；本报告可直接阅读。
