# Map／Symmetry 参数编辑验证

2026-10-19，M3 进行中。原版 JVM／JOGL 整图验收仍为 **0/11**。

## 修复内容

同一作品中，连续 Map／Symmetry 的数值参数编辑现在保留 Worker、GPU 上下文和已编译程序。修改数值仍会清除原有轨迹与密度，从种子重放到当前时刻；没有把编辑改成对历史累积图像直接热更新。

问题同时存在于两层：预览队列把新作品对象当成必须终止 Worker 的请求；生成会话又把重放身份变化当成必须释放 GPU 程序。现在队列合并同作品的待处理编辑并屏蔽过时结果，会话只重置运动状态，编译器按已有源代码键决定是否编译。倒退定位同样重放，但复用程序。公式变化会按需要编译；切换文档、场景类型、单次模式、取消或失败时仍结束相应实例。

粒子数、尺寸或存储布局变化仍可能重新分配缓冲及调色程序。已有程序缓存容量上限保持不变。释放失败时保留所有权，下次生成先重试清理；旧清理票据不能释放新一代资源。没有更改数学迭代器、种子、积分次数或密度绘制公式。

## 验证结果

- 116 项测试、7 个文件通过，覆盖重放／编译生命周期、清理失败恢复、编辑合并、过时结果和错误屏蔽、跨文档／模式退出，以及 Domain、Roots、Bouncing 共用队列回归。
- 实际应用中，Map 与内建 Symmetry 各两次数值编辑保持同一 Worker、一个上下文，着色器编译和程序链接计数保持 16／8。每次完整 RGBA 均与独立冷启动 Generator 一致，且参数改变确实改变画面。
- Map 公式编辑使计数增加到 18／9，保留同一上下文。这证明修改公式仍触发必要编译，不把所有编辑强行当成数值变化。
- 两类作品保存、下载项目、重新打开后保留编辑结果；各一张 257×193 实际 PNG 与独立 Generator 加 ArtRenderer 生成的 PNG 字节哈希完全一致。页面与 Worker 错误为 0，浏览器及服务退出。
- 自定义 Symmetry 实际应用回归通过：原版 JSON 导入、自定义参数编辑、模板撤销、时间线播放、项目保存重开、PNG，以及公式验证取消、过时结果隔离、显式 CPU 错误和编译错误后的恢复。本次没有测参数重命名时的编译次数，也没有把这组回归当成内建场景的性能数据。
- 类型检查和 Web 构建通过，仍有既有的大分块提示；1.0 应用包未重新打包。

## 同等任务成本

基线 `f73e2357ac1f9439d376fae3f386ca2368940f24`。每个任务连续编辑同一场景的一个数值参数 12 次，每次从种子重放 4 或 7 帧，5 万粒子、10 次预热、每帧 2 次迭代、256×192。测量包含完整 RGBA8、浮点密度读回及哈希，也比较边界和样本统计。

两类场景、两个版本、首次／暖任务，共 96 份完整画面、浮点密度和统计哈希匹配。每个 12 编辑任务的上下文创建数由 12 降至 1，着色器编译由 144 降至 12，链接由 72 降至 6。这里固定视口的程序数与实际应用自动视口不同。

| 场景／版本 | 首次／暖耗时 | 首次／暖 CPU | 首次／暖采样 RSS |
|---|---:|---:|---:|
| map／旧版 | 572.9 / 541.0 ms | 540 / 490 ms | 1045.8 / 1069.8 MiB |
| map／新版 | 314.5 / 276.3 ms | 280 / 210 ms | 1039.3 / 1061.5 MiB |
| symmetry／旧版 | 593.5 / 564.1 ms | 530 / 470 ms | 1041.0 / 1062.0 MiB |
| symmetry／新版 | 326.9 / 291.4 ms | 270 / 210 ms | 1043.3 / 1061.8 MiB |

每个场景／版本使用独立 Chrome 进程族，各一次首次与暖任务，不是多轮统计。首次从模块载入后开始，未清系统或驱动缓存。耗时包含完整任务及清理；不含启动、打包及模块加载。CPU 按进程身份汇总，RSS 每 250 ms 及任务边界采样，可能漏掉短命进程和瞬时峰值。RSS 含 Chrome 开销，不是显存；部分内存指标没有降低。代理 token、设备 GPU 时间、VRAM、编码、原版成本和跨设备表现未测。

复验：`node scripts/benchmark-iterated-edits.mjs`、`node scripts/verify-iterated-edit-ui.mjs`、`node scripts/verify-symmetry-custom-ui.mjs`。机器报告在本地 `.cache/v2-iterated-edit-cost.json`、`.cache/iterated-edit-ui.json` 和 `.cache/symmetry-custom-ui.json`。
