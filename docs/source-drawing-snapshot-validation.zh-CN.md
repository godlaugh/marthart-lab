# 原生渲染准备：有类型的绘制快照

2026-10-23，基线 `2e2d306`。**产品材质现在明确声明 uniform 类型，原生验证直接消费受容量约束的绘制快照；三张完整艺术画面仍与原版逐像素一致。** 本轮完成共享绘制数据边界，没有启用原生应用渲染，也没有关闭 2.0 整体验收。

## 解决的问题

此前原型导出器通过参数的 JavaScript 对象形状和 GLSL 正则表达式判断类型，还自行遍历、展开缓冲。这容易把重命名的整数参数当成浮点参数，并让未来产品适配器各自解释材质。

新增 `sourceShaderMaterial.ts`，在创建材质时声明 `float / int / vec2 / ivec2 / vec3 / vec4 / mat4 / float-array / sampler2d`。声明与 WebGL 使用的是**同一组 value 单元**，不是容易过期的另一份参数值。CPU/GPU 点、共享 Processing 线段、CPU 网格填充及隐式曲面填充已使用这个入口。材质释放后移除其声明；未知材质或被替换的参数集合不能冒充已知来源。

新增 `sourceDrawingSnapshot.ts`，把调用者明确排序的绘制对象转换成拥有独立缓冲的快照。它保留索引宽度、绘制范围、实例数、面选择顺序、深度／混合状态和纹理采样。已删除原型导出器中推断参数类型的正则及重复属性展开逻辑；CGL 适配器仅按明确的类型标签编码。

本轮没有重写曲面方程、相机或几何生成算法。普通 WebGL 仍使用原来的参数值和着色器。

## 所有权与错误边界

快照在分配任何大块打包数组前，先检查全部绘制对象并计算所读保留缓冲、待复制缓冲和保守的 shader／元数据传输空间，默认上限 256 MiB，调用者可提供更低预算。这不是完整场景、应用进程或显存的总预算，后续帧服务还必须计入帧缓冲和编码开销。

- 交错实例属性按原布局读取，实例步进保留为 1；不展开成重复三角形顶点。
- Float32 属性按原始 32 位字复制，保留 NaN payload、无穷大、负零和源槽位；其它已支持的属性格式使用 Three 自己的归一化规则。
- 快照拥有新的属性、索引、参数数组与纹理像素。之后修改或释放原材质／几何，不改变已交付快照。
- 同一纹理被多个参数使用时只复制一次，并通过明确的纹理编号引用。
- 超预算、取消、无效范围／数值和不支持状态分别返回带路径与原因的结果。不能忽略一个绘制对象后返回部分成功。
- 自定义 shader／绘制回调、未声明材质、float64 属性、额外实例矩阵、骨骼、部分光栅状态等明确拒绝，防止快照与实际 WebGL 行为不符。

快照是同步操作，取消回调在边界和分块复制时检查。它尚不包含跨进程取消、超时或 GPU 执行管理，不能把这项单元验证当作原生会话取消验收。

最终正式原生记录为 `.cache/surface-cgl-J4tzMJ/report.json`，状态 `matched`、退出码 0；源码和参考前后摘要一致，字形进程剩余 0。普通应用仍使用 WebGL，Möbius 在该路径的既知 1 像素差异仍开放。

这是一轮代表性任务对照，不能据此宣称加速或内存改善。两种导出器都使用当前材质，故它隔离的是打包边界变化，没有单独测量新增类型声明对材质创建的微小开销。首次不是清空 OS／驱动缓存的严格冷启动，后两个场景也共享该变体已加载的浏览器模块。

CPU 为浏览器进程家族的已观察累计增量，RSS 为 250ms 加边界采样的家族总量峰值，可能重复计入共享页或漏掉短时峰值。该采样范围不包括 Node/Vite、原生 helper、独立字形服务；原生命令耗时在各报告中另列。未测 GPU 时间、显存、agent token，也未测未来产品二进制传输／常驻会话成本。缓存中的基线和候选测量脚本、报告摘要保存在 `.cache/source-drawing-snapshot-20261023/cost-comparison.json`。

## 后续接入边界

快照不是整个帧协议：画布尺寸、背景、完整对象顺序与最终交付身份仍由上层拥有。后续应添加受管帧请求和常驻 CGL 会话，统一预览、暂停截图与录像，落实容量、超时、取消、崩溃恢复和 Apple Silicon 打包。

当前 CGL 诊断适配器仍使用固定尺寸、有限 draw 类型及本地 JSON 文件。它不是面向任意输入的产品服务，尚不能覆盖全部参数数组、纹理、非索引绘制或场景叠加层。正式传输应使用有边界的二进制缓冲，避免把 JSON 的数值格式当作位保真的通用协议。

可复跑入口仍是 `node scripts/verify-source-surface-cgl.mjs`。本轮日志位于 `.cache/source-drawing-snapshot-20261023/`。其余场景、连续动画、其它平台与发行验收没有缩减；Goal 继续进行。
