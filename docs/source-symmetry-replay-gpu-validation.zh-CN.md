## 执行规则

会话通过显式 `requestReplay()` 接收编辑事件，相同值的再次提交仍会重启重播；不通过 JSON 差异猜测事件。初次初始化清除尚未生效的重播请求。

普通对象更新发生在显示前。若本次显示开始重播，先执行已被宿主请求的普通更新，再恢复原有构造种子、清空累积和计数，开始分帧预热与绘制。重播未完成时 `warmupApplied` 为 false，因此后续普通更新可能再次执行完整预热。队列更新、重播预热和绘制批次分别计数；被重播丢弃的旧粒子更新仍计入实际 GPU 工作。

重播帧可以同时执行预热和绘制，每帧最多绘制 8 批。绘制轮数先耗尽、但预热未结束时，继续预热并保留墨迹。暂停状态不阻止显示阶段重播；普通显示中的参数变化在暂停时不清屏，相机变化仍会清屏。

宿主 `MathArt.config.renderFps` 决定目标重播帧数，与本地固定时间线采样 FPS 不同。新会话要求调用方明确传入宿主 renderFps，保留 Java int 输入边界及原版 `max(1, renderFps)` 解析；不从 `job.config.fps` 推测。原版没有 MathArt 宿主或配置时回退 60 FPS，该回退应由未来宿主调用方明确选择。

每次显示在 GPU 操作前检查数学与像素工作上限。中途失败或取消后必须显式重置；清理失败时继续保留资源所有者。当前尺寸变化要求重建会话，尚未实现原版只重建累积目标而保留粒子的 resize 行为。

- 关键位置：`display` PC 115–166；`update` PC 49–96；`advanceReplaySession` PC 8–105、119–238；`resolveTargetRevealFps` PC 19–39。
- 原版 helper 固定证据：`tests/fixtures/symmetry/replay-runtime.json`。21 项边界测试包括 19 个有效域内原版预算结果、宿主帧率与容量检查。
- GPU 验证脚本：`scripts/verify-source-symmetry-replay-gpu.mjs`。使用真实 Chrome headless WebGL，运行生产执行器；不替换 GPU，也不启动原版窗口。

六组小批次共 **219 个重播帧**，覆盖 0/100/1000 预热步、30/60 宿主 FPS、暂停、持续更新、编辑前尚未预热。所有场景固定使用不同的本地采样 FPS（24），以检查宿主帧率未被混用。每个绘制批次执行两次粒子迭代。预期粒子位置由独立 Float32 加法递推，未使用执行器输出的阶段列表计算。

额外检查了：内建方程的 buffer 存储与自定义 GLSL 的 texture 存储；重复重播的粒子和墨迹一致；暂停时的参数/相机清屏差异；无绘制预热尾段不改墨迹；取消后拒绝继续、显式重置恢复；资源释放。

回归结果：全量 **338 文件、6,214 项测试通过**。随后宿主 FPS 边界修正及新增一项测试，定向 **30 项测试**与 TypeScript 检查通过；最终 Web 构建通过。普通帧计划真实 GPU 回归通过，覆盖初始显示、空/零/短队列、结束后显示、倒退重建、错误粒子和重置。没有重新打包安装应用。

## 资源测量

另完成一次内建方程工作负载：65,536 粒子、640×480 累积目标、100 预热步，普通初始更新后完成 30 个重播显示帧、100 个绘制批次；重播数学求值 13,107,200 次。浏览器内部该完整工作负载约 0.765 秒。

整套验证（包含启动浏览器、219 个小批次帧及上述工作负载）外层耗时 4.50 秒，采样进程族 CPU 7.48 秒，峰值 RSS 约 1.40 GiB。250 ms 采样可能遗漏短进程和峰值，RSS 会重复计算共享页，CPU 为采样下界且没有消除 PID 复用；GPU 物理显存未测。没有等价旧版重播实现可用于前后比较，也未进行受控冷/热对照或 token 成本测量。这些数值不是完整编辑器或所有设备的性能承诺。
