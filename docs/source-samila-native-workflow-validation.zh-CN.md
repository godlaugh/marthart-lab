## 实际操作结果

| 操作 | 实测结果 |
| --- | --- |
| 改已有参数 | 保留渲染会话，清空旧积累；256 基础采样产生 1,536 个样本，即六倍补采 |
| 旋转图案 | 同一会话清空并采样一次，动画仍暂停 |
| 修改亮度、背景 | 保留积累；背景着色热更新，Scene 构造时的背景色仍保留到 Apply |
| 改名、保存 | 没有新增采样，画布字节不变 |
| 保存当前暂停画面为 193×129 PNG | 下载的完整 RGBA 与实际 capture 输出一致；导出和返回主画布各采样一次，两次因尺寸变化清空；动画时间不推进 |
| 调整窗口尺寸 | 保留会话，按新尺寸重新采样 |
| 标准→高质量→标准 | 画布像素尺寸加倍后恢复；会话保留，尺寸变化按预期清空积累 |
| 切换作品再返回 | 恢复工作文档的参数，创建新渲染会话 |
| 重新打开同 ID 文件 | 文件内容成为新的状态依据，渲染从第 0 帧开始 |
| 旧原生结果尚未交付时打开同 ID 文件 | 旧结果没有发布到画布，新文件渲染成功；最终资源释放完成 |

“在途结果”测试让真实 CGL 先完成，再暂缓其响应交付，随后通过文件输入执行替换。它覆盖结果失效和清理，不模拟渲染器，也不代表任意 CPU/GPU 执行时刻的强制中断。
