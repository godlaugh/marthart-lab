# 原生多重采样帧验证

2026-10-23。原生帧已支持显式多重采样，浏览器帧生产者能够携带实际 `GL_SAMPLES`，本机服务和 CGL 执行端均已接通。**这完成了预览接入的一项前置能力；实际应用预览、截图和录像仍未切换到原生通道。**

## 完整艺术画面对照

固定 MathArt 1.7.8 原包、三个原始配置、初始暂停时刻、500×600 物理画面。产品一侧运行真实导入器、Worker、ArtRenderer、浏览器客户端、本机 HTTP 和持久 CGL 进程；公式使用已有独立字形服务合成。单帧 CLI 与公开通道读回逐字节相同。

| 场景 | 无多重采样 | 4 个采样点 |
| --- | ---: | ---: |
| Cornucopia，CPU 点及主方程 | 0 个不同像素 | 0 个不同像素 |
| Sphere，CPU 点 | 0 | 0 |
| MöbiusStrip，CPU 网格 | 0 | **45** |

无多重采样回归通过。4 倍采样的严格整图检查仍返回 `differences`，没有放宽容差。Möbius 填充阶段有 121 个不同像素，加入线段后的完整艺术画面剩 45 个，最大通道差为 1。上述结果不包含原版品牌叠加层，也不代表连续动画或所有曲面配置已经验收。

这次原版 4 倍参考由诊断宿主明确调用 `buffer.smooth(4)`，读回每次绘制实际 `GL_SAMPLES=4`、`GL_MULTISAMPLE=true`。它证明匹配采样设置下的对照结果，**不证明原版主窗口的默认采样设置或实际窗口预览已经一致**。原版主窗口默认状态仍需独立确认。

## 改动与边界

- 二进制帧版本 2 在原 52 字节头后增加明确的采样数；零表示无多重采样。保留版本 1 的读取，用于历史证据复跑，解释为零采样。响应像素协议保持原格式。
- 原生执行端分配多重采样 RGBA8 颜色和 24 位深度附件，再解析到独立的 RGBA8 目标后读回。验证颜色和深度实际采样数；设备超限或驱动向上取整均明确拒绝，不悄悄改变请求。
- 把逐次绘制的诊断读回移至帧目标的统一所有者，最终读回复用同一实现。读回后恢复绘制目标，保留深度；每帧结束释放全部附件。
- 浏览器编码器、本机服务和原生解析器均计入多重采样存储，预算为 `packetBytes × 4 + width × height × (12 + 8 × samples) <= 256 MiB`，编码器另计保留快照。它是资源准入估算，不是整个进程或显存的 RSS 上限。
- ArtRenderer 输出实际采样数，仍拒绝不支持的对象、材质、裁剪视口和丢失的上下文。没有增加静默的图像回退。

## 排查事实

首次诊断遗漏了“首个纹理前”读回的多重采样解析，Sphere 和 Möbius 出现 OpenGL 1282，输出不作为验收参考。修正该诊断读回并恢复全部 GL 绑定后，三项原版重新运行，退出码均为 0，无 OpenGL 错误；窗口对象与可见窗口均为 0，进程已回收。验证脚本现在拒绝含该错误日志的参考。

原版 4 倍颜色附件实际是 RGBA8，采样位置为 `(0.375,0.125)`、`(0.875,0.375)`、`(0.125,0.625)`、`(0.625,0.875)`。Möbius 填充的 3,240 个按索引展开的位置和颜色与产品数据一致。将诊断 CGL 改用归一化字节颜色、原版填充 shader 或非实例填充调用，填充残差仍为 121 个像素；这些实验没有集成。残差根因尚未确定。

## 完成任务的开销

同一组保留的三张 500×600 产品几何帧，从 HTTP 提交到完整 RGBA 接收及摘要检查，比较改动前后的原生程序。首次一轮 3 帧，随后同一会话 10 轮共 30 帧。另测当前 4 倍采样；后者工作量不同，不作为等价性能对比。

| 版本 | 首轮 3 帧墙钟 ms | 首轮 CPU ms | 首轮家族峰值 MiB | 热运行 30 帧墙钟 ms | 热运行 CPU ms | 热运行家族峰值 MiB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 改动前，零采样 | 666.3 | 140 | 134.8 | 214.3 | 320 | 162.3 |
| 改动后，零采样 | 626.1 | 150 | 140.5 | 217.8 | 340 | 158.0 |
| 改动后，4 倍采样 | 99.1 | 110 | 137.3 | 225.4 | 310 | 171.0 |

没有清空系统或驱动缓存，4 倍采样最后执行；首次时间不能解释为多重采样更快。家族包含 Node、本机 CGL 子进程及可观察的测量进程，250ms 加边界采样可能漏掉瞬时峰值或重复计入共享页，CPU 有采样粒度限制。每份结果均校验输出摘要，清理后剩余受管进程为 0。Worker 生成、浏览器、公式、UI、GPU 时间/显存和 agent token 未计入该测量，不据此声称产品帧率改善。
