# Symmetry 渐变动画接入与验证

2026-10-21。**新导入的 Symmetry 项目已使用原版渐变队列、独立偏移和色板缓存规则。160 个原版显示状态的完整色板一致；330 组 GPU 散点对照误差为 0。** 这不是原版整窗口验收，后者仍为 0/11。

## 实际改变

之前 Symmetry 的相机使用源队列，渐变仍走本地动画。现在渐变与相机共享同一队列：先执行动画回调，再更新渐变，最后确定本帧显示色板。队列结束后不再推进渐变，显示保留最后的配色。粒子采样也改用该队列的帧率，避免渐变按 30 FPS、粒子却按独立的 60 FPS 前进。界面隐藏已经不生效的独立采样帧率。

共享渐变算术现在能保留三个独立起始偏移。Symmetry 的主色板、内部和外部偏移分别应用严格大于 1e-9 的写入阈值；其中任一分量发生有效写入，都会标记色板需要更新。已有 Surface、Attractor 和 Perlin 的单起点调用保持原有含义。

色板上传状态由单独所有者管理。停止渐变不会自动重建色板：如果该帧没有有效偏移写入，就继续显示上一次上传的色板，包括其循环采样与插值规则。若停止过程中发生写入，则下一次显示按当时的运行状态重建。GPU 缓存键消费这份实际显示状态，而不是仅看当前 `running` 标志。

导入支持对象或数组首元素的渐变配置，保留原始参数和数字词法证据；`targetDomain` 只接受空值或去除首尾空白后的 `SYMMETRY_CHAOS`。模式、插值、速度和两侧作用规则复用既有源配置解析所有者。编辑器提供对应的模式、插值与度/秒速度，不再提供无效的区域开关。

新规则带有独立版本标记，保存重开保留。已有本地文档和 direct runtime-config 路径没有自动迁移。源渐变运行时要求原版可表示的线性或余弦色板；对于多循环、非均匀色标、HSV 等本地扩展，明确报告不支持，避免静默丢弃用户输入。

时间线校验改用具名场景合同，替代逐项布尔参数；布局与保存校验消费同一场景选择结果。

时间线缓存按完整生产输入绑定，最多保留四组、每组三个前进实例，不保存逐帧历史。倒退定位会从所属输入快照重建；调用者后来修改原对象，不会改变旧实例的起始偏移。

## 证据边界与下一步

原版运行探针实际调用 `StartGradientAnimation` / `StopGradientAnimation` 回调、`GradientAnimator.update`、Symmetry 偏移目标与 `PaletteRuntime.writeGradientLut`。上传生命周期由探针明确模拟：构建色板之后才清除 dirty 标记，后续干净显示保留旧色板。没有执行原版 GL 上传或整个 `display`。完整 108 个 JAR、随附 JVM 和运行 harness 的身份已校验。

宿主顺序来源是原版 `Scene.update` 的动画→对象→相机顺序及 `Scene.render` 的显示调用；本地沿用已存在的源队列时钟。解析器的 Symmetry 目标过滤依据原版 `JsonSymmetryChaosConfig.buildGradientActionAnimation`，没有把这部分静态推导称作原版完整项目运行。

**仍未完成：** 编辑色板/变换后的分帧重建、原版实时/暂停显示次数与粒子迭代的完整对应、源参数动画及原生整窗口对照。尤其是源队列结束后原版停止对象更新而仍继续显示，当前粒子累积器的这部分行为还需统一；本轮只完成了渐变状态的对应规则。不能将色板和散点验证推广为完整混沌轨迹一致。

下一步应把源队列的对象更新事件接入粒子帧计划，明确无更新显示、预热、重建绘制轮数和归一化计数的共同所有者，再验证暂停、队列结束、编辑和导出组合。1.0 Apple Silicon 应用未重打包或替换，本轮没有操作主屏幕。

## 复验与成本

固定证据在 `tests/fixtures/symmetry/gradient-runtime.json`。完整原版 LUT 留在忽略目录，Git 中保留全部 Float32 字节的 SHA-256；测试重新生成完整本地 LUT 后比较摘要，不只抽样几个颜色。

```sh
python3 scripts/verify-source-symmetry-gradient.py \
  ../.cache/mathart-investigation/MathArt.app \
  .cache/v2-bouncing-jvm .cache/source-symmetry-gradient/new-native

node scripts/verify-source-symmetry-splat.mjs <新输出目录> <原版JAR路径> \
  .cache/source-symmetry-gradient/new-native/report.json

node scripts/verify-captured-density-public.mjs <新输出目录>
```

原版复验约 1.60 秒。330 组 GPU 验证约 4.94 秒；外层进程族约 5.37 秒、采样 CPU 9.57 秒、峰值 RSS 约 1.82 GiB。实际 App 流程约 12.12 秒；外层约 12.87 秒、采样 CPU 26.02 秒、峰值 RSS 约 2.13 GiB。

本轮较上一轮增加渐变状态与 GPU 对照，工作量不同，不作性能优劣结论。浏览器与 GPU 上下文新建，66 组重复上传检查是同一所有者内的热路径；没有受控的系统冷/热测速。250 ms 采样可能漏掉短进程和峰值，RSS 可能重复统计共享页，CPU 为观察下界；GPU 内存和 token 成本未测量。
