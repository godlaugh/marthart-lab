# 原版隐式曲面网格与实际导出验证

2026-10-22。本轮把源 CPU 隐式网格从本地四面体剖分改为原版 Marching Cubes。两个输入的完整顶点、法向、填充颜色及切片线数据与原版逐元素一致；实际导出仍存在像素差异，隐式曲面整类尚未验收。

## 已验证的边界

原版 MathArt 1.7.8 JAR 的 SHA-256 为 `a6e1da3acfc05c347d2529c1d590657e2dd798e16d38c55df3dc61312be24018`。后台 JVM 使用正常策略与授权状态，保留水印，捕获实际网格、法向、颜色及查表数据；两次运行均正常退出，进程组已回收。没有操作可见主屏。

| 输入 | 顶点数 | 位置、法向、填充 RGBA 差异 | 保留的重复顶点退化三角形 |
|---|---:|---:|---:|
| 默认实例 | 90,120 | 0 | 614 |
| 不等轴采样实例 | 1,752 | 0 | 104 |

生产路径保留原版遍历顺序、Float32 运算和非索引三角流。源网格不再经过本地根细化、去重或面积过滤。网格和切片共用解析后的公式与坐标，但保留各自不同的非有限值替换规则；`iso_threshold` 与网格等值面值分开保存。颜色插值修正为 Processing 的通道四舍五入。普通本地作品和其它渲染模式继续使用其原有规则。

完整数值金标及取消、容量、传输、渲染相关的 7 文件 78 项针对性测试通过。模拟渲染测试只证明接口；图像证据来自实际浏览器导出。

## 成本与复核

同输入的 `generateImplicit` 工作流在独立 Node 进程测量，导入不计时，生成前执行 GC：默认实例首次生成耗时 799.8→362.1 ms、CPU 1307.4→587.4 ms、进程峰值 RSS 163.53→161.10 MB；暖进程生成耗时 774.9→348.7 ms。保留重复顶点和法向使输出从 3.148 MB 增至 4.739 MB。RSS 为累计高水位，不代表单次分配；这些测量不含 UI、GPU 或 agent token。

另一次完整浏览器导入与导出耗时 3.336 秒，采样 CPU 5.233 秒，进程族峰值 RSS 1.640 GB。50 ms 采样可能漏掉瞬时峰值，共享内存可能重复计数，既有预览／导出服务和 GPU 内存未计入；此项没有冷缓存性能改善结论。
