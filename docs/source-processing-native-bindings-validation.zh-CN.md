# 原生 Processing 参数绑定验收

2026-10-26。**原生程序已接管链接反射和参数写入顺序。十三组、104 帧原版记录对照通过，其中十二组、96 帧有效粒子数据共 71,971,584 字节逐位一致。264 项不同测试通过。应用路由及完整画面尚未完成，M3 继续进行。**

## 本轮实现

此前的验证由外部提供原版程序的反射信息，再生成原生参数。本轮改为发送自动 setter 的名称候选、类型和值，由实际链接的原生程序选择首个活动名称，并让 GL 执行写入。原版反射仅用于比较预期结果，不再作为执行输入。

原生资源按原版顺序执行：自动参数 → `iterations` / `stateTex` 包装参数 → 作者匹配的 float 参数 → 绑定自身状态纹理 → 计算。一次 setter 类型不兼容会记录拒绝结果、保留原值，并继续后续阶段；不会转而尝试下一个别名。布尔值转换、数组首元素更新、未选别名与普通参数的链接默认值均有实际原版及 CGL 对照。

作者参数沿用原版原始正则匹配规则，注释中的名称也可能被匹配。因此匹配名称和任意类型写入的许可分别校验：`stateTex`、`iterations`、`gl_unused`、数字名称 `123` 可以作为原版匹配事实传递，并不因此获得任意类型写入权限。缺失、非有限或 Float32 溢出的作者值由现有参数绑定模块统一归零。

新协议返回每个 setter 的结果：未执行、不活动、写入成功或类型不兼容。请求、诊断数组和解码对象均计入资源预算；超限或畸形请求在重置、写入资源前拒绝。请求发出时冻结响应校验所需的名称，避免等待网络响应期间调用方修改数组。

接通公共 HTTP 客户端时发现一个实际遗漏：客户端仍把所有非读取响应当成固定 64 字节，会拒绝新诊断响应。现在响应长度由协议模块统一计算，客户端和解码器共用同一规则，已通过真实 HTTP 服务及原生子进程验证。

## 原版及原生对照

新增构造输入使用 64 个粒子，在粒子坐标中观察 123 项自动值、别名、默认值与参数结果，覆盖矩阵、法向矩阵、bool/bvec、数组、纹理采样和有意的类型冲突。它通过原版正常 ProjectState → initScene → VIEW/RUN 执行，**不是原版内置预设**。

最终对照还复用了已有原版记录。每组八帧：

| 参照组 | 验证范围 | 结果 |
|---|---|---|
| setter-coverage | 新增 123 项 setter 结果及粒子数据 | 零差异 |
| baseline、small、tween | 尺寸、像素密度、相机动画及自动值 | 零差异 |
| conflict、bool | 类型冲突、布尔转换及后续作者写入 | 零差异 |
| world | 实际世界矩阵快照及普通更新中的粒子计算 | 零差异 |
| switch | 场景重新初始化后的上下文 | 零差异；未计入粒子重放 |
| standard-custom | 562,144 个粒子的标准自定义输入 | 零差异 |
| layout-custom、layout-multi | 自定义布局、邻居读取和多步计算 | 零差异 |
| nonfinite-custom、discard-custom | 非有限结果及保留的写入历史 | 零差异 |

104 帧中，96 帧经正式 codec → Node 服务 → CGL → codec 完成有效粒子对照。原版种子与 pass 调度仍是明确的观测输入；矩阵及自动 setter 由产品模块生成。切场景组因原版创建了新的种子资源，本轮仅计上下文验证。世界矩阵组的计算仍在普通更新阶段，尚未执行世界变换内部的 replay。

另外，64 粒子、八帧的固定参照通过实际公共客户端函数、真实 loopback HTTP 服务和原生进程完成对照。测试只把相对请求地址解析到临时服务，没有伪造响应。这八帧与上表是同一份参照，不重复增加总帧数；没有浏览器或应用窗口验收的含义。

十三组最终进程监督记录均为退出码 0、退出后进程组为空；原生资源已释放。新原版采集前后的 JAR 和采集器摘要一致，license/settings 保持不变；原版自身刷新了策略缓存，运行前备份保留。没有调用或绕过原版 EXPORT。

## 自动验证

264 项不同测试通过：七个协议、上下文及客户端测试文件共 180 项；服务进程测试 53 项；三个实际原生生命周期测试文件共 31 项。之后将其中一个已有生命周期用例改为真实公共 HTTP 通路并单独重跑通过，不重复计为第 265 项。

覆盖包括：响应身份与长度、别名及参数结果越界、冻结请求后的调用方修改、预算临界值、畸形请求后资源不变、零步重置、重播、错误 sampler 单元、资源释放，以及六种坏响应触发实际子进程回收。服务坏响应测试使用受控进程，只证明通信和清理；GPU 数值结论来自上述真实 CGL 对照。

TypeScript 检查通过。实际原生验证使用 `-Wall -Wextra -Werror` 编译，无警告。源码夹具为 JSON 与提取脚本，共约 49 KiB；未将二进制、原版安装包或本地采集缓存纳入 Git。

## 剩余工作与限制

应用中的自定义 Symmetry 仍走原有 Worker，桌面包仍为 `2.0.0-preview.3`，本轮没有重打包。下一步接入 graphics 的首次绑定和持续生命周期，覆盖实时、从头重放、切场景及世界变换中的计算，再接通 completed-pass 墨迹诊断、界面和取消清理。之后继续完整图像、交互、PNG/视频和桌面包验证。

原版仍记录 `endDraw 1282`；有意的 setter 冲突还产生前置 1282。观察器读取错误会清空相应 GL 错误标志，本轮不证明完整错误队列或日志时序一致。纹理仅支持当前资源拥有的 2D 状态纹理和单元 0，其它目标或单元明确未支持。粒子对照仅计算有效粒子，不把此轮结果扩展成完整补齐纹理或最终艺术画面一致。有限用例也不能证明任意作者 shader 都能及时终止。
