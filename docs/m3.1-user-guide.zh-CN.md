# M3.1 中文使用说明

本次交付为 **MathArt Lab 2 Preview · 2.0.0-preview.18 · Apple Silicon**。可以在当前 Mac 上直接使用；它仍是创作预览版，不代表全部场景都已与原版完成一致性验收。

## 打开应用

在 Finder 中按 `⌘⇧G`，粘贴下面的目录并回车，再双击 **MathArt Lab 2 Preview.app**：

```text
/Users/hoo/AIStudio/mathartstudio-rea/studio/dist-desktop-v2/MathArt Lab 2 Preview-darwin-arm64/
```

应用完整路径：

```text
/Users/hoo/AIStudio/mathartstudio-rea/studio/dist-desktop-v2/MathArt Lab 2 Preview-darwin-arm64/MathArt Lab 2 Preview.app
```

使用这个包不需要先启动终端、REA、开发服务器或重新安装依赖；原生绘制和公式服务已随包提供。视频使用本机已有的 FFmpeg，设置方法见下文。

首次打开后，等场景画布生成完成。顶部齿轮打开“工作区设置”，可切换中文、主题和渲染质量。复杂场景先用“标准”质量；目标帧率是预览目标，并不保证复杂计算能实时达到。

这是本地临时签名的预览包，**没有 Developer ID 发行签名或 Apple 公证**。当前 Mac 上的启动已经验证；若 macOS 阻止打开，请保留完整提示，不要删除系统安全设置或修改应用内部文件。

## 选场景、编辑与应用

1. 在左侧“场景库”选择模板，或点“新建场景”。已有项目可用左下角“导入项目”选择 JSON。
2. 在右侧属性面板修改方程、参数、颜色或显示设置。底部时间线可“添加动画”；播放按钮或空格键可播放、暂停，空格快捷键在没有编辑输入框时使用。
3. 如果出现“有未应用的修改”，点击 **“应用场景”**，等待新预览完成，再录制或导出。此时“保存”只保存作品，不等于把修改应用到正在运行的场景。

不同场景的应用方式有区别，请以面板提示为准。源隐式曲面、复根等完整应用会重新开始动画，暂停时应用仍保持暂停；源分形暂停时应用保留当前动画进度，播放时应用才从头运行新的时间线。部分颜色或参数修改会即时生效，不能据此推断所有修改都会即时应用。

“返回起点”用于重新开始。后台采样类场景的暂停不一定立即停止剩余点的计算，画面也可能继续补齐。导入后如有“导入兼容说明”，先展开阅读；保留下来的字段不一定都已参与当前效果。

## 保存、重开与备份

- 点击顶部 **“保存”** 或按 `⌘S`，作品加入“我的作品”。编辑内置模板后保存会创建独立作品。
- 退出并重新打开同一个预览应用，可恢复本地工作区；也可从“我的作品”重新打开已保存作品。保存的是作品配置，不承诺恢复运行中的随机采样、墨迹或粒子历史。
- 需要备份或迁移时，点击场景库底部 **“导出项目 JSON”**；恢复时使用“导入项目”。图片和视频不能代替项目 JSON。
- `⌘Z` 撤销，`⌘⇧Z` 重做。作品库菜单还提供创建副本、重命名和回收站恢复。

预览版工作区默认保存在：

```text
/Users/hoo/Library/Application Support/MathArt Lab 2 Preview/
```

它与已有 1.0 应用的工作区分开。本次交付核对过 1.0 包的三个关键文件，均未改变。

## 导出 PNG

1. 暂停并等当前预览完成，点击顶部 **“导出作品”**，选择图片和 PNG。
2. 先用“自定义尺寸”设置 **500×600**。若出现“PNG 放大倍率”，首次可选 **1×**；最终尺寸以对话框显示的实际输出尺寸为准。
3. 若有“当前暂停场景”和重新播放之类的选择，按需要选用，并阅读说明。前者使用当前状态，后者从配置重新生成；累积或随机场景不保证两者相同。某些场景截图仍会新增采样，对话框会说明。
4. 点击“开始导出”，完成后点击 **“文件已生成 · 下载 PNG”**。等出现“已保存”提示，再到输出目录查看。

PNG 可以保留透明通道；应用画布可能按不透明 RGB 显示，因此透明图在其它查看器里的外观可能不同。公式使用其保存的布局，超出目标边界会被裁切；没有出现在图中，不一定是导出遗漏。

## 先制作一段短视频

先给时间线添加可见变化并预览，确认没有待应用修改。点击“导出作品”，选择视频、MP4。第一次可先用 **640×360、24 fps、2–3 秒**，确认流程后再提高尺寸或时长；这是一组入门设置，不是所有场景的性能保证。

视频模式按当前场景提供的选项选择：

- **按时长导出**：使用填写的时长逐帧生成。
- **按动画队列／源完成条件录制**：由队列或该场景的完成条件决定结束，可能先有一帧预热。不要把“导出范围”当作这种模式必然录满的长度。
- 顶部 **“录制”**：不同场景会进入对应的录制流程。若显示“实时录制”，它读取当前画布，计算慢时可能重复画面；需要固定帧数时使用“导出作品”。

队列录制界面如果提供 **“停止并保存”**，可用它保存已经完成的部分；“取消导出”会丢弃本次导出，不等于保存。若显示“重试保存”，按该按钮重试，或明确选择“丢弃导出”。等待操作结束、关闭按钮恢复后，再切换场景或退出应用。

文件生成后点击下载链接。部分源场景录制结束会继续播放，想检查结果时可以再次暂停。视频是有损编码，不能要求其像素等于 PNG。

## 输出目录与 FFmpeg

顶部齿轮 → **“工作区设置”**：

| 设置 | 操作与生效时间 |
| --- | --- |
| 输出目录 | 点“选择文件夹…”，选择可写的本地目录；立即生效。 |
| FFmpeg | 点“选择可执行文件…”，选已有的 `ffmpeg` 程序；退出并重新打开应用后生效。 |

默认下载目录是：

```text
/Users/hoo/Library/Application Support/MathArt Lab 2 Preview/downloads/
```

当前机器验收使用的 FFmpeg 是 `/opt/homebrew/bin/ffmpeg`。应用不会自动安装 FFmpeg。若设置里提示编码器不可用，确认选择的是可执行程序而不是文件夹，重开应用后再试；若选择按钮被禁用且提示由启动环境指定，当前路径受启动配置控制。

若导出按钮暂不可用，先检查是否仍在计算、是否有未应用修改、尺寸是否有效，以及视频编码器是否可用。收到容量或预算错误时，可先保存项目，再降低本次输出尺寸或场景计算规模重新应用；不要把错误当作仍在正常导出。

## 本次交付的已知限制

- **Implicit 的 `PREVIEW` 粒子采样尚未对齐原版。** 它是具体显示模式，不是应用名里的“Preview”；不要拿本轮已验证的网格结果代替它的验收。
- **11 类扩展场景没有完成全面覆盖。** 已验证的是各报告中指定的输入、流程和范围；能打开或导出，不等于任意输入均与原版完全相同。本地模板也不会自动成为原版执行模型。
- **只验证了当前这台 Apple Silicon Mac。** 其它 Mac、显示设备、Windows、Linux 和 Intel Mac 不在本次发行验收范围内，包也尚未公证。
- 大网格的首次生成、动画持续改参数和高分辨率导出仍可能较慢。preview.18 主要改善同一未变网格的重复显示，不保证所有动画加速，也不提供无限容量。
- 已有完整图片和视频检查不能泛化为原版整窗、所有公式位置或所有视频像素完全一致。PNG、JPEG、视频以及当前状态／重新生成各有自己的处理方式。

本次到 **M3.1** 停止，后续开发暂停，以上未完成范围继续保留。当前包与本轮验证细节见 [Implicit 网格复用说明](source-implicit-mesh-reuse.zh-CN.md)；1.0 原交付范围见 [1.0 中文验收报告](release-1.0-validation.zh-CN.md)。
