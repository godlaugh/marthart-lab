# 域着色录制传输与队列验收（2026-10-22）

域着色录制已经贯通持有会话、真实 Worker、Generator 客户端和 GenerationQueue。开始、逐帧交付、停止恢复主预览均已验证。**App 的实时域着色界面和实际视频编码尚未接入本链路，原版整窗口一致性验收仍为 0/11。**

模拟时间与参数动画的实际帧率分别传递。预热使用明确给出的实际帧率；后续每帧由调用方提供新的观测值。队列没有观测回调就拒绝开始，非法观测不会推进宿主，`-0` 也保持原值。本轮浏览器验证使用留存 JVM 样本中的帧率序列作为输入，没有把测试输入称作界面实时测量。

未送达的帧由 Worker 保留。重试需要相同的帧序号和观测值，避免重复计算或换一个观测重新解释已经发生的更新。如果传输结果不确定且像素缓冲已被转移，则保留停止能力，不重复运行数值帧。停止后的主预览也可以在传输丢失后重新获取，不多推进动画、不重复重置时钟。

客户端分别核对数值时间、录制序号、实际/模拟帧率、尺寸与像素密度、完整配置对应的公式标签以及会话身份。错误响应是否保留预览或录制控制，由 Worker 的明确确认决定。录制结束后，队列保留期间暂存的作者草稿，并继续处理新的完整 Apply；草稿与实际生效的配置保持区别。

浏览器测试使用真实 Generator、Worker 和队列；故障注入测试仅替换消息传输，运行实际的客户端、Worker 处理器、域着色宿主和 CPU 渲染器。它们分别证明正常运行和异常路径，不替代 macOS 原版窗口、JOGL 像素或实际编码器的验收。

完整浏览器验证进程族观测：墙上时间 **5.91 秒**、CPU 时间 **17.38 秒**、峰值聚合 RSS **1.61 GiB**，结束后未观测到遗留的所属进程。50ms 采样可能遗漏瞬时峰值，共享内存可能重复计入 RSS。此前版本没有相同的域着色 Worker 录制流程，不能作等价前后性能比较；未分别测量完整冷/热任务、token 成本或显存。

复核入口为 `scripts/verify-source-domain-recording-worker.mjs`。本机原始记录：`.cache/domain-recording-worker-final/report.json`、`.cache/domain-recording-worker-final-measure.json`、`.cache/domain-recording-worker-final-tests.json`、`.cache/domain-recording-boundaries-verified.log` 与 `.cache/domain-recording-worker-build-verified.log`。浏览器验证前后源文件哈希一致。本轮没有向用户桌面发送鼠标或键盘输入。
