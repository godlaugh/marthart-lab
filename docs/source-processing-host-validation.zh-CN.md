# 自定义 Symmetry 绘制宿主与重播阶段验收

2026-10-26。**已补齐绘制宿主组件，并让原生重播区分普通更新和世界空间更新。115 项相关测试、13 组既有原版记录回归及 Web 构建通过。实时／冷生成的应用入口尚未接入，M3 继续进行。**

后续更新：应用入口已接入并完成本机验证，见[自定义 Symmetry 原生应用入口验收](source-symmetry-application-validation.zh-CN.md)。下文保留本轮当时的范围与结论。

## 本轮改变

原版有三个不同的状态：每个 graphics 对象自己的矩阵、当前绘制对象选择器，以及 shader 首次绑定的 graphics。此前验证脚本直接操作矩阵，应用没有可复用的宿主。现在 `SourceProcessingHost` 统一拥有这些生命周期，验证脚本改为消费它，删除脚本中的重复事件编排。

宿主接收明确的主帧开始／结束、场景初始化、对象重置、目标绘制及屏幕覆盖层事件，不从帧号推测状态。普通更新读取设置本帧相机之前的状态；世界空间重播读取世界变换阶段的状态。暂停首显同样可以触发绑定，不能因为没有普通更新就提前绑定主画布。

离屏缓冲改变尺寸会建立新对象，而非改变旧对象身份。若 shader 仍引用旧对象，宿主保留它；当前离屏槽再次改变也不会不断保留无关历史。单 shader 范围内最多保留主画布、当前离屏缓冲及被引用的旧离屏缓冲三个对象。对象重置释放旧绑定，场景初始化和粒子重置不会被混成同一件事。离屏结束恢复 primary 选择器，primary 结束将选择器清空；它不是通用嵌套栈。

重播接口新增按阶段传递的上下文快照。原生 custom 显示必须提供这组快照，不能把整个 display 的单一上下文当作普通更新和重播两种状态。快照在第一次等待之前复制，后续修改输入不会改变已经提交的阶段。

审查发现并修复了一个失败边界：相机设置或后续事件中途出错后，部分矩阵可能已变化。现在一旦开始修改后失败，宿主会拒绝后续事件、绑定和快照，直到显式释放。预检拒绝不破坏已有状态；已分类错误与意外抛出的异常均覆盖。

## 验证结果与范围

六个相关测试文件共 **115 项不同测试通过**，包含宿主身份、离屏替换、暂停首显、同一主帧内的截图及恢复、录制预览复制、覆盖层存在／不存在、resize、异常失效、异步复制，以及既有实时／冷生成回归。先前测试与重复运行不另加计数。

真实 loopback HTTP、`SourceIteratedReplaySession`、生产原生后端和 CGL 运行了读取 `transform[0][0]` 的自定义 shader：普通更新后的粒子 metric 等于更新阶段的矩阵值；请求重播后，实际执行 update→replay→replay，最终 metric 等于世界阶段的矩阵值。像素呈现和资源释放通过。**这是本地重播阶段接线验证，不是原版 world replay 的运行对照。**

现有 13 组原版 VIEW/RUN 记录重新经过新宿主与真实原生计算通路：104 帧上下文零差异；其中 96 帧有效粒子、71,971,584 字节逐位零差异。场景切换组只验证上下文，不计入原生粒子帧数。本轮没有新增原版捕获；原版记录中的 endDraw GL1282 及观察器读取错误标志的限制仍保留。有效粒子一致不等于完整状态纹理、完整艺术画面或整个窗口一致。

最终源码对应的全部 13 组、115 项测试和 Web 构建均通过。CGL 使用 `-Wall -Wextra -Werror` 实际编译；Web 构建包含 TypeScript 检查，保留已有 bundle 大小提示。各受监督进程组结束后均为空，宿主保留对象数为零。本轮没有打开 GUI、使用原版 EXPORT 或重新打包桌面应用。

## 仍需完成

宿主组件和重播接口已具备所需语义，但 `SourceIteratedSession`、冷生成所有者和客户端默认路由还没有接线。接入时必须保持一个主帧内的暂停截图与恢复顺序，录制先 update 再离屏 render，停止录制不制造新帧；失败及取消不能发布部分状态。

离屏首次绑定、buffer 替换和录制顺序由已有字节码与本地边界测试支持，尚未取得这些路径的原版运行对照。之后仍需实际交互、原版完整画面、PNG／视频一致性和桌面重新打包。所有 11 类场景的整体验收要求保持不变；当前桌面仍是 `2.0.0-preview.3`，自定义场景默认仍走 Worker。用户只有本机，跨设备未验证。
