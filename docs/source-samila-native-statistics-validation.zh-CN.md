## 改动与预算

旧实现每 65,532 个样本下载每样本 16 字节统计，再逐项在 CPU 校验和求和。默认六倍补采每帧需要 116 次下载、121,165,824 bytes；高批次需要 601 次、629,965,824 bytes。这些字节量由实际批次及实现计算，未使用驱动传输计数器测量。

新 owner 保留采样公式、shader、seed、分块和绘制顺序，将逐样本分类与整数归约留在 GPU，每次 display 最后读回 16 bytes。归约逐项验证 tuple，再求和；部分块和 summary 的未写入尾部被明确屏蔽。内部 program、纹理、FBO 与统计 buffer 由同一个 Samila 资源持有，沿既有清理边界释放。

| 预算项目 | 集成合同 |
| --- | ---: |
| 固定统计存储 | 2,240,000 bytes |
| 内部 shader 保守源码计费 | 1,860 bytes |
| 每次统计读回 | 16 bytes |
| 相对旧版每个资源的 retained 增量 | 1,193,348 bytes |
| 默认轨迹 retained | 12,874,264 → 14,067,612 bytes |
| 高批次轨迹 retained | 12,874,432 → 14,067,780 bytes |

CPU 核对实际编译的原生头文件和实际加载的 TypeScript 模块，三项合同值完全一致；256 帧的 retained 增量也全部符合预期。retained 是保守资源计费，**不是驱动物理内存或显存测量**。容量判断包含两个保留 owner、目标尺寸、协议副本及临时读回，不能只凭减少下载量声称减少了驻留内存。

## 正确性和失败边界

两条原版轨迹基础 batch 为 1,262,144 / 6,562,144，持续参数变化实际每帧执行六倍采样：7,572,864 / 39,372,864。使用完整原公式、palette、每帧实际 seed、参数和 theta，固定模拟 dt=1/60；这不是实际 60 FPS 承诺。主目标物理 810×972，录制目标物理 576×384，primaryPixelHeight=972。

最终集成版分别与旧生产 run3、候选版核对全部 256 帧的 runtime、参数、seed、采样数、clear、passes、density 和分类统计，零差异。backend 除明确迁移的 retained 外全部一致，HTTP 状态与请求/响应尺寸也一致。两条校准轨迹的样本均 accepted；非零 invalid/clipped 分支由下面的独立真实原生测试覆盖。

默认帧 0/102/221、高批次帧 0/14/33 的全部 RGBA 与原版、旧基线、候选均零字节差异。仅依原版 GL 底向上约定翻行，没有颜色转换、遮罩或容差。边界是品牌叠加前的完整核心图像；其余 250 帧保留完整小元数据，不宣称逐帧图像全部比较。

本轮主任务实际执行 **5 files / 93 tests，17.99 秒**：8 项 native lifecycle、23 项 backend、23 项 client、32 项 service、7 项 async session。执行结果来自本轮工具输出，未另存测试日志；fixture 如实记录此来源，不伪造日志文件。native lifecycle 包括实际统计计费、三种分类、部分块与旧尾部、两资源交错、step/present、容量拒绝、resize/release 及失败恢复。

畸形 tuple 测试将错误置于第二个 sample chunk，包含全零、多重分类、非法中间 lane、超范围和 UINT_MAX。归约拒绝结果后，**native dispatcher 销毁上下文及全部 owners，gateway 清空资源注册表**；原资源后续请求返回 `state-lost`，release 返回 `absent`，fresh create 使用新 context 并恢复绘制。错误是在有界 display 的末尾检测，不能称为与旧实现每块检查具有相同报错时刻。

`npm run build:v2` 成功，保留[构建日志](../.cache/samila-native-statistics-integrated-20261025/build-v2.log)，仍有 bundle 大小提示。最终 renderer 摘要为 `3fe7d77cbaf0ab0c25d1a9281516a4aa98ae9cf8cdce689ddee6f2c795771321`，与候选 executable 相同；产品源及参考摘要在两个集成运行前后稳定。源变更清单完整保留，校准脚本不宣称验证同时存在的 App/Timeline 文案改动。
