# Symmetry 项目导入入口修复

2026-10-21。**修复了文件导入的参数转换、构造顺序、后端与初始盒规则；原版整窗验收仍为 0/11。** 本轮没有操作原生窗口，没有重新打包或替换 1.0 Apple Silicon 应用。

## 为什么上一轮还不够

[上一轮](source-symmetry-editor-order-validation.zh-CN.md)证明了原版参数编辑树的顺序，但原版“打开项目”还有一层转换：`MathArtSession.loadProject` 在 PC295 调用 `ProjectState.fromJson`，PC538 调用 `toJson`，PC541 才把结果交给渲染桥。直接把原始 JSON 送进底层配置解析器，会漏掉这层转换，影响首次构造和后续编辑。

本轮实际运行原版 ProjectState，再创建原版 Symmetry 配置和 Mobject、读取种子，验证了这个入口。并非只用本地实现相互比较。

## 已修复

- 文件适配器 `parseProjectFile` 选择项目入口；直接配置分析 `parseLegacyScene` 保留 runtime-config 入口。两种入口有不同语义，测试与初始化审计脚本已明确区分。
- 项目参数读取 Java Double 数字；布尔值、不能解析的字符串和其他失败值写入零。先清空旧参数，再按原 JSONObject 顺序填入编辑树，之后重新产生 JSONObject 顺序。缺少参数表不会保留旧参数。
- 单独保存原项目的编辑参数和值，再保存引擎的有效构造快照。缺省参数和取整后的值不再被误认作用户输入。后续编辑只把明确改动写回编辑状态，保存重开保留两者。
- 原版项目入口固定输出 GPU，包括源文件写 CPU、AUTO 或未知后端的情形；GPU 不可用时明确报错。直接配置入口仍保留原有选择。
- 原版 Symmetry 项目入口不输出 `x0/y0_min/max`，因此文件导入使用 `.001f–.002f` 默认范围。直接配置入口仍解析这些字段。
- 三项整数设置继续遵守原版转换、默认值与最小钳制；batch 解析归入构造配置 owner，后续消费者复用结果。保存数据的两组参数共用同一校验函数，避免重复解释。

## 仍需继续

**本报告不代表完整 ProjectState 或完整画面已经复现。** 本轮独立审计又确认了下一批差异：原版项目默认缩放 XYZ 为 35，色调默认 brightness 为 .3f、dynamic_range 为 .2f；实际 Symmetry GPU 使用 ROBUST 步长度量归一化及固定颜色频率。这些显示设置现已完成下一轮[项目显示参数与 GPU 着色修复](source-symmetry-project-visual-validation.zh-CN.md)，其中仍保留的呈现差异见新报告。源窗口合成、噪声、视口适配与实时帧也尚待完整对照。

本地编辑器显示有效参数；保存的源编辑状态用于精确重建，不承诺复刻原版每个控件的显示文本。旧文档没有记录源编辑参数时继续使用原有快照，不能补回未记录的历史。非有限参数与既有本地资源上限仍明确拒绝。

本轮原生读取工具实际返回“Mac 已锁定，自动解锁失败”，已请求用户解锁，没有重复解锁或移动窗口。虚拟屏上的原版截图／输入仍未恢复验证。

## 成本与证据

同类任务为修改系数、序列化构造配置并重新解析，每轮热运行 500 次；旧版为上一提交，新版含原始编辑参数。首次调用不是操作系统冷缓存，不能据一次测量宣称提速。

| 参数数 | 旧／新首次墙钟 | 旧热运行每次 | 新热运行每次 | 新热运行 CPU 每次 |
|---|---|---|---|---|
| 8 | .424／.288 ms | .024–.030 ms | .023–.027 ms | .031–.035 ms |
| 257 | 1.356／1.091 ms | .838–.875 ms | .961–.973 ms | .963–1.014 ms |

保存配置示例由 397 增至 535 字符、15,702 增至 25,152 字符。模块加载共约 1.94 秒，测量进程族采样峰值 RSS 约 825 MiB。实际 App 脚本约 11.49 秒，外层采样 12.20 秒、CPU 27.35 秒、峰值 RSS 约 2.56 GiB。250 ms 采样可能漏掉短进程和峰值，共享页可能重复计数；token、GPU 内存和 OS 冷缓存成本未测量。

提交中的 `tests/fixtures/symmetry/project-import-runtime.json` 包含输入、原版输出、原包与 JVM／JNI harness 摘要。完整本地证据在 `.cache/source-symmetry-project-import/`，实际 App 报告在 `.cache/source-symmetry-project-import-public-final/report.json`。原包、运行库、构建产物及本地缓存不进入 Git。
