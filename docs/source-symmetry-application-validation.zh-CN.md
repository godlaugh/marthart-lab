## 已完成的行为

选择原生绘图后端时，具备源构造、参数、渐变和呈现配置的自定义场景使用 GL 4.1 片元计算及持久墨迹。编辑器、参数匹配、客户端分发和冷生成共用同一个准入判断；旧项目缺少源构造配置时保留原有 Worker 路径。作者源码和原始导入证据保持原样，宏定义不会先被旧 ES 解析器拒绝。成功准备源码只代表可以提交编译，实际语法和类型仍由驱动检查。

实时及冷生成共用绘制宿主：普通更新取得本帧相机设置之前的上下文，重播取得世界变换阶段的上下文。暂停截图在同一个主帧内完成离屏绘制与预览恢复；录制保留更新、离屏绘制及主画布回显的顺序。离屏尺寸变化不冒充主画布尺寸，冷生成的缓存身份包含主画布参考和像素密度。取消及失败释放须得到原生确认，之后才释放宿主对象。

公式验证拥有独立的生成器。两个编辑入口都等实际首帧成功、资源释放得到确认后才提交候选；取消、修改草稿和卸载使迟到结果失效。释放失败的所有者仍保留在验证生命周期内，下次验证先重试清理。

界面样例使用 512 粒子，验证交互与输出接线；下面另以原版标准配置测试实际规模。原版 MathArt 本轮没有启动，也没有使用原版 EXPORT。隐藏测试窗口始终不可见，不占用用户工作屏幕。首次界面脚本只匹配“compile/编译”，漏掉驱动返回的“syntax error”；修正观察条件后完整重跑通过，失败记录仍保留。

合成界面样例最终仅占据少量像素，不能用于评价构图质量。另行通过同一生产入口生成完整 standard custom 配置的[本机实际画面](../.cache/source-symmetry-application-20261026/full-visual/last-frame.png)：810×972、74,509 种 RGBA 值；无损 PNG 解码等于原始 RGBA，且与性能任务的 5/30 秒输出完全一致。这是本机结果，没有当作原版参考。

## 成本测量

通过生产 `Generator` 使用保存的原版 standard custom 配置，**562,144 粒子，810×972 像素**。输入 SHA-256 为 `6e46f8bf711b90e22a66cff8865e5e4f4d348c8d2f2b638631f03872bddbd406`。同一所有者依次生成 0、1/30、2/30、3/30、4/30、5/30 秒，再回到 0 和 5/30 秒；回退后两端完整像素分别完全一致。后续五次采样均确认计算样本数实际增加。

| 测量 | 结果 |
|---|---:|
| 新所有者首帧 | 491.54 ms |
| 后续五次实际推进，中位数 | 43.23 ms |
| 回退至首帧重建 | 433.93 ms |
| 重建后推进至 5/30 秒 | 124.43 ms |
| 整个受监督任务，包括加载、服务及清理 | 4.071 秒 |
| 子进程 CPU 时间 | 8.114 秒 |
| 同时进程组 RSS 采样最大值 | 642.5 MiB |

首帧包含构造和编译，不是清空系统缓存后的严格冷启动。RSS 每 0.5 秒采样，可能错过短峰，不含 GPU 内存；CPU 包含 `ps` 采样开销。系统缓存和背景负载未控制，没有等价旧应用入口的基线，因此不声称加速。先前性能试跑以 1/60 秒采样，含缓存命中；它未用于上表的推进帧统计。

本轮 Goal 工具计数从 96,779,529 到记录快照 97,087,492，差值 307,963 tokens；这是整个工作区间的工具累计统计，包含研究、重复检查及上下文，并非单次渲染的模型成本，也不含快照之后的报告与提交操作。性能脚本本身没有模型调用。
