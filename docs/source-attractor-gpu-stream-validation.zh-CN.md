# GPU 吸引子连续播放验证

更新时间：2026-10-19。当前仍在 **M3：场景补全与一致性验证**。这里验证本地实现的前后行为与资源管理；原版 JVM／JOGL 完整画面对照仍为 **0/11**。

## 本次改动

预览和导出现在各自持有 GPU 运动纹理及对应的相机队列。向前播放只计算新增更新，同一时刻或改变输出尺寸不会重新初始化粒子；倒退和编辑会重建。每帧仍清空密度附件，不累积前一帧的图像。画面直接携带对应相机，显示端不再另行重放。

相机跟踪仍读取原版规则下的初始 CPU 坐标，不读取演化中的 GPU 位置。只保存时间线实际绑定的粒子坐标，按原随机序列依次扫描至最大绑定索引，保留变步长的额外随机抽样。重复索引共用坐标；没有跟踪的队列不分配坐标缓存。统计为每个唯一索引 12 字节，另有未计入的 JavaScript Map、闭包与对象开销。

资源释放失败时保留 GPU 所有权和清理票据，下次使用先重试清理；成功退休后的旧票据不会释放新一代状态。独立查询在成功或失败后清理自己的实例，不能误清理仍在播放的预览会话。

256 MiB 表示预算、每次绘制 10 亿、实例累计 640 亿工作单位与 10000 次更新绘制限制继续生效。GPU 累计预算没有改成 CPU 的每请求预算；超限会明确拒绝，不减少粒子或子步。因此不能据本次短任务声称无限时长播放已验证。

## 已验证

- 192 项相关测试（13 个文件）通过，包括新增的前进／重复帧／倒退／尺寸变化、独立查询互不释放、清理失败与旧票据隔离、稀疏绑定和累计预算拒绝；共用相机队列在所有绑定结束后才读取或更新。模拟设备测试只证明这些边界，不证明真实 GPU 数值。
- 另做真实 GPU 会话验证：固定／变动步长各 14 次请求，包含高低乱序、重复和越界跟踪、重复帧、倒退及尺寸变化，加 4 次恢复对照，共 32 帧完整 RGBA 和完整相机匹配固定基线。真实 `deleteTexture` 注入一次失败后仍持有旧资源，下一请求先清理再分配；旧票据不影响新代。结束时受跟踪 GL 句柄为 0。
- 真实 Chrome 的底层 GPU 验证通过 16 组输入。比较使用固定原包着色器构建的独立浏览器参考；已比较的浮点状态和完整画面无差异，包含默认 20 万粒子、变步长、预热边界、色板、变换和色调。浏览器参考不是原版 JVM 渲染。
- 真实应用完成 GPU JSON 导入、编辑、保存重开／重新导入、正向与反向定位、播放／暂停／续播。暂停第 9 帧不动，续播第 13 帧与独立重算的完整像素和相机一致。
- 两张实际 PNG 与独立生成和原始 framebuffer 一致；256×192、6 FPS、12 帧 MP4 完成，所有视频输入帧与独立生成一致，解码结果按既有有损阈值逐帧检查。没有页面或控制台错误，浏览器及导出服务正常清理。
- CPU 实际界面回归同样通过导入、编辑、保存重开、定位、暂停续播及两张 PNG／12 帧 MP4。
- 类型检查和 Web 构建通过，保留既有的大分块提示。1.0 Apple Silicon 应用没有重新打包。

## 同等任务成本

基线固定为 `4690a5f69a259bbe628bc2c5acd91b0ec2046d70`。两边都导入、序列化并重开同一作品，输出 31 帧 640×360 完整 RGBA8 和相机，并计算哈希；每帧 5 子步、20 万粒子、默认变步长、零预热。旧版每帧独立重建并另查相机，新版复用会话并消费交付相机。所有帧的像素和相机哈希一致。

| 版本 | 首次／暖耗时 | 首次／暖 CPU | 首次／暖采样 RSS |
|---|---:|---:|---:|
| 旧版 | 6.299 / 6.250 秒 | 6.750 / 6.560 秒 | 1140.7 / 1098.8 MiB |
| 新版 | 0.357 / 0.319 秒 | 0.330 / 0.290 秒 | 1048.3 / 1089.2 MiB |

每个版本使用独立 Chrome 进程族，各运行一次首次任务和一次暖任务；不是多轮统计或跨设备结论。首次任务从模块加载后开始，不清空系统／驱动缓存。耗时包含生成、完整读回、哈希及会话清理；不含浏览器启动、打包和模块加载。CPU 按 PID 与启动时间汇总；RSS 每 250 ms 及任务边界采样，可能漏掉短命子进程和瞬时峰值，也不是显存。代理 token、GPU 设备时间、VRAM、编码成本及原版运行成本未测。

## 长任务及容量

20 万粒子、5 子步、30 FPS 的 301 帧后台任务（10 秒）完成；首次和暖任务完整哈希一致，只创建一个 GPU 实例。第 0、1、5、300 帧额外与独立查询比对。额外对照的成本包含在长任务测量里，不用它与 31 帧任务计算提速比例。

200 万粒子／5 子步在分配 GPU 上下文前触发既有单次绘制预算，完成 0 帧；这不是已通过配置。拒绝记录单独保留，没有自动降低作者输入。

200 万粒子／3 子步的独立配置完成 31 帧；首次／暖哈希一致，四个时刻与独立查询一致。仍不能声称这个配置达到实时帧率。

| 配置 | 首次／暖耗时 | 首次／暖 CPU | 首次／暖采样 RSS |
|---|---:|---:|---:|
| 20 万／5 子步／301 帧 | 2.327 / 2.231 秒 | 2.050 / 1.750 秒 | 1240.9 / 1277.0 MiB |
| 200 万／3 子步／31 帧 | 9.835 / 9.887 秒 | 9.910 / 9.620 秒 | 1423.3 / 1380.4 MiB |

两个任务都包含额外的四个独立查询；每个连续会话仅创建一个 GPU 实例。长任务累计读回约 277 MB，而非同时保留全部输出。
