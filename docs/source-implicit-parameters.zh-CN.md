# 隐式曲面参数动画验收（2026-10-24）

**CPU 隐式曲面的原版参数动画已接入导入、编辑、预览、录制、停止后继续和暂停截图。** 本次属于 2.0 预览源码的增量，尚未替换已安装的 1.0 应用。

## 可以怎样使用

在隐式曲面的时间线添加「动作组合」，选择「开始参数振荡」或「停止参数振荡」。具名开始可以设置参数名、上下界、每帧步长及端点减速；全部开始沿用已经注册的设置。具名停止暂停对应参数，全部停止暂停整个参数注册表。

原版导入项目会自动使用这套规则。旧版本已保存为「尚未映射」的动作仍明确保留；打开后点击「设置源参数配置」可以主动重新配置，不会悄悄猜测丢失的原始参数。

参数影响同一套实际几何状态。录制结束后继续播放、暂停、改变导出尺寸和保存 PNG，都使用对应数值会话中的参数；暂停截图不会重播动画。保存再打开的项目保留原始参数名、源数值词法与已经解析的配置。

## 实现与回归处理

原版参数由函数自身的已声明变量管理，只接受已知参数名，时间增量不大于零时不更新；采用实际帧率缩放。动作先统一启动，再统一更新，随后更新参数和几何。负时长动作组自身取零，但子动画保留原时长。上述差异均保留在共享数值队列中。

Surface 和 Implicit 的相同振荡算法抽为 `sourceOscillatingParameterRuntime.ts`，删除了旧 Surface 专用模块。两个场景保留各自的未知参数及时间增量规则。导入与持久化共用参数配置解析；普通预览和录制共用隐式参数所有者，截图直接读取当前状态。参数操作也纳入现有 4096 项时间线总容量与有取消检查的单次工作预算。

回归中发现新隐式预览分支绕过原有生成入口，导致进度回调拿不到公式标注。已修复入口：进度及最终输出均绑定独立公式、参数和相机快照；公式仍使用初始作者参数，不被当前动画值改写。相关测试已经通过。Surface 数值、实际帧率和参数编辑，以及共享迭代参数引用测试也通过。

本轮没有打开或移动用户窗口，验证全程在后台完成。
