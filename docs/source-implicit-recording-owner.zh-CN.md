# 隐式曲面录制底层验收（2026-10-24）

隐式曲面的录制时钟已由真实 Worker 内的独立会话管理。无需修改作品保存的 FPS，四组共 19 帧的实际相机、旋转速率、场景时间、步长和完成状态都与原版参考精确相同；经原生后端绘制的完整 384×288 艺术画面也全部零差异。

**这一步完成底层会话，尚未接入公开客户端、录制按钮及视频编码流程。** 原有手动指定时长的视频导出保持可用，已经通过独立界面回归。2.0 Goal 继续进行。

## 本轮完成

- 仅接受 Worker 持有的已完成 CPU 隐式主预览；保存作者文档和生成输入的副本，拒绝过期或外来请求。
- 使用独立录制 FPS、一次预热、原版顺序队列完成条件及三倍绘图尺寸。隐式离屏尺寸采用实际像素，并单独保留主画布密度，避免重复放大线宽。
- 连续取帧持有同一时钟。绘图失败后的重试沿用已消费的数值帧；响应丢失或缓冲区已转移时，不重复推进。
- 停止时重建当前帧的主画布几何，不再更新时钟；取消和停止响应失败均可恢复。停止后可以重新开始录制。
- 修复导入遗漏：无法映射的原版隐式参数动作以前只有警告和原始来源记录，规范化队列中没有动作。现在保留明确的 `sourceEffect: unmapped` 事实，保存再打开仍存在。本地预览不执行该动作，录制入口明确拒绝，不通过解释警告文字或重新解析原始来源来猜测支持范围。

## 证据与复验

本地目录：`.cache/source-implicit-recording-owner-20261024/`。

- `tests-verified.log`、`build-passed.log`：最终测试和构建输出。

```sh

  .cache/source-implicit-recording-clock-20261024/reference-v2 \
  .cache/source-implicit-recording-owner-20261024/worker-native-verified \
  --worker-recording

MATHART_SOURCE_RENDERER_BACKEND="$PWD/.cache/source-native-capture-20261023/backend.json" \
```
