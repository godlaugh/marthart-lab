# 分形组合运行与导入精度验证

后续公开接线进展见 [分形参数、队列与公开预览验证](source-fractal-public-validation.zh-CN.md)。本文保留当轮验收范围。

2.0 仍在 M3。原版完整窗口对照仍为 **0/11**；本轮完成组合运行核心和导入精度修复，尚未把新组合运行核心接入公开预览及录像。

## 已修复的公开行为

原版读取分形缩放的时长和关键帧时间时，先转 Double 再转 Float。本地此前直接转 Float，极少数长小数字符串会得到不同的关键帧次序。

例如时间 `1.0000000596046447753906250000000000001` 在原版这条读取路径中与时间 `1` 相同，因此后出现的目标应胜出。本轮复用同一字段解析入口，修复导入选择；保留原输入和非有限值的明确拒绝。目标数值自身的双精度读取规则不变。

实际后台浏览器已完成这个边界用例的导入、目标编辑器显示、渲染终点、保存及重开；另回归放大、缩小、等倍率中心移动、切换编辑模式、修改目标及 PNG 导出。共 7 项通过，没有页面异常，PNG 为 257 × 193。浏览器没有打开前台窗口。

## 新完成的运行核心

公式参数集合与最终渲染字段有不同的所有者。普通 bailout / Julia 动画只改当前原生字段；注册表参数每次写入会重新映射整组原生字段，可能覆盖刚完成的普通动画。因此不能把两者合并为一个 settings 表，也不能把 lambda 与 Julia 参数当成别名。

新公式模块保留参数缺省、空集合、元数据默认值与显式写入的区别，并分别提供传统 4 槽、动态 32 槽和双精度 Julia 值。原版配置读取、参数绑定与初始化按各自顺序执行。Newton / Nova 映射允许比普通 bailout 设置器更小的下限；组合运行不能在每帧无条件重调普通设置器。

组合模块将普通动画、参数启停、公式映射与渐变接在同一分形场景时钟上。最后一个片段完成时，额外的原始间隔更新也推进参数和渐变。暂停保留状态；参数停止后，普通动画值不再被注册表覆盖。

回放模块用帧序号驱动固定步长。向后拖动时重新创建整个场景，包括参数与渐变状态；实时播放与固定帧回放不能隐式混用。取消或子模块失败后，拒绝继续读取半完成状态，必须重建。录制规划包含一个预热帧，但目前只是帧序号计划，尚未接入实际录像编码。
