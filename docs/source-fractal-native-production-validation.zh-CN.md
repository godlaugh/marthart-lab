# 分形原生绘制接入应用与本地预览包验收

2026-10-26。**Fractal 的原生采样已接入实时预览、暂停截图、独立重建和保留场景录制。Apple Silicon 本地应用已更新到 `2.0.0-preview.6`。M3 仍未完成，11 个场景家族的一致性要求继续保留。**

只有目前这一台 Mac；跨设备验收保持未验证，不再等待第二台设备。本轮没有运行原版 MathArt，也没有操作用户桌面窗口。界面检查使用后台 Chrome 和隐藏的打包应用，数据保存到独立测试目录。

## 改动

同步 WebGL 与异步原生采样共用同一份分形生成逻辑、数值结果解释和呈现规则。异步绘制确认后才提交显示进度；实际响应中的渲染器身份与输出像素一起传递。原生实时会话使用页面时钟，独立录制使用固定步长，录制停止不额外推进数值帧。

截图明确计入旧预览和已捕获图像。整图、坐标与采样数组分配前，使用同一个预算计算器检查容量；不是等分配完成后才拒绝。最多保留两个原生分形资源，未确认创建或释放的资源仍占用名额。

取消只撤销发布，已提交的原生请求必须完成后才能释放。失败后的独立重建先确认释放旧资源；录制停止遇到不可继续绘制的后端时转为清理，释放失败保留原所有者，下次只重试释放。暂停、截图和录制准入也检查后端是否仍有效。

实际界面测试发现预览与独立导出会竞争同一个原生请求位置。现将已有的 Samila 导出暂停机制提取为共用机制，供 Fractal 使用：导出期间不再预订新的动画帧，关闭后恢复仍待绘制的预览。没有通过放宽传输互斥或增加无界请求队列掩盖冲突。

未运行全套测试。三组固定数学区域的参考来源见[原生画面证明](source-fractal-cgl-proof.zh-CN.md)。这不是原版窗口、全部公式、公式叠加或动画全程的独立证明。本轮录制验证到实际原生帧与停止/恢复，未重新编码并验收 MP4。

**当前 PNG 仍有画面验收限制：** 测试中的 Multi Pass 场景从预览尺寸切到 96×80，首次捕获的渐变纹理处于首遍状态，下载只有 1 种颜色；独立重建 PNG 有 13 种颜色。两者都与实际产生的像素完全相同，文件导出与状态保留管线成立，但不能据此宣布成品画面正确。仍需对照原版截图的显示推进顺序，不能把这个单色结果当作完整效果验收通过。预览在后续显示完成后呈现正常分形，已人工查看截图。

另有保守行为：截图若在绘制准入阶段失败，会话仍可能标记失效并要求重新应用。近容量上限的大图、长录制和驱动内存峰值未实测。

## 本地应用与记录

应用：`studio/dist-desktop-v2/MathArt Lab 2 Preview-darwin-arm64/MathArt Lab 2 Preview.app`。

这是本机 ad hoc 签名的 Apple Silicon 预览包；不是已公证的对外发行包。现有 1.0 包不在本次更新路径内。构建继续使用已配置的独立 JDK、官方 JLaTeXMath 和仓库 helper，没有安装系统依赖或引入原版应用运行时。

复验入口：

```sh
node scripts/verify-source-fractal-production.mjs
node scripts/verify-source-fractal-display.mjs /absolute/new/output
node scripts/verify-fractal-native-desktop.mjs /absolute/preview.app /absolute/passed-production-report.json
```

运行前使用仓库已有锁定 Node 工具链。原生生产验证总耗时 37.68 秒；250ms 采样的 Node/Chrome/原生进程族观测到 55.43 CPU 秒、约 2524.38 MiB 聚合 RSS 峰值。包含编译、启动、参考图和应用工作流，排除最后清理；共享页可能重复计算，短进程与瞬时峰值可能漏采。每组先创建资源，再复用绘制；未清空系统/驱动缓存，没有等价的旧版整套测量，不能宣称性能提升。GPU/VRAM 和逐帧 CPU/RSS 未测。

Goal 计数从本阶段开始的 98,824,457 到报告快照 99,695,369，增加 870,912 tokens，包含实现、上下文、复核和失败重试；不是渲染成本，收尾另计。
