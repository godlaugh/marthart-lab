# 分形公式与完整作品画面对照

2026-10-26。**已修复 Fractal 的公式导入、字形和尺寸绑定；两组 Mandelbrot 作品（含公式）在 500×600 全画幅逐像素一致。本地 Apple Silicon 应用更新为 `2.0.0-preview.7`。这完成了 M3 中一项实际缺口，M3 与全部 11 家族验收仍未完成。**

本轮原版采样使用无窗口 JVM/JOGL，界面测试使用后台 Chrome 和隐藏 Electron。没有操作用户的桌面窗口。仍只有这一台 Mac，跨设备保持未验证。

## 修复了什么

此前，原版 Fractal JSON 的公式会走通用 MathJax 布局，坐标被转换到 1280×720；Mandelbrot/Julia 的源主公式文本也尚未接入。现在导入按原版语义保存居中偏移与 Float32 缩放，使用已有的独立 JLaTeXMath 字形服务和源纹理合成器。

原版主公式由初始公式参数生成，不读取 `main_equation.latex`，也不读取根级 `formulas`。这些原始字段保留在来源记录，不擅自变成可见标注。导入后仍可以编辑本地自定义公式。已经保存的通用布局不自动迁移。

实时场景保留构建时的文字和样式，每帧只绑定实际主画布高度。调整窗口更新布局；热编辑保持原有文字。截图和录制继承已完成预览的主画布高度，独立导出必须明确提供这个高度。客户端检查实际返回的公式与视口；缺失高度时不会拿导出尺寸代替。

源透明公式颜色目前明确拒绝；字形尺寸、样式及容量仍受本地边界限制。此次不声称覆盖所有原版可接受的异常输入。

每组比较全部 300,000 像素、1,200,000 个 RGBA 字节。最后一行的差异逐项等于原版最后水印绘制产生的差异；没有裁剪水印或把它计为一致。增强后完整截图分别有 13,273 / 13,270 个差异像素，包含水印边缘增强的影响。因此准确结论是：**这两组完整作品与公式一致，带原版水印的最终截图并非零差异。**

原版正常初始化许可与场景策略，VIEW/RUN/EXPORT 均允许，FREE 水印照常绘制。原版自动刷新策略缓存；旧缓存已备份，许可和设置文件摘要未变。探针读取原始 GL draw 后的缓冲，恢复所读绑定，不更改绘制参数。默认组最终 PNG 与此前未插入读取观察器的采样完全相同。

原版执行 7 次暂停 `runFrame`；取稳定的第 3 帧。产品使用公共 Generator 的固定录制第 3 帧，输入只有 wait，没有影响图像的参数动画。两者证明上述静态图像，不证明暂停时钟与固定录制时钟相同。原版原始截图、增强图、公式前后缓冲和调用栈均完整保留。

## 实际界面与应用

- 实际导入开启公式的原版输入，预览正常；“当前帧”和“独立重建”两种 96×80 PNG 都与实际生成帧经过公式合成后的结果相同。
- 打包应用使用包内原生 helper 和独立字形服务，隐藏窗口验收两种 PNG；退出码 0，进程组为空，服务端口关闭。
- 浏览器内容区为 594×423，Electron 同样外窗尺寸下为 594×425。初次直接比较公式 PNG 失败；验收脚本将实际内容区对齐到 594×423 后，两种下载逐字节一致。没有改写公式或放宽像素断言。
- 702 项定向 CPU 测试通过，覆盖 36 个文件。首轮 701 项通过，1 项旧断言未包含新增的主高度字段；更新断言后该文件 7 项全部通过。未运行全套测试。
- TypeScript、Vite、原生与字形构建、深层严格签名检查、打包应用首次启动与恢复启动均通过。另复验三组浅层/深层 Mandelbrot 数学参考、录制/恢复/取消/故障清理，均通过。

应用位置：`studio/dist-desktop-v2/MathArt Lab 2 Preview-darwin-arm64/MathArt Lab 2 Preview.app`。这是本机 ad hoc 签名预览包；不是对外公证发行包。原有 1.0 包保持原路径。
