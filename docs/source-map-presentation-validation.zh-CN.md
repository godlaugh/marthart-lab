# Map 最终调色、背景与导出验证

2026-10-21。**新导入 Map 已接通源最终呈现，包括主画布归一化、最近邻采样、亮度转换和场景背景合成。** 当前仍在 M3；实时会话和原版完整窗口对照尚未完成，整窗验收仍为 **0/11**。

## 实际变化

新项目带有 map-present-1.7.8 标记，预览与导出通过 GPU 执行原版 Map 最终调色。导出沿用已呈现主画布的物理尺寸，不把导出分辨率当成主画布。没有提供主画布信息的底层调用会明确标记为 local-output。旧的未标记作品保持原模型，不自动迁移。

Map 与 Symmetry 共用已核对一致的 Float32 归一化、亮度转换、正常调色算式及 GPU 资源管理。Map 保留独立差异：最近邻采样；越界和空像素输出背景；质量大于 1e-6 才计算平均颜色。源最终调色失败时明确报错，不换成另一套 CPU 算法。

背景保存为 RGB 和 alpha 字节，二者共同保留原 ARGB。场景清屏颜色由原 Processing 规则解释，着色器背景则只按位读取 RGB。例如原颜色整数 128 清屏为灰色，着色器读取蓝色分量，两者不能合并。界面可以编辑背景 alpha，PNG 保留合成目标的 RGBA；预览复制已合成 RGB，视频传输把 alpha 明确置为不透明，避免重复混合背景。

Map 使用固定余弦配色。通用调色板和 color 原文保留在导入来源中，不再误用本地色板解析器拒绝它们；界面说明实际配色控制项，隐藏无效的调色板编辑及不兼容的白点模型切换。

## 导入与结构修正

实际运行原 JVM 的 ProjectState 和 JsonMapAttractorConfig 后，分别实现两条输入路径。项目字符串先读取 Java double，再缩为 Float32；运行配置还支持表达式，缺失／null 使用默认值，显式无效表达式或非标量回退为零。配置阶段保留衰减原值，在累积器读取时才夹到 [0,1]。颜色、背景、点尺寸等数值原文登记完整，编辑保存后不再从原始来源覆盖作者修改。

从吸引子模块移出原背景解析代码，建立共用配置背景读取模块；清屏复用已有 Processing 颜色转换。字段契约独立放在没有解析器依赖的模块，消除了新输入模块与数值原文登记之间的循环依赖。GPU 调色计划统一验证场景族、模型、归一事实及必需的清屏 RGBA，再把明确的场景族交给执行器。

## 边界与下一步

原 shader 在本地浏览器上的局部对照，不等于原 JOGL 驱动或原版整窗对照。收尾时重新读取 Yomado，原生工具再次返回“Mac 已锁定，自动解锁失败”。未取得原版窗口截图，未移动窗口或发送测试输入；虚拟屏上的截图和输入能力仍未验收。

Map 公开预览／导出仍按本地固定时钟重放；下一步接通原版实时显示、参数与相机事件、重播及暂停截图的状态管理。原版热更新点尺寸 setter 与构造值的区别仍需保留。原生宿主帧时序、目标随机流、MSAA／DITHER 和整窗效果仍需独立验收。

已有 Apple Silicon 1.0 应用未重打包或替换。
