# 曲面录制界面与视频文件验收

2026-10-22，开发分支 `codex/v2-scenes-parity`。

曲面录制已连接工具栏、导出对话框、连续帧客户端和 FFmpeg。可从上次完整应用的场景开始，跳过预热帧，录到动画队列结束；也可提前停止保存或取消。停止后恢复主预览并继续播放。

这属于 2.0 开发分支进展。已安装的 Apple Silicon 1.0 应用尚未重新打包。**原版 MathArt 整窗效果对照仍为 0/11，本次本地视频验证不代表原版 GPU、字体或整图一致性已完成。**

## 使用方式

导入源曲面项目后，点击工具栏“录制”，设置尺寸、帧率和质量，再开始录制。“导出作品 → 动画视频”也默认提供“从上次完整应用的场景录制”；原来的按时长导出保留为另一个选项。

录制起点使用最近一次完整应用的配置。若希望将修改作为录制起点，先点击“应用场景”。模拟与编码使用所选帧率；参数动画继续接收实际绘制间隔的帧率观测。录制使用三倍离屏画布并按实际像素密度取整，视频输出尺寸再单独取偶数。公式在上传 PNG 帧前叠加，录制帧不经过暂停截图的增强或放大流程。

“停止并保存”保存已经提交的连续帧；“取消”删除当前编码任务。队列若在预热时就结束，显示“没有可保存帧”，不会制造占位帧或空视频。上传、保存结果暂时无法确认时，保留同一个录制任务，允许“重试保存”。

## 本轮发现与修复

1. 曲面录制像素已经完成相机投影，生成端却未携带 `cameraResolved` 标记。预览渲染器会拒绝该图像。现在由像素生成端声明已投影，并通过真实 App 预览及回归测试确认。
2. 暂停确认改变运行时状态，不重画已完成图像。原校验把图像绘制时的暂停状态与当前运行状态强制比较，导致播放后暂停、再次录制时报“需要已完成的源主预览”。现在共享图像身份、相机、尺寸和数值事实校验；新返回的画面仍严格检查时钟状态，已完成图像的录制准入则允许已确认的播放状态变化。没有修改历史画面元数据或放宽新响应的暂停校验。

## 验证边界

自动化走实际 App 控件、生产 Worker/客户端/GL 绘图、公式合成、本地导出服务和 FFmpeg。CPU 点云、CPU 网格、GPU 点云、GPU 网格分别验证；每组覆盖自动完成、提前停止保存、取消、首个编码帧前停止、响应丢失后重试，以及真实空队列。

服务故障通过浏览器拦截实际成功的上传/完成响应来注入，随后允许查询确认或显式重试。它验证传输结果未知时的恢复行为，不冒充真实网络故障或驱动故障。视频以 ffprobe 核验尺寸、帧数、帧率、时长，并用 FFmpeg 解码检查动画帧变化；上传 PNG 检查真实公式颜色像素。

验证脚本曾因英文按钮名称写错而超时；另一次把浏览器设备密度当成预览密度，低质量预览实际仍为 1×，导致断言失败。修正控件名称，并让 GPU 案例使用高质量预览、显式断言实际密度后复验。这两次属于验收脚本设置问题，保留失败记录，不计为通过。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| 相关测试 | 12 个文件，170/170 通过 |
| TypeScript / Vite 构建 | 通过；保留既有大资源包提示 |
| 曲面实际界面与视频 | 4 种组合 × 6 条录制流程，全部通过 |
| 完成视频 | 12 个文件：每组完整录制、提前停止、恢复保存各 1 个 |
| 完整录制与恢复保存 | 64 × 48、4 fps、3 帧、0.75 秒；FFmpeg 解码可见帧变化（完整录制） |
| 提前停止 | 每组保存 1 帧，无额外数值更新 |
| 奇数输入尺寸 | 65 × 49 → 1× 离屏 195 × 147；2× 离屏 196 × 148；编码均为 64 × 48 |
| 公式 | 完整录制的 12 个上传 PNG 均检测到指定洋红色公式像素 |
| 空队列 | 4 组均仅预热，0 个编码任务、0 个上传帧 |
| 域着色共享界面回归 | CPU / GPU 两组实际录制、停止、取消、PNG 流程通过 |
| 运行后资源 | 浏览器、Vite 与导出服务均成功关闭；前后源码摘要一致 |

曲面验收总墙钟约 40.68 秒。132 次进程族采样：累计观测 CPU 约 56.99 秒，采样峰值 RSS 约 2236 MiB。统计包含驱动、浏览器、本地服务、FFmpeg 及其被采样到的子进程，可能遗漏短命进程和采样间峰值；不是产品单帧成本。

每个组合使用新页面，浏览器与服务复用，不是等价冷暖启动性能比较。前版没有等价的完整曲面录制界面，本轮不声称性能提升。VRAM 和完整 token 成本未测量。

## 复现与本机证据

```sh
node scripts/verify-source-surface-recording-ui.mjs <新的证据目录>
```

脚本使用后台 Chrome 和临时本地服务，不操作实体桌面窗口；退出时关闭自行创建的浏览器及服务。源码前后摘要用于确认运行期间文件稳定。视频、截图和完整 JSON 均保留在忽略的 `.cache` 目录，未加入 Git。

- `.cache/surface-recording-ui-tests.json`：170 项相关测试结果。
- `.cache/surface-recording-ui-build-final.log`：最终构建。
- `.cache/surface-recording-ui-acceptance/report.json`：最终 4 组实际 App/FFmpeg 验收、源码摘要和成本采样；同目录保留视频和截图。
- `.cache/surface-recording-domain-ui-regression/report.json`：域着色共享流程回归。
- `.cache/surface-recording-ui-first/report.json`：首次录制成功、重复录制暂停校验失败的诊断记录。
- `.cache/surface-recording-ui-final/report.json`、`.cache/surface-recording-ui-verified/report.json`：验收脚本控件名称及实际密度设置修正前的失败记录。
