# Symmetry 实时预览与编辑器验收

2026-10-21。Symmetry 的实时后台现在已接入实际编辑界面：播放、暂停、调色板/变换编辑重播、相机调整、时间跳转、取消与恢复均通过后台浏览器联测。**这完成了界面接入阶段，不代表 2.0 或原版画面一致性验收完成。原版整窗口对照仍为 0/11。**

本轮未操作主屏幕，未启动原版 MathArt 窗口，未重新打包或替换已安装的 1.0 Apple Silicon 应用。

## 使用行为

- 打开完整源模型的 Symmetry 项目时，先按本地固定步进重建起始预览，包含预热与首帧数学计算。随后由实时会话继续；不会因为初始处于暂停状态而只显示未预热种子。
- 播放时间来自 Worker 的真实场景时钟。暂停/恢复通过独立控制消息完成，等待正在生成的帧；恢复不补算暂停时间。队列结束后，粒子与仍开启的参数动画继续更新。
- 暂停后改变调色板或六轴变换，会逐帧完成重播。相同数值的新输入仍触发重播；撤销数值变化也会重播。重命名和等值撤销可以复用当前图像。
- 暂停时调整相机角度立即呈现；恢复时还原暂停前角度并继续环绕。修改缩放、中心、焦距或数学参数会建立新场景。
- 时间跳转是明确的本地逐帧重建，不是原版任意时间跳转能力。画布尺寸变化保留实时会话与粒子，不推进暂停场景的时间。
- 取消时保留已呈现画面；旧 Worker 的迟到结果不能替换它。重新计算建立新会话。

Samila 与 Symmetry 共用当前界面的播放会话标识、控制消息所有权和帧调度；各自的数学与重播规则仍由各自后台负责。Viewport 对实时 Symmetry 直接使用已交付的相机，不再通过固定时间线重演另一套相机状态。

旧文档缺少完整源参数/渐变/呈现模型时继续使用原有固定预览。**非零本地累积起点、停止记录批次，也保留固定回放语义**；它们不是原版实时 Mobject 的行为，不能被实时路径静默忽略。界面从这些配置恢复标准设置后创建新实时会话。直接请求不适用配置的实时 API 会明确拒绝。

## 实际执行的验收

新的 `scripts/verify-source-iterated-live-ui.mjs` 操作真正的 App、Worker 和 WebGL，不替换生成结果。1× 运行通过 11 项核心流程；最终 2× 运行通过 13 项，包含兼容性切换和原版项目样例。

| 流程 | 观察结果 |
|---|---|
| 初始显示、重命名 | 起始预览有数学采样；暂停空闲不继续计算，重命名不新增生成请求 |
| 播放、暂停、恢复 | 队列结束后仍更新一次数学；暂停保持时间，恢复不计入暂停间隔 |
| 暂停相机编辑 | 角度变化被显示；恢复的三个角度按独立 Float32 计算精确相等 |
| 变换、同值输入、撤销 | 保留会话，显式重播序号前进；相同值的两次完成图像哈希相等 |
| 调色板 | 实际编辑器触发重播并完成，普通数学更新次数为零 |
| 数学参数 | 新会话从起始预览重建，而非沿用旧粒子 |
| 时间跳转、尺寸变化 | 跳转使用独立重建起点；暂停缩放窗口保留会话和时间 |
| 取消与迟到响应 | 暂留一条真实 GPU 完成消息后取消，释放旧消息也不替换已呈现图像；重试成功 |
| 本地固定回放兼容 | 当前时间设为累积起点后只重建一个起始帧；关闭记录得到无累积图像；恢复设置后重新进入实时会话 |
| 原版项目样例 | 导入、播放、暂停和可见图案均通过，最终有 32,526 个占用像素 |
| Samila 回归 | 1×/2× 的编辑、元数据复用、同尺寸/异尺寸暂停 PNG、实时控制、跳转、重开通过；1× 离线视频通过；1.5× 测量与初始呈现通过 |
| 全量测试与构建 | 340 个测试文件、6,237 项通过；TypeScript/Vite 构建通过，保留已有大 chunk 提示 |

原版样例取自已固定 JAR 的 `data/SymmetryChaos/Emperors_Cloak.json`，成员 SHA-256 为 `31146f45ab32c9aa01045b78fb29314732167faadfce5b65a7442ac04bee1608`。脚本核对完整 JAR 摘要后，只把粒子数由 6,562,144 降为 32,768；公式、参数、色板、时间线及相机保留。该样例用于实际工作流与可见图案检查，**没有测试原始全粒子负载，也没有原版窗口的配对图像**。

界面联测发现并修复了真实竞态：重播最后一帧完成、队列解除 busy 后，React 可能尚未提交新状态，RAF 因旧 replayActive 多发一帧。现在完成回调立即撤销调度许可，再交给 React 呈现。后续验证中最后重播帧后没有额外普通显示，暂停空闲也没有追加请求。

测试脚本另有两次修正：使用实际按钮名 `Geometry & parameters`，以及按 Worker/请求身份匹配暂停确认，避免把已取消请求计入待确认数量。此前失败报告保留，没有删除或将其记为通过。

## 成本与剩余工作

最终 2× 界面任务耗时 17.66 秒，采样 CPU 27.99 秒，峰值进程族 RSS 约 1.90 GiB。Samila 回归耗时 43.43 秒，CPU 56.86 秒，RSS 约 3.64 GiB。最终全量测试耗时 44.92 秒，CPU 289.19 秒，RSS 约 4.10 GiB；构建耗时 35.09 秒，CPU 35.88 秒，RSS 约 1.93 GiB。

任务分别启动新进程，内部包含持续会话，没有独立拆分系统缓存冷/热成本。测试和构建并行运行。CPU/RSS 为 250 毫秒采样：可能漏掉短进程和峰值，CPU 是观察下界，RSS 可能重复计算共享页，未消除短任务内 PID 复用。GPU 实际内存与单任务 agent token 未测量；没有等价旧版完整实时界面基线，不声称性能提升。
